# 欢迎使用 WorkBuddy 项目

你好，新朋友 👋

这份文档帮你快速了解 **WorkBuddy 项目** 的核心定位、主要模块和使用姿势，方便你和队友在项目里高效协作。

## 它是什么

WorkBuddy 项目把"和 AI 协作完成工作"这件事拆成几个清晰的入口：**动态、计划、任务、协作任务、资产、团队、项目配置。**每个入口都有明确职责，避免大家在一个对话框里堆所有上下文。

## 主要模块

| 模块   | 它是做什么的              | 你可以怎么用                               |
| ---- | ------------------- | ------------------------------------ |
| 动态   | 查看项目最近发生了什么         | 先看团队最近上传了什么资料、创建了哪些待办、推进了哪些事项        |
| 计划   | 把事情拆清楚、分出去、推进起来     | 创建待办，写清楚任务内容，指定处理人和截止日期，推进状态         |
| 任务   | 和 **AI、队友**一起完成具体工作 | 发起任务、@ 引用资料或待办、邀请队友协作、一起补充信息和推进结果    |
| 协作任务 | 多人围绕同一个任务一起工作       | 队友加入后可以看到同一份上下文，继续发消息、确认结果，减少来回同步    |
| 资产   | 统一存放项目资料和任务产物       | 上传文档、表格、图片等资料，也可以把任务产物保存进来，后续继续 @ 引用 |
| 团队   | 查看成员并邀请队友加入项目       | 通过团队入口查看成员，有权限时复制邀请链接并设置加入角色         |
| 项目配置 | 让 AI 更懂这个项目         | 设置项目指令、连接器、专家、技能和自动化，让项目内任务复用这些能力    |

## 推荐上手姿势

1. 先看下项目"动态"，对当前进度有个感觉。
2. 在"任务"里发起一个新任务，把你想完成的事情写清楚，必要时 @ 引用资料。
3. 如果需要别人帮忙，直接邀请队友加入这条任务变成"协作任务"。
4. 任务有阶段性产物时，把它保存到"资产"，后续继续 @ 引用。
5. 项目里频繁用到的能力（专家、连接器、技能），统一在"项目配置"里设好，全员复用。
