# 2026-09-12 AI 新闻简报

> 侧重 AI Coding 与具身智能。筛选自 09-11 ~ 09-12 聚合源与行业动态，已避开 09-05 / 09-06 简报及近期已推送事件（GPT-6 Astra、Bun 1.4、Claude 费马证明、Copilot HydraFusion、OpenAI 断供 Cursor、Orca/OpenHands/FastContext、宇树 UnifoLM 开源、智元 AGIBOT WORLD 三期、优必选 H1、无界动力 K15 等）。

## 1. DeepSeek 开源 V4.1-Flash：552B MoE 输入仅激活 8B，1M 上下文 + API 大降价

**事件**
DeepSeek 正式发布并开源 DeepSeek-V4.1-Flash（MIT 协议）：总参数 552B 的稀疏 MoE 架构，输入 prefill 阶段仅激活约 8B 参数、解码阶段约 16B，原生端到端多模态视觉理解，上下文窗口拉到 1M token，KV 缓存开销降至上一代 V4 Flash 的四分之一。官方基准：GPQA Diamond 90.9%、Codeforces 竞程评分 3471、Terminal-Bench 2.1 达 90.6%；全档位 API 降价，闲时输入缓存命中价低至 0.02 元，SiliconFlow 等平台零日上线。

**关注理由**
「稀疏 MoE + 超低价 + 1M 上下文」组合直接冲击 coding agent 的成本结构：Terminal-Bench 90.6% 说明它在真实终端任务里已经能打，而 0.02 元的缓存输入价让「长会话 + 大代码库上下文」的 agent 工作流成本再降一个台阶。开源权重 + 国产算力平台零日托管，对自建 agent 流水线（尤其是成本敏感的长程任务）是本周最值得实测的模型。

## 2. Google 开源 Mantis：让 coding agent 自主完成「发现漏洞 → 复现 → 修补 → 再攻击验证」全链路

**事件**
Google 以 Apache 2.0 协议开源 Mantis 工具包，为 coding agent 提供模块化的安全技能：扫描代码文件、过滤误报、在隔离沙箱中复现漏洞、生成补丁，最后重新攻击验证防御有效——把漏洞处理的生命周期全部自动化，可直接挂进 CI 流程。

**关注理由**
AI 写的代码越来越多，「谁来做安全兜底」成了工程化的最后短板。Mantis 的关键设计是「复现 + 再攻击」双验证：补丁必须扛住重放攻击才算修复，而不是靠单元测试糊弄过去。这与本周 agent 治理主线（沙箱隔离、资源限制、特权身份管控）同向——coding agent 竞争已从「写得快」转向「写得对 + 写得安全」，安全自动化技能层会是下一个生态卡位。

## 3. Shopify 把 App 从 React Native 迁回 Swift/Kotlin 原生：coding agent 改写了跨平台的成本公式

**事件**
Shopify 宣布将移动应用从 React Native 全面迁回 iOS/Android 原生（Swift/Kotlin）。理由是：过去选跨平台方案的核心动机是「避免双端重复开发的成本」，而当 coding agent 能低成本并行维护两套原生代码库后，跨平台框架「省人力」的前提不复存在，剩下的只有双端体验与性能的妥协。

**关注理由**
这是一个架构级信号：AI coding 不只是「提效工具」，它在实质性地推翻过去十年因人力成本而做的技术选型。跨平台框架（RN/Flutter）的生存逻辑被 agent 直接动摇，未来「为一套代码跑多端付出运行时妥协」的理由会越来越少。反过来说，判断一个技术选型是否还成立，新标准是「这件事 AI 做起来还贵不贵」。

## 4. 超维动力完成超 5 亿元天使+轮融资：「数据-模型-本体」全栈闭环 + 触觉皮肤本体

**事件**
深圳具身智能公司超维动力（Kinetix AI，成立仅一年）宣布完成超 5 亿元人民币天使+轮系列融资，淡马锡旗下祥峰资本、方广资本、万石资本等加注。团队配置华为自动驾驶高管 + 港大科研副院长 + 前小鹏机器人整机负责人；已发布原生具身大模型 KAI World Model（百万级视频预训练）、第一人称数据采集头环 KAI Halo、人形本体 KAIBot（173cm、117 自由度、约 1.8 万触点的触觉皮肤覆盖）和 1:1 仿人灵巧手 KAI Hand（37 自由度）。其 SMASH 2.0 乒乓系统已实现同一套感知-预测-控制算法迁移到宇树 G1、智元远征 A3 等异构本体，验证「一脑多形」。

**关注理由**
投资方明确表态：具身智能实现路径尚未收敛，「数据、模型、本体分头推进时问题难定位」，因此押注全栈闭环团队。这与 09-06 推送的「资金从本体转向大脑」形成对照——现在头部资本开始为「全栈协同」付溢价。触觉皮肤 + 毫秒级全身协同 + 跨本体迁移这三个硬指标，恰好指向「泛化」这个行业内核，值得持续跟踪它的真机落地数据。

## 5. 外滩大会具身智能之辩：「数据越多越聪明吗」+ 机器人从展台走进真实门店

**事件**
2026 外滩大会（9/9-9/12）上，破壳机器人创始人、清华交叉信息研究院许华哲直指行业被高估的部分：当前没有证据表明数据数字越高模型效果越好，按市价一百万小时数据投入可能达数亿元，应「边扩边找」先验证数据有效性再放量。SAG 数据同时显示：上半年全球人形机器人出货约 1.91 万台（同比 +272%），工业和商业应用占比已超 70%。落地侧，蚂蚁灵波「机器人智慧药房」已在上海国大药房真实运营（80cm 窄通道、反光透明包装干扰下自主接单拣选），同一套大脑可驱动物流分拣、工业上下料等多形态机器人（「一脑多机」）；擎朗人形机器人进入香格里拉等酒店承担取衣、洗衣、叠衣长程任务。

**关注理由**
两条线索拼出行业的真实坐标：出货量暴涨、商业场景占比过七成说明产业化在加速，但头部研究者公开质疑「堆数据」路线，说明模型泛化还没有标准答案。「数据有效性优先于数据规模」对做数据采集/标注的团队是直接的方向校准；而「真实门店 + 免改造部署 + 一脑多机」则是从 demo 走向经营场景的关键一步——能不能在不同门店复用同一套模型，是今年判断具身智能是否真泛化的最直观标尺。
