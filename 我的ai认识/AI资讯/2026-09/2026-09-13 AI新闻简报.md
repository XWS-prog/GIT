## 1. 工信部印发《"人工智能+软件"专项行动实施方案》：AI coding 进入政策主赛道

**事件**
9 月 11 日，工信部印发《"人工智能+软件"专项行动实施方案》，明确到 2028 年培育一批高水平智能编程工具与开发平台，推广覆盖 2 万家规模以上软件企业，实施 100 项软件企业智能化技改项目，在重点行业打造 100 个智能体软件标杆应用；从推进软件生产变革、关键软件智能化升级、培育智能体软件新业态等六方面部署，并提出完善智算云服务、用好"算力券"降低中小企业用算成本。

**关注理由**
这是国家级部委首次把「智能编程工具 + 智能体软件」写成带量化指标的专项行动——AI coding 从工程社区的自发实践，正式升格为产业政策对象。对做编程智能体、代码基础设施的团队，这意味着未来两年会有真金白银的采购需求与标杆项目机会；同时「由人工编写向人机协同、由产品交付向价值交付转型」的提法，等于官方给「agent 重构软件生产方式」背了书。政策风向值得纳入技术选型与商业化的考量。

## 2. Benzi 开源编译器式代码索引：用确定性索引替代「读整库」，SWE-bench 单实例成本约 0.095 美元

**事件**
9 月 12 日，开发者开源 Benzi——一套为 AI 编程智能体设计的编译器式代码索引基础设施：基于 tree-sitter 把代码库解析成符号、调用边与继承链组成的可查询地图，让模型用 O(1) 查找替代「读大量源码」，显著降低 token 消耗与上下文漂移。信息分为 RESOLVED（确定证据）/ CANDIDATE（静态分析候选）/ OBSERVED（运行时观测）三级以缓解编译误差，支持 Python/TS/Java/Go/Rust 等 10 种语言及 HTML/CSS 专用引擎。SWE-bench Verified 上配合 DeepSeek v4-flash 取得 78.2% 解决率；24-bug 跨 harness 对比中，Sonnet 版本仅读 9,125 行源码，而 Claude Code 需 20,704 行。VS Code 插件与 Web Demo 已开放。

**关注理由**
「coding agent 效率瓶颈在上下文管理」正在从共识变成工程竞速：Benzi 的思路是不堆更大窗口，而是给模型一个编译器级别的「确定性地图」，从检索范式转向查询范式。读码量减半 + 单实例约 0.095 美元的成本，对大规模并发 agent 流水线是实打实的经济性改善。这类「结构化代码理解」工具（代码索引、LSP 挂载、依赖图）很可能是下一层 agent 基础设施卡位点，值得实测对比。

## 3. 「多模型路由」在本周集中落地：编码 Agent 进入「质量—成本」真实竞赛

**事件**
本周几条信号同时出现：Sakana AI 推出 Fugu Max / Ultra v2，把每个任务动态路由到「最便宜能完成的模型」，宣称近旗舰质量、成本降 2-6 倍；Cognition 的 Devin Fusion 配对「前沿主力 + 廉价副手」，成本降 43%、提速 31%，并首登 Artificial Analysis Coding Agent Index；Claude Code v2.1.269 引入 plugin eval（插件可写测试、打分、关闭重跑看差异），并发上限提到 256；Codex 桌面端已支持对接 Ollama 本地模型，离线开源权重的编码闭环成型。

**关注理由**
与 09-05 推送过的 GitHub Copilot HydraFusion 单点方案不同，本周的信号说明多模型路由已经从「演示特性」变成行业标配——头部玩家全部在押注「不是所有子任务都值得旗舰模型」。配套变化同样关键：plugin eval 让 agent 输出可以被自动化测试打分，本地模型接入让私有化部署成为选项。「能跑 → 可测试、可规模化并发、可私有化」的工程化转向，意味着接下来比拼的是调度策略和评测基建，而不只是单模型能力。

## 4. 优必选柳州「万台级」人形机器人工厂投产：用机器人造机器人

**事件**
9 月 12 日，优必选柳州万台级工业人形机器人超级智慧工厂投产，是其全球首个适配万台级产能的智能制造工厂：占地 1.4 万平方米，每 10 分钟可下线 1 台机器人、年规划产能超万台；联合西门子打造人形机器人专属智造底座，落地「用机器人造机器人」模式。主力产品 Walker S2 搭载工业人形协作智能体 Co-Agent，支持自主换电与 7×24 小时作业。

**关注理由**
国内人形机器人正在从「千台量产」跳到「万台级制造」，而这座工厂本身就是最好的落地案例——产线调度、质检、搬运由机器人自己承担，等于在制造环节闭环验证了自家产品的作业能力。结合本周小鹏 IRON 自动化产线启用（自动化率超 80%、首台自主走下线）与智元上半年出货 1.5 万台并启动赴港上市，「量产能力」正在取代「demo 表演」成为头部竞争的分水岭；产业链配套（换电、智造底座）的成熟度也直接决定 2027-2028 规模化渗透窗口能否兑现。

## 5. 朱军团队发布通用世界模型第一性原理框架与五级路线图：给「世界模型」立了可量化的坐标

**事件**
9 月 12 日，清华大学 TSAI 实验室与生数科技团队（朱军等）发布通用世界模型的第一性原理框架与五级演进路线图：以「理解、想象、行动」三大核心能力定义通用世界模型，提出 MoT 架构让各模态保留专家参数、经共享注意力交换上下文；产品线上 Vidu 验证数字世界、Motus2 验证物理世界——后者集策略、模拟器、评估器于一体并加入触觉专家，实现行动前预演与闭环自进化。团队称现有系统已触及前三级。

**关注理由**
「世界模型」是当前具身智能最热也最混乱的概念——各家口径不一、无法比较。这份工作的价值在于给出可量化的分级坐标（类似自动驾驶的 L1-L5），让 TARS AWE、智象未来 HiDream-O1-Embodied 等本周密集发布的具身世界模型有了统一的评价参照系。触觉专家 + 行动前预演的设计也呼应了行业共识：物理世界的泛化不能只靠视觉。对跟踪具身「大脑」路线的人来说，这是一个值得对照所有新模型的基准框架。
