# 2026-09-17 AI 新闻简报

## 1. [AI Coding] 豆包 Doubao-Seed-2.1-pro-0915：多子 Agent 连跑 36 小时，修完开源游戏 83% 历史 Issue

**事件**：9 月 16 日火山引擎全量上线 Doubao-Seed-2.1-pro-0915，接入豆包工作与 TRAE。在约 38.7 万行的真实开源游戏仓库 Luanti 上，从真实历史 Issue 筛出 1000 个（覆盖渲染、网络、物理等 13 个模块），模型调度多个子 Agent 并行开发，近 36 小时将 83% 修复到可合并标准，正确率较上一代提升 31%。另一个案例更有意思：一套 28 万行、缺文档的传统 Java ERP 老系统，只给 PC 操作录屏 + 几张手绘业务草图 + 源码，约 2 小时理顺采购全流程，产出 3 个移动端页面约 2000 行代码并跑通完整链路。图像与视频推理 Token 消耗较上代下降 30% 以上。

**关注理由**：AI 编程正从「补全一行」走向「承包整条 Issue 队列」，多子 Agent 并行 + 长时连续作业成为新的能力度量口径。多模态入口（录屏 + 手绘草图驱动遗留系统改造）意义更大——大量没有文档、只存在老师傅经验里的存量系统第一次有了低成本改造路径。Token 降耗则让这种长程作业的成本账算得过来。

## 2. [AI Coding] VS Code 1.138 Agent Host 架构落地：Agent 会话成为可打包带走的工程资产

**事件**：9 月 16 日微软发布 VS Code 1.138，把筹备近一年的 Agent Host 架构推进日常版本：会话由独立后台进程「持有」，不再绑定某个窗口——关掉文件夹、离开机器，会话仍在跑。会话可运行在本地 Dev Container 内（Agent 面对项目真实工具链，消掉「在我机器上能跑」类失败）；Codex 可在 Copilot 与 ChatGPT 两种订阅间中途切换不中断会话，会话还能在 ChatGPT 应用与 VS Code 之间交接、自动归档。

**关注理由**：编辑器正在从「聊天框」变成能托管长跑「工作单元」的载体，Agent 会话第一次有了独立于窗口的生命周期——可交接、可归档、有状态。Codex 双订阅中途切换则承认「模型与工具正在解耦」：用户买的是能力而不是厂商席位。对企业这既是灵活性也是新的治理题（会话换底座后审计口径怎么跟）。

## 3. [AI Coding] Kimi K2.7-Code 开源：编码模型竞争焦点从「谁更聪明」转向「单位任务花多少钱」

**事件**：月之暗面开源 Kimi K2.7-Code——1T 总参数、激活 32B 的编码向 agentic 模型。核心亮点不是榜单峰值（仍落后 GPT-5.5 与 Opus 4.8），而是相比 K2.6 思考 Token 削减约 30%，延续「够用 + 便宜 + 可自托管」路线。同日 Hugging Face 开源 agent-eval 基准，评测 Agent 在代码库里「走过的路」（回合数、Token 数、错误数）而非只看最终答案；其案例研究发现一个反直觉结论：加 CLI 和 Skill 能提升大模型表现，却反而伤害最小模型。

**关注理由**：两条消息指向同一趋势——开源编码模型进入「单位任务 Token/成本」竞争阶段，cost-to-solution 取代榜单分数成为核心指标。agent-eval 进一步说明「Agent 优化」不是可一次性 bolt-on 的属性，必须按模型尺寸在自己的工具链上分别测，不能从榜单外推。另注意其短板：英文 CLI 体验缺失，中文团队要用起来还得补工具链。

## 4. [具身智能] 地瓜机器人完成 4 亿美元 C 轮：具身芯片底座进入量产级出货

**事件**：9 月 17 日地瓜机器人宣布完成 4 亿美元 C 轮，未来资产领投、美团战投，合肥国投等国资平台与高瓴、五源、淡马锡 Vertex 等跟投。旭日系列芯片累计出货突破 800 万片，2026 上半年营收同比数倍增长；旭日 S600 发布半年内获它石智航、千寻智能、自变量、优必选、北京人形机器人创新中心等 20 余家头部客户采用，具身智能领域客户覆盖率突破 50%，多数合作项目已进入量产级出货。募资用于旭日全算力段产品矩阵 + 贯通「数采-训练-仿真-部署」的全链路软件平台。

**关注理由**：与近期「资金从本体转向大脑/底座」的判断一致，具身竞争的上游——机器人芯片与软硬一体基础设施——率先跑出了规模化验证：800 万片出货 + 50% 客户覆盖率是硬数据而非叙事。当本体厂商洗牌加速（见下条），卖「铲子」的底座公司反而先收钱，这个结构性信号值得持续跟踪。

## 5. [具身智能] 深兰机器人进入司法破产清算：明星机器人公司首次退场，分水岭改由现金流画线

**事件**：曾经的明星机器人公司深兰机器人已进入司法破产清算，管理人公示的五批职工债权显示累计涉及职工超百人、债权总额突破 2300 万元，绝大多数是拖欠工资与经济补偿金。其业务横跨工业、服务、医疗、汽车零部件，但多数停留在样品阶段。今年已有骨科手术机器人龙慧医疗、美国人形公司 Cartwheel Robotics 等退场，深兰是其中声量最大的一家。

**关注理由**：这是具身智能行业第一次有明星公司正式清算退场，与同期优必选万台工厂投产、地瓜大额融资形成同一天的两极画面。坍塌路径很标准：用广撒网业务线换估值、靠融资输血，却没有一条线跑到可持续交付。行业验收标准正从「会不会做 Demo」换成「能不能发工资」，叠加此前梅卡曼德对虚假收入的质疑、工业真实商用订单仅约 21% 中标占比，下半年洗牌信号会越来越密集。
