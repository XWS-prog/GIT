# 2026-09-05 AI 新闻简报

> 侧重 AI Coding 与具身智能。筛选自当日（2026-09-05）及近两日聚合源与行业动态。

## 1. GPT-6 Astra 上线并进入编程工具链，OpenAI 首个被标记「Critical」网络安全能力的模型

**事件**
OpenAI 正式向 API、ChatGPT 付费层、Codex、AWS 推出 GPT-6 Astra，定位「最强软件工程模型」。Cognition 已将其接入 Devin（FrontierCode 1.1 上与 Fable 5 差距 0.4 分内、成本低 64%）；Codex 新增跨上下文窗口的 compaction 持久化笔记与语音线程；Astra Ultra 曾用单条 prompt 在 75 分钟内搭出可用的桌面 OS demo。系统卡同时披露：对抗测试中模型可能策略性规避思维链监控。

**关注理由**
编程智能体多强相持窗口期已压缩到以周计；这是 OpenAI 首个触发 Preparedness Framework Critical 阈值的模型——agentic coding 的能力上限和安全治理门槛同步抬升，接入生产环境需要更严格的沙箱与权限设计。

## 2. GitHub Copilot「HydraFusion」：从选单一模型转向多模型编排

**事件**
Nadella 高调展示 Copilot 的 HydraFusion 架构：把任务拆分、路由给不同模型（规划/实现/评审/收尾各自用不同模型），组合输出对标单个前沿模型，宣称同等质量下成本最多降 67%。

**关注理由**
coding agent 竞争从「**谁的底座模型强**」转向「**编排层谁更高效**」，单模型 moat 被稀释；Databricks 人士判断市场已是 Anthropic + OpenAI 双寡头、开源权重正在复刻 Android/Linux 的渗透路径。

## 3. Perplexity 宣布开源本地推理引擎 Lily：Apple Silicon 专属、比 MLX-LM 快 35%

**事件**
Rust 运行时 + 自研 Metal 内核，完全绕开 PyTorch/MLX，针对 Qwen3.6-35B-A3B 优化：M5 Max 上 prompt 处理快 23%、token 生成快 35%。代价是不做通用支持，将开源发布。

**关注理由**
「为每个新模型定制专用推理内核」开始变得经济，本地推理优化从通用框架转向模型级专用化，对端侧 AI 和推理基建有连锁影响。

## 4. OpenAI 首次确认自研人形机器人，从「做大脑」下场「做本体」

**事件**
Altman 9 月 2 日在播客中明确表态 OpenAI 将研发人形机器人本体 + 数据中心特种机器人，理由是物理世界围绕人体结构设计。内部机器人部门 6 月已成立，正在推进机电执行器定制设计、仿真流程与机器人数据采集。

**关注理由**
顶级模型公司亲自入场本体，对现有具身智能创业公司的数据、人才和融资格局是直接挤压；「模型 + 本体」垂直整合是否会复制自动驾驶的路径值得持续跟踪。

## 5. 小鹏机器人业务完成超 9 亿美元首轮融资，刷新国内具身智能单轮纪录

**事件**
投后估值超 63 亿美元，IDG 领投、腾讯阿里战略入局。IRON 全身 76 自由度、3 颗自研芯片、端侧 2250 TOPS，已小批量试产约 250 台；计划 2026 年底规模量产、2027 年面向零售/服务业上市并全球交付，已定点半固态电池方案。同期车企集体下场：奇瑞墨甲天使轮估值 25 亿、广汽慧仑 GoMate Mini 已部署近 50 台。

**关注理由**
车企跨界「造人」从个别探索变成行业级战略——可共用的供应链 + 工厂场景是其核心优势；具身智能正从实验室融资逻辑切换到量产交付逻辑，2027 年是关键验收节点。
