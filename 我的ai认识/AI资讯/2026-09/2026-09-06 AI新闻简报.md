## 1. Bun 1.4 发布：AI 用 11 天重写百万行代码，Token 账单 16.5 万美元

**事件**
Bun 1.4 正式发布，核心开发者 Jarred Sumner 先搭好 Agent 工作框架，再让多个 AI Agent 并行将运行时底层代码从 Zig 重写为 Rust——11 天产出 6778 次提交、超过 100 万行代码变更，单次合并记录达「+1,009,257 行」，全程消耗约 16.5 万美元 Token。InfluxDB 创始人 Paul Dix 随后撰文《The end of programming》，称「程序员写代码、另一个程序员逐行 Review」的模式正在消亡：他观察到 OpenAI 和 Anthropic 内部开发者现在一周能提交几十甚至上百个 PR，逐行 Review 已不可能，工作重心转向写 Prompt、搭 Harness、做测试、设验证条件。

**关注理由**
这不是 Copilot 补全几行代码，而是 AI Agent 首次独立完成百万行级、且修到稳定发布的工程级迁移——「**把 100 万行翻译出来不稀奇，能修到稳定发布才是关键**」。开发者角色从「写代码」转向「搭流水线 + 验结果」，这个信号对个人工作流（如何组织 Agent 并行干活）有直接参考价值。

## 2. Claude 自主完成费马大定理完整形式化证明，产出 1300 万行可验证 Lean 代码

**事件**
Anthropic 宣布，数十个 Claude 智能体在 Prove2Me 平台上协作，历时约 11 天生成约 1300 万行 Lean 代码，完成费马大定理史上第一个被计算机完全验证的形式化证明，最终形式化包含近 29,500 个中间定理。需要澄清：费马大定理本身由 Wiles 于上世纪 90 年代证明，Claude 并没有发现新证明，突破在于把一个人类极易看漏细节的超复杂证明转译成机器可自动校验的形式并全部通过检查。

**关注理由**
与 Bun 事件同一天出现，形成呼应：一个展示 AI 改写工程代码的极限，一个展示 AI 啃「人类最硬的智力活」。长周期、多 Agent 协作 + 机器可验证的闭环（写 → 验证 → 修）可能成为 agentic coding 最早跑通大规模价值的场景——形式化验证天然提供客观奖励信号，绕开了「代码对不对要靠人看」的瓶颈。

## 3. Cohere Labs 实测 69.6 万个 Agent 工具：只有 2.6% 能独立完成真实任务

**事件**
Cohere Labs 从 12.3 万个 MCP 服务器中抓取了 69.6 万个 Agent 工具做实测，发现只有 2.6% 能独立完成一个真实的岗位任务。同期 Armature 一项 17,000 次会话的实验显示，Claude Code、Codex、Cursor 面对同一请求选择同一个外部工具的概率只有 42%。

**关注理由**
对火爆一整年的 MCP/Agent 工具生态是当头一盆冷水：工具数量指数增长，真正能扛活的极少；不同主流 coding agent 连「选哪个工具」都远未收敛。Agent 落地的瓶颈已从「有没有工具」变成「工具好不好用、标准化程度够不够」——做 MCP 服务或 Agent 工具链的话，质量与一致性比数量更重要。

## 4. 上半年人形机器人出货超 2 万台、国内融资 935 亿元：资金从「本体」转向「大脑」

**事件**
行业统计显示，2026 上半年全球人形机器人出货量突破 2 万台、同比增长近 3 倍，智元以约 44% 份额居首，工信部预计我国全年产量有望破 10 万台。资本端：上半年国内具身智能赛道融资 322 笔、总额 935 亿元，同比暴涨约 5 倍；但重心已从硬件本体转向机器人大脑——超一半资金涌向 VLA 模型、世界模型及数据基础设施，本体厂商获投不足 20%。同期加速进化完成近 10 亿元融资（Booster K1 累计出货超千台、覆盖全球 20 国），梅卡曼德登陆港交所成为具身智能「眼脑手」第一股。

**关注理由**
具身智能正经历第一次价值重估：一级市场加码、判断标准从「demo 炫技」切换到「量产交付 + 商业化营收」；资金明确投票给「大脑」（模型与数据）而非「身体」。这意味着掌握高质量真实交互数据与 VLA/世界模型能力的团队将拿走行业大部分利润，纯本体组装的护城河在快速变薄。

## 5. 智元开源 AGIBOT WORLD 第三期数据集：11,430 条真机强化学习轨迹

**事件**
智元机器人正式发布 AGIBOT WORLD 2026 第三期具身智能强化学习开源数据集，首批开放 11,430 条真实交互轨迹，覆盖工业、家居等真实场景，包含网线插接、钥匙开门等 14 类交互任务，附带超 9.8 万个细粒度关键状态标注，支持训练不同维度的奖励模型，为真机强化学习提供可复用的经验数据基础。

**关注理由**
真实物理交互数据是具身智能最稀缺的资源，行业真实数据供给与需求之间缺口在 99% 以上——这与上一条「资金涌向数据基础设施」直接呼应。头部厂商持续开源高质量真机数据，一方面在把「数据壁垒」转化为生态护城河（吸引开发者绑在自己的模型/数据栈上），另一方面也为中小团队提供了绕开数据垄断的路径。真机 RL 数据 + 细粒度状态标注是训练奖励模型的关键素材，值得做机器人方向的开发者直接跟进。
