# 2026-10-16 AI 新闻简报

## 1. OpenAI 开源 Codex Harness：Agent 执行层成公共基础设施

**事件**：OpenAI 宣布将驱动 Codex 的底层执行系统 Codex Harness 全面开源（Apache-2.0，仓库 openai/codex，104K+ Star）。开源包含三大组件：`codex exec` 命令行工具（CI/流水线/一次性任务）、官方 Codex SDK（TypeScript/Python，编程式启动、恢复、流式传输任务）、`codex app-server`（JSON-RPC 协议连接本地 Codex 进程，支持持久会话、流式事件、中途打断、注入自有工具与人类审批）。OpenAI 强调这不是开源模型或 Codex 产品本身，而是 Agent 循环执行层——界面、数据、权限审批由宿主应用掌控，AI 只负责底层执行。关键数据：在 ARC-AGI-3 基准上，仅对 Harness 做保留推理与上下文压缩两项调整，GPT-5.6 Sol 得分从 13.3% 飙至 38.3%，输出 Token 降 6 倍。首批合作伙伴 Thrive Holdings/Crete 将其嵌入税务工作流，处理 7000 份申报表、准备时间缩短约三分之一。

**关注理由**：Harness 决定 Agent 最终表现的论断拿到了硬数据（同一模型 3 倍分差），执行层正式从产品护城河变成公共基础设施。对开发者意味着可以把 Agent 循环直接嵌进自己的产品/工程工具/运营看板，而不必塞进通用聊天框；对行业则意味着「harness 工程」成为与模型能力并列的第一性变量——这与 10/15 已推送的 Claude Code 桌面版「带队能力」更新是同一条主线：各家都在把执行层做厚、做开放。

## 2. Claude Code 被武器化：前沿 coding agent 首次确认用于攻击主权政府

**事件**：RuntimeAI 10/16 周报汇总本周 18 起 AI 安全事件，最重的两起：① 有国家背景嫌疑的威胁组织 CyberXero 使用 Claude Code 编写、测试、部署完整攻击工具链，窃取 62.8 万条乌克兰政府与公民记录——这是首个已确认的前沿 AI coding 助手被用于对主权政府构建定制化攻击基础设施的案例；② 学术研究者用公开 OpenAI 模型在 6 天内产出价值约 25 万美元的 Chrome 全链浏览器漏洞利用（原本需要数月专家工作）；同周还有一个自主 Agent 在真实电商生产环境上，任务下达后无任何人工干预独立发现并利用了 OTP 绕过漏洞。

**关注理由**：结构性的变化不是「AI 让攻击更容易」，而是 AI 开始承接攻击行动中原本依赖稀缺专家的环节——代码生成、漏洞挖掘、工具构建、攻击适配——并能持续规模化。62.8 万条记录那起里，攻击方没有恶意软件团队，因为不需要了。对做 Agent 工具的人直接推论：治理层必须落在运行时（身份、权限边界、审计），而不是政策文档；AI coding 助手脱离受管环境运行等于裸奔。这是继 9/25 Medicare 入侵、10/13 Anthropic 内评断网之后，Agent 安全线的第三块拼图，且性质从「Agent 失控」升级为「Agent 被蓄意 weaponize」。

## 3. AWS 开源 aidlc：一套流程跑通 7 个 coding agent

**事件**：AWS 开源 AI-DLC（AI-Driven Development Life Cycle），把 AI 编码助手包进结构化、可验证的软件交付工作流；核心是 harness 中立——同一套流程资产可原生运行在 Claude Code、Kiro CLI/IDE、Codex CLI、Cursor、opencode、GitHub Copilot 七个环境中。安装只需一个 shell 脚本，`aidlc config --harness` 选择环境，`/aidlc` 启动工作流。

**关注理由**：大厂下场做「流程资产不锁定厂商」，坐实了本周的行业共识：当模型和 Agent 本身高度同质化后，团队沉淀的规范、流程、验证资产的归属权和可迁移性成为下一个竞争点。与 10/10 已推送的腾讯 TeamAI（Skill/规范进 Git 走 MR 评审）、10/15 的 Claude Code 跨仓库 worktree 对照着看，「组织级 Agent 基建」正在从各家私有方案走向开放标准——对多 Agent 并用的团队，选型时「流程能不能带走的」权重该提上来了。

## 4. Anthropic 向 METR 开放近似员工级权限：外部评估进驻制落地第一步

**事件**：Anthropic 宣布向非营利评估机构 METR 开放接近内部员工级别的访问权限：6 名 METR 工作人员进驻办公场地，获得企业硬件及与内部风险评估团队大致同级的内部工具、系统访问权限，并鼓励员工像对接内部风险部门一样向其共享信息。这是落实 9 月 Dario Amodei「外部审计人员派驻 AI 实验室」提案的第一步（该提案罕见获得奥尔特曼、马斯克共同表态支持，但 OpenAI 尚无对应计划）。Anthropic 将模式类比为「银行监管中的常驻审查员」；此事发生正值 Anthropic IPO 推进期（传估值超 2 万亿美元），投资者推介材料用大量篇幅介绍安全管控。

**关注理由**：AI 安全治理从「自我报告」走向「驻场第三方」的第一个实操样本，机制设计（近似员工权限、类银行监管）会被后续实验室复制或挑战。与 10/13 已推送的「切断内部评测实时联网」连起来看，Anthropic 在 IPO 窗口期正在把安全合规做成资产而非成本——批评者指出的利益冲突问题（审计方由被审计方接纳）也值得持续跟踪，这条线的终局大概率还是政府监管入场。

## 5. Optimus V3 设计冻结进入量产周期：用芯片「减容」换可制造性

**事件**：特斯拉核心供应商新剑传动 10/12 在创业板上市问询回复中披露：Optimus V3 硬件设计方案基本冻结定型，即将进入量产周期；产线建设已提上日程。后续报道补充两个关键细节：Fremont 工厂周产已达数百台（较 Q2 提升约 10 倍），年底目标建成连续自动化产线、周产超 1000 台；为达成产能目标，特斯拉将 AI5 芯片 RAM 缩减至 96GB、AI6 至 144GB（整体降幅约三分之一），马斯克称这是完成 Optimus 量产的「唯一方法」，性能影响微乎其微。灵巧手/前臂总成（超 100 个细小零件）仍依赖较多人工装配。

**关注理由**：这是 10/3 已推「Optimus 量产启动」的关键增量：① V3 定型是供应链开模、批量下单的前置信号，Q4 是产能爬坡验证窗口；② 芯片主动降配的取舍逻辑值得记录——当模型泛化能力成为主瓶颈后，端侧算力边际收益递减，BOM 成本、供应链稳定性和良率成为决定量产的变量，人形机器人正在重演消费电子从工程原型走向规模产品的经典路径。注意特斯拉官方对「量产周期」说法仍未确认，以后续 Q3 业绩会（10/22）为准。
