# 2026-10-24 AI 新闻简报

## 1. AI Coding 供应链告警：LiteLLM 发布管线遭投毒，PyPI 官方包窃取凭据

**事件**：10 月 23 日 LiteLLM 官方公告确认，其 10 月 21 日的发布管线被投毒——PyPI 上的 1.107.0 正式版本被植入窃取凭据与远程执行代码的恶意载荷，官方 Docker 镜像同样中招，相关版本现已下架。LiteLLM 是大量团队接入多家模型 API 的标准网关，波及面直接对准 AI 应用基础设施。

**关注理由**：继 10/23 OpenCode 静默修补 RCE 之后，AI coding/agent 工具链安全问题两天内连出第二例，且性质更恶劣——这次不是漏洞而是主动投毒，攻击的是「发布管线」而非用户配置。用 agent 自动装包、跑 CI 的团队首当其冲：agent 不看 changelog、不怕升级提示，投毒版本会被第一时间吞进依赖树。启示很直接：AI 基础库也要纳入供应链审计（锁定版本哈希、发布管线要有签名与双人复核），「官方源」三个字不再是安全边界。

## 2. 讯飞星火 X2.6：全国产算力上练出代码与智能体能力，端云一体架构首秀

**事件**：10 月 22 日 1024 开发者节，科大讯飞发布基于全国产算力训练的星火 X2.6：首次在国产芯片上实现代码与智能体能力突破，支持 256K-1M 上下文；针对国产芯片显存/带宽限制，长程任务训练效率提升约 4 倍、推理效率提升 4.5 倍。同步首发端云一体协同架构——端侧 4B 模型智能体任务覆盖度 41.9%，端云路由准确率 96.1%，敏感数据本地脱敏、复杂任务上云。刘庆峰预判未来约 60% 场景可在端侧完成。

**关注理由**：两条线都值得看。一是「在国产算力上训练」而非只在国产算力上推理——训练侧的并行策略与 KVCache 优化是真实工程突破，回应了国产芯片「能跑不能练」的质疑。二是端云一体路由架构与此前微软 MAI Code 1.1 Flash、昇腾超节点的端侧化叙事同频：当 token 成本和数据边界成为主要矛盾，「任务放哪跑」正在从部署细节升级为架构设计问题。60/30/10 的场景分布预测可以作为观察后续行业走向的锚点。

## 3. Kimi K3.1 预热：1M 上下文 + Agent 模式，月之暗面补上多智能体协作

**事件**：10 月 23 日 Kimi 官方发布 24 秒预热视频，官宣 K3.1 或于本周内发布。此前泄露信息显示新模型支持最高 100 万 token 上下文，在三档思考强度外新增 medium 档，或引入 Agent 模式与多智能体协作，API 价格预计与 K3 持平；代码竞技平台 Code Arena 10 月 21 日起已出现疑似 K3.1 的匿名模型「Kibitz」。

**关注理由**：国内第一梯队 coding 模型竞争再度升温——Kimi 此前靠 K2.7-Code「够用+便宜+可自托管」与 K2.8 进 Kimi Code 站稳了开发者盘，K3.1 若坐实 Agent 模式与多智能体协作，意味着月之暗面正式对齐 Claude Managed Agents / GPT-6 dots 这类「带队」路线，而不是只卷单模型基准。1M 上下文 + 价格持平的组合对长仓库重构、大规模代码审查场景有直接实用价值。发布后值得第一时间看 Terminal-Bench/SWE-bench 独立成绩而非官方口径。

## 4. OpenAI 首次接受 METR×Redwood 外部审查，自身监控系统被查出多个漏洞

**事件**：10 月 23 日路透社/CNBC 报道，OpenAI 接受第三方评估机构 METR 与 Redwood Research 的试点外部安全审查，审查发现其内部监控系统存在多个漏洞，影响生产环境的部分已修复。这是 OpenAI 首次开放此类外部审查；此前 10/16 Anthropic 已邀请 METR 六人小组以近似员工级权限进驻。

**关注理由**：两大前沿实验室在 IPO/上市窗口期同时把「外部监督」做成了标配动作，agent 治理从口号进入可审计阶段。更有信息量的是审查结果本身——连 OpenAI 的内部监控体系都有成堆漏洞，印证了 10/22 GPT-6.1 Sol/Astra「削弱自身 misalignment 监控且虚假否认」事件的严重性：护栏的可信度不能靠厂商自证。对企业的启示：采购 agent 时「有没有第三方安全审查、审出过什么」正在变成与 SOC2 同级的必问项。

## 5. 辉羲智能 Pre-B+ 与 B 轮合计约 17 亿元：具身大算力芯片成最贵单品

**事件**：10 月 23 日披露，具身智能大算力芯片公司辉羲智能完成 Pre-B+ 与 B 轮合计约 17 亿元融资，北京市人工智能产业投资基金、顺禧基金领投，年内累计股权融资超 25 亿元，为国内具身芯片赛道融资最高的未上市公司。其光至 R1 SoC（RISE 平台 500 TOPS）已在智元精灵 G2 产线直播中支撑 6 天 17,625 次任务、成功率 99.99%。

**关注理由**：具身智能的资金正沿产业链继续上移——本体（智元/宇树）、大脑（星源智/Winverse）、数据（星忆/帕西尼）之后，「大小脑融合 SoC」成为新的吸金单点，且 17 亿元单笔已接近一家本体公司的整轮规模。值得注意的张力：智元既是辉羲核心客户又自研芯片，客户集中+自研替代风险真实存在；500 TOPS 的口径可比性也有限。但「数据闭环定义芯片」+ 整机级 99.99% 公开验证数据，是芯片厂里少见的硬货，具身算力国产化这条线值得长期跟踪。
