# 2026-10-29 AI新闻简报

## 1. [AI Coding] GitHub Universe 2026：Copilot Fusion 自动多模型编排亮相

**事件**：GitHub 于 10/28 在旧金山年度开发者大会 GitHub Universe 2026 上发布 Copilot Fusion——按任务类型（推理/编码/调试）综合计算性能需求与输入成本，自动编排最优模型组合，无需开发者手动切换。官方引 Artificial Analysis 的 AACAI 指标：与 Claude Opus 5.5 Max 相差 2 分以内，成本降一半、单任务耗时降 40%。同场发布 Copilot App（打通规划到完成的全流程 agent 连接）、Copilot Automation（实时监控工作流异常并自主执行预案）、Code Review Max（错误检测增强），并将企业计费改为按实际用量付费的 pay-as-you-go 选项。为支撑 agent 流量，GitHub 今年基建扩至新增 400 万 CPU 核心、160PB 高速存储、50Tb/s 网络带宽。

**关注理由**：这是继 9 月中旬多模型路由成行业标配（Sakana/Devin/Codex）之后，最大平台级玩家的官方定调——模型选型权从开发者手上收走，交给编排层自动调度。微软 Core AI 高管 Jay Parikh 的话点题：「人类迄今写的所有软件，不及未来五年要写的 1%」。对开发者而言，工具链竞争焦点已从「哪个模型最强」转向「谁的编排层调度得最好」；对企业而言，按量计费 + 自动编排组合大幅降低 agent 化改造成本。

## 2. [AI Coding] Cursor 周四发布新一代 Composer：纯编程数据训练的小模型路线

**事件**：据 Economic Times 10/29 报道，Cursor 计划于本周四（10/29）发布新一代自研模型 Composer 2，定位为执行长时程编程任务的 agent。联创 Aman Sanger 透露其核心差异：完全只用编程相关数据训练，从而做出更小、更便宜的模型——「它不会帮你报税，也写不了诗」。Cursor 目前日活超 100 万、企业客户 5 万家（含 Stripe、Figma），正洽谈约 500 亿美元估值的新融资。

**关注理由**：8 月被 SpaceX 收购后（100% 股权、获 Colossus 超算算力），这是 Cursor 自研模型路线的首次集中亮相。在 Anthropic/OpenAI 用通用大模型卷 agent 能力的当口，Cursor 选择「垂直纯化」路线：牺牲通用性换成本与延迟优势。这条路线能否成立，直接检验「coding 专用小模型 + 顶级 harness」对「通用旗舰模型」的替代空间——若 Composer 2 基准站得住，将动摇工具厂商必须依赖前沿实验室模型的假设。

## 3. [AI Coding/安全] AGENTS.md 恶意 Markdown 首次在野劫持 coding agent

**事件**：安全公司 Forever Security 披露首个在野（in-the-wild）利用案例：攻击者在用户下载目录植入恶意 AGENTS.md 等明文文件，coding agent 在该目录启动后将其读取为「项目指令」并照做——改写自身配置、安装恶意 npm 包、窃取登录 token。该攻击链在真实客户机器上被捕获；后续测试中对 OpenAI Codex 攻击成功率超 90%，对 Claude Code 约 50%。研究者明确表示「OpenAI 和 Anthropic 无可修补」——agent 执行目录内指令正是其设计功能。

**关注理由**：这是继 10/16 CyberXero 武器化 Claude Code、10/23 OpenCode RCE、10/24 LiteLLM 投毒之后，agent 攻击面的又一形态升级：从供应链与配置层退回到「信任项目内文件」这一最基础的设计假设。攻击门槛极低（一个文本文件），且无厂商补丁可等——防御责任完全落在用户与组织侧。实操结论：不要在 Downloads 等接收互联网内容的目录里启动 coding agent；企业需对 agent 的目录访问范围做显式白名单。

## 4. [具身智能] Physical Intelligence 洽谈至少 10 亿美元融资，估值逼近 200 亿美元

**事件**：彭博 10/27-28 报道，机器人 AI 公司 Physical Intelligence（π）正洽谈新一轮至少 10 亿美元融资，由现有投资方 Avenir 与 Lux Capital 领投，投后估值约 200 亿美元——较今年早些时候的 115 亿美元接近翻倍，而去年 11 月仅为 56 亿美元。该公司至今零营收、不造本体，专做跨硬件通用机器人「大脑」（pi-zero 系列 VLA）；10/13 已开放 Pi API 测试版，外部开发者上传操作数据、平台负责微调并提供云端推理。投资方含贝索斯、Alphabet CapitalG、Thrive、红杉。

**关注理由**：零收入却拿到具身赛道最高估值之一，资本明确在押「机器人时代的操作系统」卡位。对照同赛道 Skild AI（1 月估值 140 亿，9 月 ARR 破 1 亿美元、60+ 付费客户）——两条路线的分野在收敛：PI 也开始搭数据飞轮（Pi API），商业化答卷窗口正在收窄。叠加本周国内辉羲智能 17 亿融资、智元 500 亿估值，物理 AI 的估值体系已完全脱离传统机器人企业的订单/收入逻辑，需要警惕估值与技术兑现的倒挂风险。

## 5. [具身智能] 阿里高德发布并开源 λ0 全身基座模型：500 小时人类视频替代真机采集

**事件**：10/27，高德联合阿里 Token Hub 事业群发布开放世界全身基座模型 λ0（Lambda Zero），为国内首个基于人类真实行为数据训练的人形全身基座模型。核心是无本体采集管线：采集者佩戴消费级设备（颈挂相机/头显/关节追踪）日常活动即可，机器人本体完全不到场——单条示范采集从约 100 秒压到 29 秒，效率约 3.4 倍。基于 500 小时人类视频（HumanVerse-500 数据集，32993 片段、8700 万姿态帧）训练，在宇树 G1 真机四项任务盲评中完成 25/40（62.5%），超基线 π0.5（40%）22.5 个百分点，七项长程移动操作零样本迁移。硬件配置代码（Apache 2.0）与数据样例已开源，但完整权重与训练数据未放出，模型卡标注「非可部署策略」。

**关注理由**：地图公司切入具身智能，凭的恰是「人类行为数据」这个本命资产。λ0 验证了「人类全身视频越多、真机表现越好」的 Scaling 曲线——若被独立复现，具身训练数据成本曲线将被改写：真机遥操（贵、慢）可能被近乎零边际成本的人类行为录制替代。两点保留：消融实验显示去掉 HumanVerse 中训阶段真机成功率从 62.5% 跌到 22.5%，说明数据确实在起作用，但所有成绩均为自测、尚未第三方复现；且据报道数据集缺少参与者知情同意与伦理审查记录，合规框架需跟进。
