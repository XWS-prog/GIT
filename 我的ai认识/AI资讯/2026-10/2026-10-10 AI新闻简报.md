# 2026-10-10 AI 新闻简报

## 1. [AI Coding] 微软 × 英伟达把 Agent 塞进 PC：MAI Code 1.1 Flash 端侧编程模型 + Execution Containers 沙箱 GA

**事件**：微软 10/7-8 在旧金山举办 Windows & Surface 发布会（10/10 报道持续发酵），与英伟达联手推「混合智能（hybrid intelligence）」架构。核心三件套：① 端侧编程模型 **MAI Code 1.1 Flash**（137B 总参/6.8B 激活，3-bit 量化后约 53GB，SWE-Bench Verified 70.8% vs 云端版 72.6%，64K 上下文下读取超 900 token/s）；② **Microsoft Execution Containers（MXC）正式 GA**——进程/会话/WSL/MicroVM 四级隔离边界，由 OS 而非 Agent 自身执行权限策略，附 Learning mode 自动生成最小权限策略，OpenAI、Anthropic、NVIDIA 官宣接入，GitHub Copilot/Codex/Replit 已支持；③ 新硬件 **Surface Laptop Ultra**（NVIDIA Grace CPU + Blackwell RTX，128GB 统一内存，本地跑 120B+ 模型）。Copilot 将在本月实现本地/云端按任务自动路由（GitHub HydraFusion 承担调度）。

**关注理由**：这是「Agent 运行时」之争的最新一极——此前 Agent 安全治理都发生在云端和 CLI 层（Claude Code 沙箱、OpenAI Agents API），微软直接把治理下沉到操作系统，Nadella 的口号是「让桌面成为 Agent 最安全的执行场所」。与 9/25 英伟达 Open Agent Safety Platform 联盟、10/1 MIT OpenClaw 控制平面同属一条主线：Agent 权限边界正从「模型自觉」转向「平台强制」。另一面是现实约束：内存涨价让本地化变贵（DGX Spark 涨价 75% 至 6,950 美元），分析师直言「软件准备好了，硬件太贵」——端侧 Agent 能否成为主流，价格是最大变数。

## 2. [AI Coding] Google 发布 Gemini agent：给 Agent 发「员工工牌」，Smart Routing 首度官方路由竞品 Claude

**事件**：Google Cloud 10/8 在 Gemini at Work 2026 大会上发布企业级通用 **Gemini agent**（私有预览，预计 10 月底 GA）：单一 Agent 跨 Web/iOS/Android/桌面/命令行/Workspace/Microsoft 365/Slack 执行知识工作、内容创作与编程。两个关键设计：① **Coworker agent（数字同事）**——可拥有独立 Workspace 账号、@agents.company.com 邮箱、日历、目录条目与密码学认证身份，所有操作以 Agent 本身（而非借用人）名义留审计日志；② **Smart Routing 多模型调度**——按任务质量/成本自动在 Gemini 与 Anthropic Claude 之间选模型（后续接入 OpenAI 及开源模型），管理员可设项目级消费上限、超支自动暂停。内存分四类（session/semantic/procedural/episodic），跨设备共享。

**关注理由**：Futurum 的评价切中要害——「把 Agent 从模型里拆出来」比任何单点功能都重要：**Agent 不再绑定某家旗舰模型，而是像服务账号一样可被 IT 部门授权、审计、吊销。**「Agent 有没有独立身份」正在变成企业采购的标准问题（微软 Copilot Autopilot 同月走了同一设计路线）。Google 旗舰产品官方路由竞品 Claude，也坐实了 9/13 推送过的「多模型路由成行业标配」趋势——现在连超大规模厂商都承认单家模型不可能全场景最优。与微软事件合起来看：本周两大巨头把「Agent 治理」从伦理讨论变成了产品 SKU。

## 3. [AI Coding] 腾讯云开源 TeamAI：把团队 Prompt/Skill/规范塞进 Git 仓库，一人配置全员复用

**事件**：10/10 腾讯云宣布开源内部自用工具 **TeamAI**——基于 Git 的团队 AI 协作工具：将团队 Skill、工作规范、工具配置、项目知识统一放入 Git 仓库，像代码一样走分支、合并请求、评审与版本管理；成员 Agent 通过会话启动 Hook 自动拉取更新。已适配 WorkBuddy、CodeBuddy、Claude、Codex、Cursor 等 16 种 Agent，并集成到腾讯云智能体管理平台 ClawPro；新增模型配置统一下发（管理员强制内网任务走合规模型），支持从成员纠正记录中自动沉淀经验文档入仓。

**关注理由**：行业注意力都堆在「单兵 Agent 能力」上，TeamAI 补的是组织层缺口——当每个人都在用自己的 Agent 和 CLAUDE.md/AGENTS.md，团队知识就散落在个人配置里。用 Git 流程管理 AI 配置（评审、回滚、版本化）是个朴素但正确的工程化思路，让「团队级 Agent 标准」像代码规范一样可维护。这也呼应 9/16 已推送的腾讯 teamai-cli、9/25 的 AGENTS.md 标准化等脉络：Agent 生态的下一个战场是共享与治理基建，而非又一个 coding agent。

## 4. [具身智能] 国庆文旅数据揭示分水岭：机器人日租金从万元雪崩至千元以下，「表演经济」退场、「岗位化」登场

**事件**：《科创板日报》10/10 报道：今年国庆近 30 家具身智能企业进入文旅/零售/消费场景，在岗规模达数千台，且职能从「翻跟头跳舞」扩展到卖货收款、导览巡检、门店店长——银河通用 Galbot G1 在景德镇陶溪川流动售卖车担任售货员（太空舱智慧零售已落地约 50 城 200 个点位），智元灵犀在滑雪/香氛门店当「一日店长」。同期机器人租赁「抢租潮」消失，日租金从 2025 年初万元级跌至不足千元（闲鱼宇树人形租赁起步价已见 289 元/天）。配套 IDC 数据：2026 上半年全球人形机器人出货近 2.5 万台、同比 +432.1%，中国超 1.9 万台占 77.9%（智元上半年出货 8600+ 台）。

**关注理由**：两组数据合起来是商业化阶段的清晰信号：租赁价格雪崩 = 供给端产能上来 + 纯表演同质化失灵；而「能上岗」与「能盈利」之间仍隔着重重关卡——百人会张峰判断瓶颈已从**硬件制造转向场景适配与软件能力**，IDC 亦提醒出货统计含科研采购与样机、纯商业化付费订单占比待提升。此前 9/16 已推过 Agility 把安全做成卖点、9/22 推过消费级价格战，本次提供的是需求侧（景区/零售真实排班）与价格侧（租金曲线）的交叉验证：行业叙事正在从「能不能做出来」切换到「能不能在真实岗位回本」。

## 5. [具身智能] 西湖机器人 WR1 完成全球首个灵巧手自主折叠衣物 + 双机协同家务演示，对标 Figure Helix

**事件**：10/9-10 报道，杭州西湖机器人发布通用大脑 **WR1** 升级版，在真实家庭环境完成长链柔性家务：人形机器人从晃动的晾衣架取下长裤（持续抵消扰动）、灵巧手自主折叠 T 恤（官方称全球首个灵巧手自主折衣演示，难于业界常见的折毛巾/浴巾）、与另一台人形机器人实时协同折叠铺展。架构上采用「通用大小脑双预训练」：世界模型 WM + 视觉-语言-动作模型 VLA 统一输出移动/全身姿态/灵巧手操作序列，由自研通用动作大模型 **GAE** 负责高速稳定执行。报道称柔性动态物体处理上实现对 Figure Helix 的超越。

**关注理由**：柔性物体操作（衣物形态随拉扯改变）是家务自动化公认的高壁垒，此前多数公开演示停留在单点技能（抓杯子、折毛巾）；WR1 展示的是「取衣-承托-转移-展开-折叠」的连续任务链 + 多机协同 + 外部扰动下的稳定，任务链长度而非单点精度成为新的竞技维度。值得注意的是国内团队选择与 Figure 正面比较柔性任务——「大小脑双预训练 + 通用动作大模型」的架构叙事，与 9/6 已推送的「资金从本体转向大脑」、10/1 苏度 3D 世界模型等一并看，世界模型 + VLA + 全身控制的耦合路线正在成为国内「大脑」阵营的收敛方向。
