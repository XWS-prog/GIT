# 2026-10-15 AI新闻简报

## 1. Claude Code 桌面版史诗级更新：单会话进化为多 Agent 协作工作台

**事件**：Anthropic 于 10/15 发布 Claude Code 桌面版重大更新（工程师称「几乎是 v2 版本」）：主会话识别可并行任务后自动创建嵌套会话（Nested Session），子会话后台并发跑代码、测试，完成后自动把结果汇总回主线程；新增 /btw 指令在独立标签页开支线对话（完整继承主会话上下文），不打断主线；支持「环境复用」（多目录/SSH/云端配置打包一键拉起）、多会话时每文件夹自动拉独立 Git Worktree 防冲突、空闲压缩（缓存过期前自动压缩上下文省 Token）。同日 Claude Code v2.1.300 对齐 OpenTelemetry GenAI 语义规范，Claude Platform 也开放 OTel 追踪公测。

**关注理由**：AI Coding 竞赛的重心从「单点能力」转向「带队能力」——瓶颈不再是单个 agent 写得多准，而是如何并行推进十个模块还不把工程搞砸。人类角色位移为「批阅奏折的验收者」。这是继 10/10 Managed Agents（API 层千级子 Agent）之后，把多 Agent 编排下放到每个开发者桌面的标志性一步，与 VS Code Agent Host、JetBrains Air 的「IDE 即调度台」路线正面竞争。

## 2. Last Secure Code Benchmark：最强 coding agent「功能+安全」双通过率仅 25.1%

**事件**：10/14 发布的 LSCB 基准（450 个任务、150 个真实漏洞、6 个前沿 agent、7 种语言、24 类 CWE）显示：六个 agent 的功能测试通过率高达 73.6%–91.3%，但「功能+安全」同时通过的最佳成绩（Claude Fable 5）仅 25.1%，其余在 16.4%–24.7% 之间；仓库级 SusVibes 数据下最佳结果仅约 11.8%。关键设定：任务描述只提功能、只字不提安全——精确复刻真实 vibe coding 场景。Veracode 春季报告交叉印证：150+ 模型的安全通过率两年停在约 55%，XSS 约 15%、日志注入约 13%。

**关注理由**：「代码能跑」和「代码能上线」之间的缺口首次被量化得这么难看——大部分失败不是代码写错，而是漏洞随功能一起交付。作者强调测的是默认行为：明确写出安全要求+自动评审环节后表现会显著改善。结论落在流程而非换模型：提示词写明安全要求、按真实失败类别做测试、每个新依赖过审、diff 处保留人工门禁。对任何在用 coding agent 的团队都是一张必读的风险清单。

## 3. EmbodiedEvo：自进化 Coding Agent 登顶具身珠峰 RoboDojo

**事件**：Einsia AI 旗下 Navers Lab 于 10/15 发布 EmbodiedEvo（arXiv 2610.18867）：Agent 用 Python 程序控制机器人（仅 get_instruction / get_observation / step / reset 四个原语），每个任务先在一个 Playground 场景里边交互边探索，把验证过的操作沉淀为带参数的代码 Skills 和文字 Lessons，随后 harness 冻结交给新 Agent 在未见场景评估——全程不更新模型权重。在被称为「具身智能界珠穆朗玛峰」的 RoboDojo 评测中取得 45.08 平均分、38.95% 成功率，超过所有 VLA/WAM、Agent、Agent+VLA 方法。

**关注理由**：这是「AI coding」与「具身智能」两条关注线的正交点：前沿 coding agent 的 zero-shot 操控能力已与专门训练过的 VLA 相当，而「探索期经验冻结复用」让 Agent 像积累代码库一样积累身体技能——不重训模型、成本可控、经验可迁移。若该范式在真机上成立，「大脑」侧的迭代速度可能被 coding agent 生态直接接管，改变当前 VLA 路线与数据收集逻辑的竞争格局。

## 4. 智元新一轮融资 10–15 亿元、估值约 500 亿：IPO 或推迟到 2027 年

**事件**：10/15 财联社/红星资本局报道，智元创新启动新一轮融资（10–15 亿元，接近收尾，投后估值约 500 亿）。按港交所规则，递表后、上市前完成新融资，除非获特殊豁免，需等最后一笔融资完成后满 120 日方可挂牌——这意味着智元今年内或无法完成 IPO，最早 2027 年 2 月底。背景：证监会已向投行下发非正式「窗口指导」，提高人形机器人企业上市门槛，重点核查订单与收入真实性；上交所对云深处的首轮问询直接追问业绩可持续性。

**关注理由**：具身智能 IPO 梯队正在分化——宇树已上市，云深处/乐聚在问询，星海图/逐际动力保密递表，而估值最高的智元反而被新融资拖慢节奏。两条信号值得跟踪：一是监管从「鼓励」转向「验真」，订单收入真实性成为审核核心，裸奔的 Demo 公司将无法套现离场；二是「边融资边上市」与交易所规则的冲突，可能成为所有冲刺港股的具身公司的共同约束。

## 5. 若愚科技亿元级 Pre-A 轮：「大脑」融资向高危场景纵深

**事件**：10/15 宣布完成亿元级 Pre-A 轮，信维通信领投（金木资本、勤道资本等跟投），哈工大（深圳）孵化。资金重点投入「九天」机器人大脑迭代。路线是反「通用场景卷参数」：从加油机器人、港口复杂作业等高危高价值场景切入，倒逼大脑在动态干扰、突发工况下成长，形成「大脑—本体—场景数据」闭环；已入选深圳市「机器人+」应用示范案例，前奥比中光高级副总裁江隆业加入任 COO 补产业化短板。

**关注理由**：机器人大脑赛道已出现「港股第一股」（仙工智能），但多数团队仍在通用场景卷 benchmark；若愚选择「从最难啃的场景反推通用能力」的窄门路线，与 10/14 DeepSeek 领投 Winverse（不做本体专注大脑）共同印证：具身智能的资金正持续向「大脑」层集中，且开始按场景纵深分层定价。产业资本（信维通信）领投也说明下游硬件厂商在抢占具身入口。
