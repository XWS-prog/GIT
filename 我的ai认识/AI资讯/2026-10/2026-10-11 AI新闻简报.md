# 2026-10-11 AI 新闻简报

## 1. [AI Coding] Claude Managed Agents 动态工作流公测：单次并行调度 1000 个子 Agent

**事件**：10 月 10 日 Anthropic 宣布 Claude Managed Agents 动态工作流开启公测——主 Agent 接到任务后自主编写分工程序，把大任务拆解后分发给并行工作的下级 Agent，最多可同时调度 1000 个子 Agent，再汇总结果。实测数据：在 11.6 万行代码中预埋 70 个 Bug，单 Agent 三次运行最好只找出 27 个，动态工作流三次均稳定找出 66 个（90%+）。同日 Claude Code Projects 扩大公测，所有等待名单中的 Pro/Max 用户均已获得资格。

**关注理由**：多智能体编排从「Demo 协作」正式跨入「规模化生产调度」，千级并行意味着全库重构、批量代码审计这类原本需要人工编排数天的任务可压缩进一次调度。单 Agent vs 组队 27:66 的对比也给「多 Agent 到底有没有用」提供了首个干净的量化答案。编排层价值正在逼近传统分布式系统的调度器，这是继 Cursor Projects、Gemini coworker 之后又一家巨头把「分活、盯进度、交接」产品化。

## 2. [AI Coding] Cockroach Labs「教学医院」流水线：5 个月让 Agent 合并 1238 个 PR、100 万行代码

**事件**：数据库公司 Cockroach Labs 公开其运行五个月的 MOLT Sinai 流水线：把 GitHub Issue 当「病人」，Agent 分饰 Fellows（写修复）、Review Attending（找错）、Discharge Nurse（合并前审计）等角色，人类只做最终裁决。4-9 月共合并约 1238 个 PR、超 100 万行，仅 7 次 revert，Token 成本约 13.5 万美元（每 Issue 约 84 美元）；为 Db2 提供支持只花 2 天/4172 美元（2024 年为 Oracle 写支持用了约 9 个月）。

**关注理由**：这是目前披露最完整的企业级 coding agent 生产环境运营数据——不是 benchmark，而是带 revert 率、单位成本、失败模式的真实账本。其踩坑经验极有价值：流程曾变得官僚化（需要三轮返工断路器）、评审 Agent 会接受执行 Agent 的借口放水、正确性必须做成机器可校验。对任何想在公司内部落地 agent 工程团队的团队，这几乎是免费的作业模板。

## 3. [AI Coding] Harness 收购 Augment Code 核心资产，推出 Cosmos「软件工厂 Agent」

**事件**：10 月 8 日，软件交付平台 Harness 宣布收购 Augment Code 的精选资产（Cosmos「软件工厂」、Auggie CLI、Code Context Engine 及团队）。Cosmos 定位「从想法到代码」的自动化工厂：工单/缺陷/PR/Webhook 事件即可触发一支 agent 舰队，各自在隔离 VM 中规划、写码、测试、开 PR，收到评审意见或检查失败会在同一 PR 上自动修复，直至产出「可合并的 PR」，再交由 Harness 既有的交付/安全/成本 agent 推进到生产。

**关注理由**：这是 coding agent 从「单点代码补全」走向「端到端 SDLC 自治」的标志性整合——卖点已从「生成了多少代码」转为「有多少有价值的软件真正抵达生产」（Harness CEO 原话）。Augment 的代码上下文引擎与交付知识图谱打通后，测试/安全/部署约束在写代码前就进入上下文。行业价值重心正从模型能力下沉到 harness、运行时与「代码上下文 × 交付上下文」的闭环，与 Cursor 收购 Firetiger/Continue 是同一主线。

## 4. [具身智能] Hexagon 拟向舍弗勒部署 1000 台人形机器人；Simplexity 单臂看护双 CNC 仅用 600 条真实轨迹

**事件**：Machine Dawn 10/10 汇编：Hexagon 计划向 Schaeffler（舍弗勒）制造设施部署 1000 台人形机器人，且强调「非简单复制、需现场逐场适配」；IROS 2026 上 Simplexity Robotics 用单台机器人同时看护两台 CNC 车床，以 0.5 毫米间隙插装零件，训练仅用 600 条真实轨迹。同期 The Robot Report 刊文直言：人形演示常无法泛化到真实工况，从 demo 到可靠劳动缺的是更好的数据与人的判断。

**关注理由**：行业正从「能走能跳」转向「能稳定干活」，两条落地范式首次同时摆上桌面——「千台级规模部署但需逐场适配」与「少量真实轨迹即达工业精度」。结合研究与产业侧共识（灵巧操作与泛化是 physical AI 真实约束），能解决「适配成本」与「数据闭环」的环节（柔性夹具、触觉传感、仿真与数据平台）比单纯本体厂更具确定性。

## 5. [具身智能] 关节模组赛道进入「交付能力竞赛」：酷灵天使轮 + 头部厂商十万台级出货

**事件**：南京酷灵机器人完成数千万元天使轮（百联挚高资本独家投资），主打关节热管理系统（六大散热方案解决小体积高功率密度关节热积累与扭矩衰减），客户涵盖上市公司、独角兽与军工集团。同期行业数据显示：泉智博 2025 年关节模组出货破 10 万台、产线节拍 90 秒/套；因克斯第二代快拆液冷关节 2025 年出货亦破十万台；天机智能 MEMS 关节扭矩传感器 4 个月交付力控双臂超 2000 台。华创证券判断：具身智能正从「技术参数竞赛」进入「交付能力竞赛」。

**关注理由**：本体的热闹（乐园、门店、巡检）之下，上游零部件先完成了从「能不能做」到「能不能百万台级稳定交付」的跨越。散热是当前人形机器人最被低估的工程瓶颈之一（宇树 G1+ 也在主打发热 -72%），关节热管理专精公司拿到机构独家投资，说明资本开始沿「卖铲人」逻辑下沉。看具身投资，上游模组的出货量与良率比整机融资额更诚实。
