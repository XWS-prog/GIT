# 2026-10-23 AI 新闻简报

## 1. GPT-5.6 Sol 挖出 PHP 两大高危 RCE 漏洞，波及十余年版本

**事件**：OpenAI「Patch the Planet」计划中，GPT-5.6 Sol 发现 PHP 两个未认证远程代码执行漏洞「PHP2Shell」（CVSS v4.0 评分 9.2），涉及内存管理与错误处理，影响 PHP 5.4 至 8.5 十余年版本；Wiz 独立发现了同一问题。PHP 官方已于 10 月 21 日发布 8.5.12 等四个安全更新。披露前一天消息泄露，CISA、NSA 等发布紧急警告，维基媒体及《赛马娘》等多款日本游戏一度停服。

**关注理由**：前沿模型做漏洞挖掘从「演示」进入「实战刚需」——一次发现覆盖十余年历史版本的通用型 RCE，且与头部安全厂商结论交叉验证。对普通运维的启示是：AI 挖洞的披露节奏远快于传统补丁周期，消息泄露到官方警告只有一天，「AI 发现→全球紧急响应」将成为常态流程。与此前 OpenAI 6 天产出 $250K Chrome 全链 exploit 是同一趋势的两面：攻击面与防御面同时被 AI 加速。

## 2. OpenCode 严重 RCE 以「重构」名义修补、不申请 CVE：安全工具链出现盲区

**事件**：Pillar Security 披露，开源 AI coding agent OpenCode（约 300 万周 npm 下载、211k GitHub Star）存在 CVSS 9.8 级 RCE：Windows/WSL 上远程 MCP 服务器在 OAuth 握手时通过 discovery doc 中的 `authorization_endpoint` 字段注入 PowerShell 命令，无需用户交互、无需模型配合（非 prompt injection）。官方 9 月 28 日把修复混进一次「浏览器启动代码重构」提交，未发安全公告、未申请 CVE——所有 <1.18.33 的安装无任何告警提示。

**关注理由**：这是 AI coding 工具链的第一个结构性安全问题样本：MCP 让 agent 天然信任远程服务器，而「不打 CVE 的静默修复」让漏洞扫描器、依赖告警、SBOM 全部失明。约 300 万周下载的用户至今收不到升级提示。给所有用 coding agent 的人提了醒：MCP server 配置等同于给 shell 执行权，选型时要把「厂商是否规范披露 CVE」纳入评估，而非只看 Star 数。

## 3. 腾讯混元×复旦 WorkForge：1.67 万个真实职场环境，小模型反超大模型

**事件**：腾讯混元联合复旦大学提出 WorkForge 框架，按专家蓝图从真实代码仓库、数据集和网页搭建工作区，结合程序化检查与 LLM 语义评分核验。WorkForge-16K 含 16,665 个环境，覆盖 40 个专业领域、60 种文件类型，单条轨迹平均约 7.6 万 tokens。训练后 WorkForge-A3B 的 GDPval 从 45.5 升至 73.6，WorkForge-27B 达 82.4，超过 397B-A17B 大模型的 79.7。

**关注理由**：继 OpenAI、DeepSeek 之后，国内团队也在重仓「Agent 训练环境基建」——真实任务环境数量与质量正成为 coding agent 能力的决定性变量，而非模型参数量。27B 环境特训模型反超 397B 通用模型，进一步印证「数据/环境 > 规模」路线在 agentic 任务上的有效性。对做 agent 评测和训练的团队，这套「专家蓝图 + 程序化核验」的环境构造方法是可直接借鉴的工程范式。

## 4. 智元开源首个真实场景 Physical Agent 数据集：任务设计从「操作难度」转向「决策难度」

**事件**：10 月 22 日，智元开源 AGIBOT WORLD 2026 第四期「具身推理」（Physical Reasoning）数据集——行业首个真实场景 Physical Agent 数据集。围绕物品数量、遮挡关系、位置占用、任务进度四类因素，采集同一任务在不同状态与约束下的决策与执行过程，覆盖九类核心推理能力（前置条件推理、长程规划、记忆状态维护等），按 Easy/Medium/Hard 分级，提供高层问答与低层动作轨迹配对。已用于智元即将推出的 Agent 框架与新一代基座大模型训练。

**关注理由**：具身数据集的演进方向信号明确：从「教会机器人照着做」转向「教会机器人看情况做」。真实任务没有标准答案（如「补货到 3 瓶」的步骤取决于现场空满瓶数量），这类决策型数据是真机数据训练场造不出来的，属于新的稀缺资源。智元同步预告 Agent 框架与新基座模型，后续 AI WAVE 系列发布值得跟踪——本体厂商正在把「数据优势」转化为「模型叙事」。

## 5. 星忆智能连续完成种子轮及种子+轮数千万元融资：手部姿态数据成具身基建单品

**事件**：北京具身智能数据基础设施公司星忆智能（2024 年成立，清华计算机系孵化）宣布完成数千万元种子轮及种子+轮连续融资：种子轮顺禧基金领投，种子+轮凌云光领投、中关村资本与一创投资跟投。创始人宋知珩曾任智元全尺寸双足人形整机产品负责人，负责数采与遥操体系。核心产品为 EgoKit 头戴式多模态采集系统（第一视角视觉+触觉+姿态，含手部姿态识别）与 HBR Engine 自动清洗/标注/质量评估引擎，合作方含清华、港大、字节跳动、中国信通院、智元。

**关注理由**：融资虽小，赛道信号清晰：数据基建正沿「采集硬件」环节进一步细分——继动捕服、遥操设备之后，「手部姿态理解」这种单点技术被拆出来做成了公司。前智元整机负责人出来做数据而非做本体，与此前「资金从本体转向大脑/数据」的趋势一致；第一视角人手操作数据也是 hand manipulation 类任务（当前 VLA 最短板之一）的针对性供给。
