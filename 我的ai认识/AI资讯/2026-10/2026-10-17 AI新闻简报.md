# 2026-10-17 AI 新闻简报

## 1. OpenCode 2.0 稳定版发布：一次「重大改造」，1.x 插件全线报废

**事件**：斩获 21.4 万 Star 的开源编程 Agent 领跑者 OpenCode 正式发布 2.0 稳定版，技术栈从 Bun/Tauri 全面转向 Node.js/Electron，插件架构与服务器 API 整套重写——1.x 时代的插件和基于旧版 API 的集成全部无法兼容，需要重写。同时更新改为手动升级、不再静默安装。官方称新系统吸收了「数百万日活用户」的使用经验。

**关注理由**：这是继 Codex CLI 静默安装后台守护进程（10/13）之后，又一开源编程 Agent 在「运行时与更新治理」上做激进决策的案例——宁可报废整个插件生态也要换底座，说明 agent 对运行时稳定性、热重载、多 agent 扩展的需求已经压过了向后兼容。AI 编程工具正式进入「硬核运行时竞争」阶段，选型时插件的存活率成了真实成本。

## 2. Reflection AI 开源 Beam 501B 权重：西方前沿规模模型首次挂 Apache 2.0

**事件**：Reflection AI 于 10/16 将 501B（激活 23B）MoE 编程/agent 模型 Beam 的权重上传 Hugging Face，采用 Apache 2.0 协议——今年西方实验室对前沿规模开源模型给出的最宽松条款，无用户量上限、无署名条款、无下游训练限制，附 tokenizer、参考实现和 agent harness。10/17 OpenCode 宣布免费接入 Beam（Terminal-Bench 2.1 80.1%）与智谱 GLM 5.3 Flash，后者公布数小时 X 浏览量破 192 万。

**关注理由**：开源权重之争的焦点已从参数规模转向「许可条款 + 能否装进你自己的硬件」。Meta 前一天还在用带条件的社区协议发模型，规模小得多的 Reflection 反手甩出零条件 Apache 2.0——这是算力买不过大厂的小实验室的便宜竞争杠杆，也会倒逼前沿实验室解释「为什么你的开源还要留作业」。对自托管团队，法律审查成本直接归零。

## 3. DeepMind：四个 Gemini 4 Argon Agent 全自动通关 Minecraft（27 小时 14 分钟）

**事件**：Google DeepMind 10/17 宣布，四台 Gemini 4 Argon agent 在随机生存种子下从零通关 Minecraft、击败末影龙，全程 27 小时 14 分钟无人类协助。Agent 只用标准 Mineflayer API、代码执行和文本聊天，自主分工协作，共编写并调试 2,783 个 JavaScript 程序，跨 605 次死亡互相恢复队友物品。同期 Argon 还刷新了 WANDR 基准纪录并上线 Perplexity Pro/Max。

**关注理由**：多 agent 长时程协作的标志性演示——605 次死亡后的物品恢复与 2,783 个程序的自我调试，考验的是持久记忆、角色分工和失败恢复，而这正是企业级 agent 舰队（Claude Managed Agents 千级子 agent、Codex 并行舰队）最缺的工程能力证据。游戏环境正在成为 agent 协作能力的低成本试验场。

## 4. 乐聚×兆丰：15 台人形机器人产线常态化作业，「作业即采集」数据飞轮跑通

**事件**：乐聚机器人与兆丰机电 10/15-16 联合发布「具身智能+汽车零部件上料解决方案」：15 台人形机器人在真实汽车零部件产线连续无故障运行超 2 个月（约 1000 小时），一次上料循环稳定控制在 40 秒内、成功率 98%，已协助生产超 6 万个零部件。配套体系把上料技能拆成 30 余个可拼装模块（开发周期从数月缩到数周），并构建「作业即采集→质量分类→模型迭代→成功率提升」的数据回流闭环，单月采集超 4 万条真实工业数据，失败样本也按用途归档。

**关注理由**：人形机器人从「试点验证」到「常态化作业」的关键跨越，而真正的看点在数据侧——实验室和仿真造不出来的异常工况、边缘场景，只有产线天天跑才有；把数据采集融进生产流程而非单独排产，是当前「数据稀缺」瓶颈下最扎实的解法。这套可复制体系若在更多工厂推广，真实工业数据会成为中国具身模型迭代的护城河。

## 5. 法奥机器人连续完成 C+、D 两轮融资近 10 亿元，美团系领投

**事件**：法奥机器人 10/16 宣布连续完成 C+ 轮及 D 轮融资，累计近 10 亿元人民币，分别由美团龙珠和美团领投，永鑫资本、苏创投等跟投，老股东继续追加。资金用于核心零部件产能固投及工业具身智能扩产研发（ART 系列工业级人形力控臂、AIRLab 具身智能工具平台）。公司预计 2026 年全球订单销量 18000 台、同比增长 68%，海外销量同比增 87%。

**关注理由**：融资方向从「人形本体叙事」进一步向「工业具身智能+核心零部件产能」收敛——拿到钱的第一用途是产能固投而非研发烧钱，说明协作机器人出身的厂商在用已有出货量（1.8 万台订单）换资本。美团系同时押注「大脑」类公司（Winverse）和力控臂本体，平台资本正在具身产业链上下两头同时布子。
