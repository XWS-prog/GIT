# 2026-10-05 AI 领域动态（AI Coding + 具身智能）

> 筛选当日及近两日高价值动态，侧重 AI Coding 与具身智能，避免与 10/01、10/03 已推送内容重复。

## 1. [AI Coding] JetBrains 开放 Air：IDE 从编辑器变成多智能体调度台

**事件**  
10 月 1 日起，JetBrains 在 2026.3 EAP 中向 IntelliJ IDEA、PyCharm、WebStorm、GoLand 等主流 IDE 开放 Air——**一个可同时托管多个编码智能体的插件层**。官方称这是「26 年历史上最重要的几步之一」。Air 支持基于 Git worktree 的并行智能体、ACP（Agent Client Protocol）协议接入，并配套推出免费的 Junie Lite 档位。

**关注理由**  
编码智能体的竞争重心正从「会写代码」挪到「会编排、会验收」。*JetBrains 把调度台直接做进 IDE，意味着传统 IDE 厂商不再只*做编辑器，而是变成多 agent 的运行时底座。这与 Cursor 的云智能体、**VS Code Agent Host**（9/17 已推）形成同方向呼应——「agent 编排层」正成为新的必争入口。对开发者而言，多 agent 并行 + worktree 隔离会直接改变大代码库重构的工作流。

## 2. [AI Coding] Cursor 收购 Continue：开源 BYO-Model coding agent 的商业化归宿与数据主权风险

**事件**  
Continue 官网 10/02 变更为「已被 Cursor 收购」公告，承诺开源代码库（Apache-2.0）保持自由可用、仓库不归档（当日仍有提交）。Continue 曾是 VS Code / JetBrains 中「自带模型」（BYO-Model）coding agent 的事实标准答案，受数据驻留约束的银行、国防、医疗团队靠它把源码留在自有基础设施内。收购后其托管账户层（订阅）前景不明，社区提示：纯自托管用户可维护 fork，但依赖 Continue 云端账户系统的部分需优先审计。

**关注理由**  
这是开源 coding agent 商业化归宿的一个样本——代码开源不等于服务延续，「代码留、服务并」是常态。对受数据主权约束的企业，BYO-model 路线的长期路线图不确定性上升，呼应 9 月智谱 ZCode 数据主权事件：工具链集中化与开源治理，是 coding agent 采用决策中必须前置评估的维度。SpaceX 全资控股 Cursor（6 月）后模型路线向 OpenAI 收敛（11/12 OpenAI 模型将离开 Cursor），更强化了这一趋势。

## 3. [AI Coding] Qodo 3.0：把分散 PR 收成「评审工作包」，评审/验证成新瓶颈

**事件**  
Qodo 发布 3.0，核心是把团队里零散的 PR、评审意见、规则收敛成统一的「评审工作包」（Review Workload），把质量规则前置到编码阶段，并支持私有化与气隙（air-gapped）部署。同日行业观察指出，编码 agent 跑通「写代码」后，瓶颈已转移到「评审与验证」——谁来验收 agent 产出的大量 diff。

**关注理由**  
与 Anthropic 披露 Claude 承担 80% 代码（9/15）、Cursor 推出 Rollouts 生产监控（9/25）同一脉络：coding agent 的价值链正从「生成」延伸到「验收」。当 agent 单日产出数十个 PR，人类评审成为 throughput 天花板，围绕 PR Triage、评审编排、私有化合规的工具会成为下一波重点。评审环节的工程化与治理，是 2026 下半年 coding agent 落地的真实卡点。

## 4. [具身智能] 传化集团开放 300 个产业场景 + 首年 3 亿订单「养」具身智能

**事件**  
10 月 5 日报道，传化集团（成立 40 年的制造业龙头，业务含化工、智慧物流、科技农业）在场景开放与 AI 共创生态大会上宣布：全面开放 300 多个产业场景，首年投入不少于 3 亿元 AI 与数字化订单，通过「揭榜挂帅」推动技术跑在产线上；成立浙江传化具身智能科技有限公司做二次开发，并设「体外孵化、体内赋能」平台。开放的四块「试验田」为化工厂区、科技城园区、谢径安农业、物流园区。背景是 6 月工信部、国资委联合启动 2026 年度人形机器人与具身智能实景实训专项行动（年底形成百个以上高价值场景、万台级落地能力）。

**关注理由**  
行业正走过「秀肌肉」展示期，进入「能干活、算得清账」的商业化验证阶段。传化的信号在于：制造业龙头把自有真实场景 + 订单 + 资本打包成「训练土壤」，直击具身智能「不缺技术、缺能试错的场景」的核心瓶颈。这与宇树王兴兴「泛化能力不足是最大瓶颈」的判断互相印证，也说明「实景实训—数据沉淀—产品迭代—规模部署」的闭环开始有制度性力量（两部门专项行动）与产业资本共同推动。

## 5. [具身智能] 宇树发布 UnifoLM-WLA-1.0 全身 VLA 基础模型

**事件**  
10 月 4 日行业日报披露，宇树发布 UnifoLM-WLA-1.0——全身（whole-body）VLA 基础模型，约 6B 参数，覆盖 64 项任务，基于 2500 小时真机数据训练。这是宇树从本体厂商向「本体 + 大脑」一体化延伸的标志性动作。

**关注理由**  
具身智能的竞争正从「运动能力」转向「通用操作大脑」。宇树作为出货量领先（9 月已上市、占全球约 31%）的本体厂商，亲自下场做全身 VLA，意味着头部玩家不再满足于卖硬件，而是要把数据飞轮和模型能力攥在自己手里。2500 小时真机数据 + 6B 规模， indicator 了「数据—模型—本体」全栈闭环成为主流叙事（此前超维动力、智元 AGIBOT WORLD 数据集已铺垫此趋势）。对行业而言，本体厂商自研大脑会进一步抬高纯「机器人大脑」创业公司的差异化门槛。
