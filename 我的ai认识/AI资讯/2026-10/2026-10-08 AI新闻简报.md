# 2026-10-08 AI 领域动态（AI Coding + 具身智能）

## 1. [AI Coding] 微软亚洲研究院开源 Agent Lightning v1.0：直接在「真实 harness」上做 Agent 强化学习

**事件**
10 月 7 日，微软亚洲研究院开源 Agent Lightning v1.0（约 3500 行代码），提出「Harnessed Agentic RL」训练范式：不再要求开发者把 agent 搬进 verl/AReaL 等训练框架里重写一遍，而是通过一个 OpenAI 兼容代理层插在 agent 与模型之间，**记录 mini-SWE-agent、OpenHands、OpenCode、Claude Code、Codex 等现有 harness 的真实调用轨迹直接用于训练**。rollout 以标准 Kubernetes Job 运行（自建/云/本地集群均可），并支持 rollout 与模型更新共享 GPU 的 Collocated Async RL（端到端速度约为同步 RL 的 2 倍）。实测：Qwen3.5-9B 在 SWE-bench Verified 上 Pass@1 从 41.8% 提到 56.4%，仅用约 6000 条开源训练样本。

**关注理由**
「训练的 agent ≠ 部署的 agent」是 agent RL 的老问题——在训练环境里重写的交互循环，与线上真实 harness 行为不一致，练出来的能力上线就打折。Agent Lightning 把难度转移到 trainer 侧（只看 request/response 对，需处理 rollout 拆分、重分词、优势偏差等四个新问题），换来的是零改动接入生产 agent。更重要的是它把「任务级微调」的门槛打到中小团队可用：不用大算力、不用付费沙箱（Modal/E2B），一个 K8s 集群 + 能给任务打分就能跑。独立复现与 GPU 成本数据尚未披露，是下一步验证点。

## 2. [AI Coding] Kubernetes 两位缔造者推出 Mecatl：把 coding agent harness 重造成「云原生应用」

**事件**
Latent Space 10 月 7 日刊出对 Stacklok 创始人 Craig McLuckie 与 Joe Beda（Kubernetes 联合缔造者）的专访。Stacklok（2023 年 1750 万美元 A 轮，Accel/Madrona/Bain）已从软件供应链安全转向 agent 基建，6 月起开源云原生 harness Mecatl：把 agent loop 与客户端、模型供应商、状态存储、执行环境解耦——工具调用、bash、会话状态和记忆从「本地 JSONL 文件」挪进可治理的系统。配套 ToolHive（MCP 服务器治理网关/注册表/Operator）与未开源的 AI Gateway（访问控制、预算、路由，客户多为银行/半导体/电信）。Beda 类比：企业里的 agent 交互应当像邮件一样归组织治理；「lift and shift」进 VM/容器解决不了 agent 生命周期与安全静默（quiescing）问题，必须从零重造。

**关注理由**
这是「agent 编排层」竞争中一个新物种：JetBrains Air（10/05 已推）、VS Code Agent Host 做的是 IDE 侧多 agent 调度，Mecatl 直接把 Kubernetes 的控制循环（保活、故障恢复、暂停迁移）引入 agent 运行时——前提恰是会话状态外置，这也是它拆解得最实的部分。其核心卖点是帮企业降低对前沿实验室桌面工具（Codex/Claude Code/Copilot）的依赖，正如当年 K8s 对抗云厂商锁定。若「K8s 之于容器」的类比成立，agent harness 的云原生化是 2027 年企业级落地的关键基建，值得早期跟进其开源仓库。

## 3. [具身智能] The Information：英伟达拟再向 Figure 追加 10 亿美元投资，投前估值 380 亿美元

**事件**
10 月 7 日 The Information 援引知情人士报道，英伟达就向人形机器人公司 Figure 追加约 10 亿美元投资展开讨论，投前估值约 380 亿美元（一年前同估值融了超 10 亿美元，英伟达当时已参投 C 轮）。同一报道披露英伟达下一阶段投资重心集中于人形机器人、自动驾驶与端侧 AI 模型（含扶持 Nemotron 生态，如 60 亿美元换 Poolside 许可与团队）。背景：截至 7 月的六个月内英伟达三家客户贡献 44% 销售额，黄仁勋借近 990 亿美元现金与证券推动「数千模型」生态以对冲客户集中风险。

**关注理由**
英伟达在具身智能上「财务投资 + 核心供应商」双重身份的飞轮逻辑清晰：模型在 Vera Rubin 上训练、在 Isaac Sim 验证、部署回机器人里的英伟达 GPU。Figure 已是物理 AI 生态最大单笔押注，若此轮落地将进一步坐实「物理 AI 是英伟达下一增长曲线」的叙事。对国内产业链的参考意义：巨头资本正沿「本体 → 大脑 → 数据」全链路卡位，国产供应链（执行器、减速器、灵巧手）在 Optimus 之外又多了一个潜在放量出口。注意此为匿名信源报道，交易尚未官宣。

## 4. [具身智能] 优必选 × 一汽-大众战略合作：人形机器人从质检实训扩展到物流场景

**事件**
10 月 8 日优必选官宣与一汽-大众达成战略合作，联合开展具身智能人形机器人在物流场景的应用开发与测试，共建示范场景并推广面向制造业的整体方案。此前 Walker S Lite 已进入一汽-大众青岛国家级智能制造示范工厂做车辆质检实训，与工厂自动化控制系统对接；此次合作将范围从质检正式扩展至物流（整车制造中劳动最密集、最重复的环节之一）。产能侧，柳州万台级超级工厂 9/12 已投产（9/13 日报已推），2025 年优必选全尺寸人形收入 8.2 亿元、销量 1079 台，均列全球第一。

**关注理由**
车企是人形机器人最早的真实雇主（此前已推比亚迪/富士康实训、丰田 40 万台计划）。一汽-大众合作的增量在于「任务面扩展」：同一本体平台在一家工厂内从质检延伸到物流，是检验人形机器人单平台任务覆盖度（task coverage）最清晰的对照实验——这直接决定客户按「台」还是按「工位」计价。结合柳州工厂「用机器人造机器人」的产能爬坡，优必选正同时验证供给侧规模化与需求侧场景纵深，是观察 2026 下半年人形机器人商业化的核心样本。

## 5. [具身智能·补推] AMD 82 亿美元全股票收购李飞飞 World Labs，李飞飞出任 EVP 兼首席科学家

**事件**
9 月 28 日 AMD 宣布以约 82 亿美元（约 550 亿元人民币）全股票收购李飞飞联合创办的空间智能公司 World Labs（此前日报未推送，10 月初分析报道密集发酵，补推）。李飞飞将任执行副总裁兼首席科学家、直接向苏姿丰汇报，联合创始人 Justin Johnson、Ben Mildenhall 继续带队；约 70 人团队（含 7 月收购机器人仿真公司 SceniX 并入的成员）。World Labs 核心为世界模型 Atlas 与 Marble 平台（少量照片生成可仿真导入的 3D 场景）；2024 年估值 10 亿美元、2026 年 2 月融资谈判口径约 50 亿美元，本次对价溢价超六成，为 AMD 史上第二大收购（仅次于赛灵思）。

**关注理由**
两周内英伟达 129 亿美元收 Hugging Face、AMD 82 亿美元收 World Labs——芯片巨头用资本买「AI 下一层」的竞争已经摊牌。AMD 买的是空间智能/世界模型与物理 AI 前瞻能力：世界模型是具身智能的仿真训练与数据引擎，与 AMD GPU 软硬协同后直接对标英伟达 Cosmos + Isaac 链路。行业含义有二：其一，世界模型赛道获硬件巨头定价确认（成立两年、70 人、80 亿美元）；其二，模型公司深度绑定芯片/硬件厂商成为新常态，独立世界模型/仿真公司的窗口正在收窄。国内对标（智谱/生数/苏度 R1 等）的资本化路径值得持续观察。
