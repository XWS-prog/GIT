## 1. Claude Code v2.1.238：内置 "Concise" 输出 + 长会话内存泄漏修复 + MCP 凭证隔离

**事件**  
Anthropic 8/20 连发三个小版本（v2.1.236 / 237 / 238）。v2.1.237 新增内置 "Concise" 输出风格（直出结果、省略叙述与铺垫）；v2.1.238 为本周最大发布（约 40 项改动）：修复长会话无界内存增长（+subagent 结果滚出显示窗口后即释放）、新增 `keybindingFlavor=readline`（Ctrl+W 像 Bash 一样按空白边界删词）、self-hosted runner 支持 `--defer-shutdown` 宽限期与按连接刷新的代理鉴权、MCP `headersHelper` trust gate 与凭证隔离强化。

**关注理由**  
Coding agent 正从"开发者玩具"走向"生产 / 自托管基础设施"。内存泄漏修复、自托管 runner 运维选项、MCP 凭证隔离三条线都指向同一趋势——团队开始把 agent 当长期运行的进程部署在自己机器或内网代理后面，稳定性与安全性成为下一轮竞争的硬指标。

## 2. OpenAI Codex CLI 0.149.0 + GitLab 支持 + 异步消息：跨出 GitHub、agent 可"边等答案边干活"

**事件**  
Codex CLI 0.149.0（8 月下旬）新增 Codex Cloud 的 GitLab 支持（Beta）：连接 GitLab 项目、从 issue / MR 用 `@codex` 启动任务、自动 MR review；桌面端支持共享只读线程快照。另据 The New Stack，Codex 加入异步消息能力——agent 向开发者提问后无需阻塞，可继续推进无关子任务，消除"等输入"造成的双向空闲。

**关注理由**  
编码 agent 的平台绑定正在松动，Codex 同时拥抱 GitHub 与 GitLab，"托管平台中立"成为卖点；异步消息则把 agent 从"一次性脚本"升级为"可被打断、可并行推进的工程线程"，直接降低把长时重构 / 迁移交给 agent 的门槛。

## 3. Canonical 用 LLM 辅助 C→Rust 迁移并加"行为等价验证"：编译通过 ≠ 安全

**事件**  
Canonical 披露用 LLM 生成 C 代码的 Rust 翻译，再用一套验证流程捕捉并修复与原实现的行为差异。关键风险：Rust 版可能干净编译，却以微妙不同的方式解释安全策略——干净编译说明不了正确性。团队先把"维护者需要什么证据才敢信任自动翻译"列清楚，而非急于投产。

**关注理由**  
这是给"用 AI 重写安全关键 C/C++ 代码"的一记明确警示。AI 辅助迁移若只盯着 green build，会漏掉语义差异这条致命裂缝。对所有打算用 coding agent 做 legacy 代码现代化 / 语言迁移的团队，这是该刻进流程的红线——必须做行为等价验证，而非只做编译检查。

## 4. 北京人形发布 Pelican-Unify 大一统具身世界模型 + 天工 Omni：从模块化走向端到端，商用落地

**事件**  
8/20 在 WRC 分论坛"具身觉醒·慧生万象"，北京人形机器人创新中心发布 Pelican-Unify（全国首个统一表征具身世界模型）与新一代产品天工 Omni。Pelican-Unify 将文字 / 图片 / 视频 / 动作编码统一对齐到共享表征空间，统一推理规划、端到端生成视频与动作，实现"理解—推理—规划—行动"闭环；配套的 Pelican-VL 2.0 已面向社会开放服务，率先实现"具身大小脑协同"商业化。天工 Omni 推出旗舰 / 标准 / 基础三产品线，开放底层接口与运动控制框架。现场与中 / 德 / 韩 / 日 / 西等 6 国共 20+ 企业签约。

**关注理由**  
具身智能技术路线从"模块化堆叠"转向"端到端统一表征"，是今年 WRC 最清晰的范式信号；Pelican-VL 2.0 的商业化开放说明"大一统世界模型"不再只是论文概念，开始进入可用服务层。开放底座 + 多国签约，反映行业从"秀技术"转向"建生态 / 找订单"的规模化落地阶段。
