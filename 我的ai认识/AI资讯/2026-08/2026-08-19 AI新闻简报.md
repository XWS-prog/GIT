# 2026-08-19 AI 新闻简报

> 聚焦 **AI coding** 与 **具身智能** 两个方向，筛选当日/近期有价值动态 5 条。

## 1. Claude Sonnet 5 成为 Claude Code 默认模型，原生 1M 上下文 + 促销价

- **事件**：Anthropic 于 8/18 推送 Claude Code v2.1.197，将 **Claude Sonnet 5** 设为默认模型，原生支持 **1M-token 上下文窗口**，并给出促销价 **$2 / $10 每百万 token（输入/输出）**，限时至 8/31。同日还加入「组织默认模型」管理能力和会话可读默认名等。
- **关注理由**：模型默认切换 + 百万上下文下放，意味着单会话即可完成大型代码库的整体理解、跨文件重构与长链路任务；促销价进一步压低了 Agent 级编码的边际成本，对「用得起长上下文 Agent」是实质利好，也会倒逼 Codex / Cursor / Muse Code 在上下文与定价上跟进。

## 2. Cursor 发布 Origin：面向并行 AI Agent 的原生 Git 托管平台

- **事件**：Cursor 于 8/17 上线 **Origin** 代码托管平台，专为「并行 AI agent 工作流」而非顺序人工 PR 设计，特性包括 stacked PR 管理、400ms 全球延迟、自动 merge 冲突解决，并原生对接 Vercel / Depot / Buildkite 部署。
- **关注理由**：这标志着 AI coding 的竞争从「模型/插件能力」外溢到 **开发协作基础设施层**。当多个 Agent 同时在仓库里并行干活时，传统 GitHub 的 PR/冲突模型会成为瓶颈；谁掌握 agent 友好的代码托管入口，谁就卡住「agent 运行 + 部署」的流量与生态位。

## 3. Anthropic 推 /design 研究预览：把「设计稿 → 代码」闭环带入 CLI

- **事件**：Anthropic 为 Claude Code CLI 与 Desktop 增加 **/design** 研究预览命令，引入 Claude Design 的 artboard（画板）工作流——开发者可先生成、检视、调整可编辑的视觉 UI 工件，再让 Claude 编译成代码。
- **关注理由**：这是前端/全栈开发从「文字需求直接出码」走向「**可视化中间态确认再出码**」的范式补完，显著降低大模型一次性生成 UI 的返工率，也预示 coding agent 将向上游「产品设计」环节延伸，吞掉更多工作流。

## 4. 触觉成为具身智能今明两年最大突破维度

- **事件**：WAIC / WRC 2026 报道显示，灵巧手与触觉感知成为焦点——千觉发布 **VTLA 具身触觉模型**与视触觉数据集、一目科技完成 **超 10 亿元 E 轮融资**用于触觉材料/芯片/算法、多家厂商强调「装上了」的力觉无法靠视觉训练出来。产业链判断：触觉提供的几何、材质、接触动力学信息，是视觉等远距传感器无法替代的。
- **关注理由**：具身智能此前卡点在「硬件炫技」与「缺乏物理直觉」，触觉电子皮肤 + 灵巧手正补齐「摸得到、抓得稳、学得会」的最后一块，是从 Demo 走向真实作业的关键变量；相关传感/芯片/数据公司将成下一波资本与产业落地的核心标的。

## 5. 宇树科技科创板 IPO 注册获批，产业链国产化率超 85%、量产拐点确立

- **事件**：宇树科技 7 月获证监会同意科创板 IPO 注册（拟募资约 42 亿元）；WRC 2026 披露国内头部整机厂核心硬件国产化率普遍 **超 85%**，工信部预测 2026 全年人形机器人整机产量将首破 **10 万台**，智元机器人 6 月完成第 1.5 万台下线交付、DaxAI 锁定 5 亿元年度订单。
- **关注理由**：「头部企业上市 + 供应链国产化 + 万台级真实交付」三者同时兑现，说明行业评价标准已从「能不能动」转向「成本算得过来、订单在涨、产出可验证」。国产替代打通后，具身智能的规模化部署真正从预期进入进行时态，对上游零部件与下游场景集成商是明确信号。
