# 2026-08-20 AI 新闻简报

> 侧重 AI Coding 与具身智能。筛选自当日（2026-08-20）聚合源与行业动态。

## 1. xAI 开源 Grok Build：84.4 万行 CLI agentic coding 栈全量公开

**事件**
xAI 开源了 Grok Build —— 包含其 agentic coding 栈的全部 84.4 万行 CLI 代码：完整的 agent loop（上下文组装、模型调用、响应解析、工具分发），以及 skills、hooks、MCP server、subagents 的加载方式。可本地编译并指向本地推理。限制：单一贡献者、不接受外部 PR、关闭 issue，属"源码可见"的参考材料而非社区项目。

**关注理由**
此前各家几乎从不公开 agent loop 的内部实现，如今这套"官方参考实现"可直接对照。对自研 coding agent 的团队是现成的架构样本；也反映头部玩家从封闭走向"以开放换生态影响力"的转向——agent 工程细节正成为公开竞争维度。

---

## 2. Vercel 开源 fx：6MB Zig 编写的可嵌入编码 Agent

**事件**
Vercel Labs 开源 fx —— 一个仅 6.4MB、用 Zig 编写的二进制编码 Agent，10 微秒冷启动，支持本地模型 / API / 网关，内置 WebAssembly 可嵌入式运行。设计理念是"像 Unix 工具而非假装是应用的终端"，通过 Skills / Plugins / MCP 扩展，在 Hacker News 获 143 分热议。

**关注理由**
编码 Agent 市场正在分裂——一端是重量级 IDE 驾驶舱，另一端是可嵌入部署流水线的轻量原语。fx 代表"Agent 即基础设施原语"的极端路线，预示 coding agent 会像 grep / sed 一样成为可组合的系统组件，而非必须常驻一个应用。

## 3. Cursor 云端 Agent 新增"订阅"：监视 PR / Slack / 定时任务自主推进

**事件**
Cursor 的云端 Agent 现在可"订阅"一个 PR、Slack 线程或定时计划，自主持续推进任务直到完成；配合此前推出的 Builds（预建环境，首 token 提速约 3 倍）。同日 AI/TLDR 还集中列出 TencentDB Agent Memory v2.0（团队级记忆）等"持久化 / 记忆层"涌现的信号。

**关注理由**
Coding agent 正从"召唤一次跑一次"走向"无人值守的长时循环"——agent 监视外部状态（PR 变更、消息、时钟）并自我驱动。记忆 / 持久化成为当天最密集的信号，说明"agent 的忘性"已成为工程化落地的核心痛点，基础设施层正补上这块短板。

## 4. 世界机器人大会展期中 + 世界模型集群密集发布

**事件**
2026 世界机器人大会（8/19–23，北京亦庄）进入展期，373 家企业、3000+ 展品、300+ 首发新品。同期模型端密集推新：清华 + 腾讯 RoboticsX + 港科大 + 深技大推出可交互世界模型 GeniWorld（URDF 渲染将数值动作转为与相机对齐的视觉动作表示，预测未来视频以合成训练数据）；另有隐空间预测世界动作模型 ω-0、戴盟触觉锚定世界模型 Daimon-TWM、DynaRobotics DYNA-2（>100 万小时人类视频预训练，部分操作任务成功率最高 90%）等。

**关注理由**
具身智能叙事从"VLA 与世界模型二选一"转向"融合"，世界模型成为补足物理理解与预演能力的关键层；GeniWorld 用"视频预测合成训练数据"直击数据瓶颈。WRC 首设"采购日"（200+ 企业参展），行业从"秀技术"转向"找订单"——表演期落幕，打工期开场。

## 5. 宇树"超人"原型：原地跳高 2 米、冲刺 12.66 m/s，研发仅三个月

**事件**
宇树科技 8/17 发布全新人形机器人原型"超人"：腿长仅 0.85 米，原地极限跳高约 2 米（超人类原地跳高世界纪录约 1.8 米），极限冲刺 12.66 m/s（超博尔特峰值 12.42 m/s），研发周期仅三个多月。官方称距离商用尚有距离，性能为厂家自测待独立验证。

**关注理由**
高动态双足运动的迭代速度（月级而非年级）反映国内高密度供应链与 actuator / 控制硬件积累。性能数字虽待第三方验证，但持续拉高"人形机器人运动能力上限"的公众预期，也为后续量产版的运动鲁棒性设下新基准。
