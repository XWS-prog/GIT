# 2026-08-18 AI 新闻简报

> 聚焦：AI coding 与具身智能。筛选 5 条高价值动态（3 条 AI coding，2 条具身智能）。

## 1. Claude Code 默认开启 Auto Mode，重构"人机共治"安全范式
**事件**：8 月 14 日，Anthropic 宣布 Claude Code 默认开启 Auto Mode——AI 编程智能体可无需人类逐条审批即自动执行代码操作。官方数据：人工审批仅能拦截 13.6% 的危险操作，而 Auto Mode 内置分类器可拦截 89%；用户在 97% 的情况下会直接批准权限提示，"审批疲劳"已成为比 AI 犯错更严重的安全隐患。
**关注理由**：这标志着 AI 编程从"人类逐条审批"走向"智能体自主执行 + 分类器兜底"的范式转折。当智能体比人类更擅长审代码，开发者的角色与责任边界需要被重新定义，安全治理也从"权限弹窗"转向"行为分类与沙箱隔离"。

## 2. 智谱 GLM-5.3 登顶开源 coding 基准：后训练 scaling 仍有巨大空间
**事件**：8 月 14 日，智谱发布 GLM-5.3——在**不更换预训练底座**的前提下，通过把后训练（SFT/RLHF/DPO）推向极致，实现编码能力较上一代 +50%，登顶开源模型 coding 基准（Terminal Bench 3.0 开源第一，逼近 Claude Fable 5）。更意外的是其安全能力：白盒代码审查比肩 Mythos 5，CyberGym 达 84.5%。权重将于两周后开源。
**关注理由**：它给"Scaling Law 触顶"争论一个务实答案——预训练放缓，但后训练仍有巨大 headroom。同一底座、不同后训练配方即可换来 50% 编码增益，意味着企业可低成本复用现有底座做定向增强；同时"AI 安全"从营销话术进入可量化基准阶段。

## 3. DeepSeek V4 Pro 正式 GA：1M 上下文 + 完整 Agent 栈，近零迁移成本
**事件**：8 月 12–14 日，DeepSeek V4-Pro-0813 结束预览正式 GA，覆盖 API、DeepSeek Chat 与第三方平台。100 万 token 上下文、三档可调推理强度（low/high/max），官方列出 Terminal Bench 2.1 87.9、DeepSWE 62.7、Toolathlon 74.1 等一整套 agent 基准。API 原生支持 OpenAI Responses API 格式并专为 Codex 适配，附一键迁移脚本；8 月 17 日起推出峰谷分时定价（谷时半价）。
**关注理由**：开源模型在 agentic 工作流上已全面对标闭源前沿，且迁移成本近零。分时定价进一步拉低长任务成本——对把"编程智能体"作为基础设施的团队，开源 + 低谷算力组合正在改变成本结构。

## 4. 2026 世界机器人大会本周召开：具身智能从 Demo 走向量产交付
**事件**：2026 世界机器人大会（8 月中旬）聚焦"具身智能从实验室涌向真实世界"。北京人形机器人创新中心发布具身大一统模型 Pelican Unify 与轻量化开放平台"天工 Omni"；浙江中心展出工业级微米精度 NAVIAI WA1。商业化数字亮眼：智身科技截至 6 月累计量产破 1.5 万台、单月破 5000 台；优必选 U1 全渠道订单破 13361 台、9 月交付；星动纪元二季度开启千台级批量交付（增速 300%）。
**关注理由**：2026 年行业关注点已从"炫技 Demo"转向"量产与交付"。头部企业的真实订单与交付节奏，是判断具身智能是否跨越商业化拐点的最硬指标——这比任何 benchmark 都关键。

## 5. 宁波具身智能产业链半年产值 142 亿，机器人已在真实场景产生效率
**事件**：宁波智能机器人产业链 2026 上半年规上企业 101 家、产值 142.3 亿元（+19.1%）。真实落地案例：宇树四足机器人在宁波舟山港将单箱巡检从 80 分钟压缩到 20 分钟；均胜电子发布自研灵巧手（20 自由度、0.08mm 抓取精度）。当地正建设人形机器人未来产业试点区与训练场。
**关注理由**：具身智能的价值最终要在真实工况中兑现。港口巡检 4 倍提效、灵巧手亚毫米精度，说明"干真活"已从 PPT 进入产线；零部件—整机—场景的产业链集群成型，是区域级规模化落地的前兆。
