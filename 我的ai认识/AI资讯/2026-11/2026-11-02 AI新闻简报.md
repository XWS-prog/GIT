# 2026-11-02 AI新闻简报

## 1. [具身智能] 智元创新日补推：Worken「有效智能工时」+ 灵渠 OS 1.0 开源——行业从"参数领先"进入"产出可核算"

**事件**：10/29 智元在上海举办 2026 创新日，11 月初报道集中发酵。CTO 彭志辉（稚晖君）发布三件"非硬件"武器：① **Worken（有效智能工时）**——给物理 AI 时代定义生产力度量衡，类比蒸汽时代的马力、电气时代的千瓦时，让机器人价值"可衡量、可积累、可规模化"，配套 BotShare（擎天租）已可调度 4000+ 台并按 Worken 计费；② **灵渠 OS 1.0**——业界首个具身智能原生操作系统，南向解耦 15 类 100+ 种外设、北向统一大模型调度，1000Hz 硬实时任务下端到端时延抖动 <4 微秒，经量产机器人大规模验证，计划 2026 年底全面开源并捐赠给开放原子开源基金会（智元成为白金捐赠人）；③ **GO-3 Preview 具身基座模型**（登顶三项国际榜单）年底前开源。同时披露：上半年营收近 20 亿元（超宇树的 11.52 亿）、通用机器人累计下线 2 万台、全球人形机器人 43% 份额、通过 92 项车规级量产测试。11/2 起，六台精灵 G2 进真实便利店 24 小时无人在环直播大考（上货/补货/热食/咖啡/迎宾全流程）。

**关注理由**：这是行业商业范式切换的信号——人形机器人最被诟病的是"能上台、不能上岗"，当本体量产不再是瓶颈（2 万台、半年 20 亿营收已验证），竞争焦点转向"让客户愿意持续付费"。Worken 把计费单位从"卖铁疙瘩"改成"有效工时"，灵渠 OS 把生态入口让给开放原子，等于把安卓打法复制到机器人：谁定义度量衡和操作系统，谁就掌握定价权与标准权。受冲击的是仍按"卖设备"定价的二三线本体厂和一次性项目制集成商。未来 3-12 个月盯两个信号：Worken 能否被长隆（年底冲 1000 台）、广州地铁（120 台）等标杆客户写进采购合同成为结算依据；以及 11/2 便利店直播大考的系统层表现。

## 2. [AI Coding] Google 官宣关停 Jules、全量并入 Antigravity：编码智能体进入平台化决战

**事件**：10/29 官宣（changelog 确认时间表），11/1 各方集中报道。Google 编码智能体 Jules 将于 11/11 起进入只读模式（不再接受新任务），12/31 彻底关停；用户需在此之前导出会话历史、环境变量、定时任务、仓库连接等数据（已存 GitHub 的代码/PR 不受影响）。Jules 2024 年 12 月上线，以异步编码智能体起家（连 GitHub 后台修 bug、写测试），曾是 Google 对垒 Codex 与 Claude Code 的先手棋。官方口径：集中资源打造统一的 Agentic 编码开发环境，Jules 的经验直接喂给 Antigravity，但能力全量迁移时间未定。

**关注理由**：这是头部玩家"收缩换聚焦"的标志性动作——编码智能体竞争已从广撒网转向平台化决战，独立小产品被收编或关停的速度在加快。对用户有实际影响：11/11 前必须完成工具链切换规划；对行业，Antigravity 承接 Jules 后将与 OpenAI Codex Cloud、Claude Code Web 形成"云端后台 Agent"三强格局，异步执行这一品类不再有独立玩家。开发者社区反馈两极：有人惋惜"现在没有好用的云端编码 agent 了"，恰好说明该需求真实存在、只是入口收拢。

## 3. [AI Coding] Claude Max 20x 更名 Ultra、验证账户取消 5 小时会话限制：抢夺重度 agent 用户的正面应战

**事件**：10/31 起分批生效，Anthropic 调整个人订阅体系：$100/月 Max 5x 更名为 Max，$200/月 Max 20x 更名为 Ultra，价格不变、老用户自动迁移。真正变化在 Ultra——通过自动验证的账户不再受"每 5 小时"滚动会话限制，长任务可一口气跑完，仅受每周额度约束（周额度仍为 Pro 的 10 倍，旗舰 Fable 模型另设每周上限）；验证基于账户与支付历史自动完成。两档订阅还分别新增 $100/$200 月度 API 额度。

**关注理由**：这直指 Claude Code 重度用户最大的痛点——长程 agent 任务跑一半被会话上限打断。被普遍解读为对 OpenAI、Google 争夺开发者的正面回应（同期 Codex/Copilot 均在加码长时程任务）。但要看清边界："不限时"不等于"不限量"，周额度未涨，实际是**把限流从时间维度转移到总量维度**——对 agent 连续值守场景（挂机跑长任务）是实质利好，对高频重度使用者改善有限。订阅送 API 额度也是新信号：厂商在模糊订阅与 API 的边界，争夺"一个人一个账号跑全套工作流"的开发者。

## 4. [AI Coding] Kimi 上线 3D Make：coding agent 能力外溢到 3D 资产管线

**事件**：11/1 月之暗面 Kimi 上线 3D Make 模块：给 K3.1 Pro 一段文字描述、一张草图或参考图，模型先推断物体的形状、比例与空间关系，再自主编写 Blender、FreeCAD 等专业软件的可执行脚本，上传云端运行，相当于让 AI 远程操控建模软件完成建模。

**关注理由**：技术路线值得注意——它不是端到端生成 3D 模型（那类方案精度和可编辑性都差），而是让模型**写代码驱动专业建模软件**，本质是 coding agent 的能力外溢：把"会写代码"泛化为"会操作一切有脚本接口的软件"。这条路的上限远高于生成式 3D，因为产出是参数化、可编辑、可进专业管线的。对游戏/工业设计/3D 打印等资产生产场景是实打实的提效工具；也预示下一阶段 agent 产品竞争的关键：谁能调度更多"专业软件执行环境"而不只是 shell 和浏览器。

## 5. [AI Coding/成本] DeepSeek 深夜更新：Search/Fetch 接口按次计费 + V4.1-Flash-1017 权重开源——Agent 账单不只看 token 了

**事件**：10/31-11/1 DeepSeek 一组更新：① App 端"许愿式编程"更新（官方演示口径：一句话生成可交付项目，第三方实测尚未铺开）；② 新增 Search/Fetch 联网工具接口，约 5 元/千次（单次约 5 厘钱），**11/1 0 时起按次计费**——此前在 DeepSeek Harness、Claude Code、Codex 里用 DeepSeek API 联网已默认走这套接口且免费；③ V4.1-Flash-1017 最新 checkpoint 权重在 HuggingFace/ModelScope 双平台开放下载（552B MoE、输入激活 8B、1M 上下文）。

**关注理由**：重点不是"许愿式编程"的演示，而是**计费结构的变化**：Agent 越会用工具，账单越不只看 token——搜索一次一毛钱，一个会话搜 20 次就是隐形成本。以后比较"哪个模型便宜"，必须把工具调用费一起算进 TCO，这是行业第一次把联网工具明确单独定价，可能被其他厂商跟进。对自部署用户，1017 权重开源延续了 DeepSeek 的一贯路线；但要注意旧模型名请求会自动路由到新版本，做深度定制的团队需留意版本兼容。
