# 2026-11-05 AI 新闻简报

## 1. [AI Coding] Meta 收购 Conductor、OpenAI 收购 Pierre：两大实验室同日抢购编码智能体「管道」

**事件**：Meta 确认收购 AI 编程初创公司 Conductor（Mac 应用，让工程师并行运行多个 coding agent，各自工作在代码库的隔离副本中，支持 Claude Code/Codex 等第三方模型；约 10 万用户，Meta 工程师本就是客户）。几小时后 OpenAI 宣布收购 Pierre Computer Company——其 Code Storage 服务与开源库 Trees/Diffs 已内置于 Codex 的文件浏览与代码变更管理中。Conductor 创始人 Charlie Holtz 将加入 Meta 超级智能实验室（与 Alexandr Wang、Nat Friedman 共事）；Conductor Cloud 11/20 关停、产品明年年初有「新东西」。Meta 今年 8 月已推自研编码智能体 Muse Code（用户破 1000 万）。

**关注理由**：竞争重心已经从「模型本身」移到「调度和检验模型产出的基础设施」——Axios 的概括很准：Pierre 管 AI 生成代码的存储与版本，Conductor 管多个 agent 并行写码。这与此前 Entire（Dohmke 的 agent-first 托管平台）、GitHub 限流、DeepSeek Super-agent 构成同一趋势：代码托管/编排/审查层成为兵家必争，且大厂开始直接买而非自建。对工具链创业者是个坏消息信号：编排在巨头眼里值得被收购。

## 2. [AI Coding/安全] OpenAI 自动化漏洞流水线挖出 948 个 Linux 内核提权漏洞，单个成本约 1279 美元

**事件**：OpenAI（11/4 安全报告）用一款尚未发布的网络安全模型构建了「发现→动态验证→可利用性评估→补丁生成→人工复核」五阶段自动化流水线。10 月中旬对 Linux 内核测试：筛选 5034 个审计目标（约 280 万行代码，占内核 7%），12 小时产出 2308 个候选漏洞（31.65 万美元）；隔离虚拟机 30 小时动态复现 1724 个（确认率 74.7%，仅 3.1% 属模型误判）；最终生成 948 个本地提权（LPE）利用程序 + 291 个信息泄露 PoC + 候选补丁。总成本约 121.34 万美元，平均每个 LPE 约 1279 美元。对比：7 月用 GPT-5.6 Sol 做同类测试仅发现 166 个——内核同期还加固了三个月，产出仍是 5 倍以上。抽查发现至少 10 种此前未见的漏洞利用技术（第三方专家确认）。已有 61 个漏洞被上游修复。

**关注理由**：这是「AI 漏洞研究工业化」的最强样本：发现到可利用补丁全闭环、按漏洞计价、产出是三个月前的 5 倍。双刃剑属性极强——同一能力既能批量交给内核社区，也能批量找攻击面；OpenAI 强调受控环境与按流程披露，但「单漏洞千余美元」意味着攻防成本结构彻底改写。与此前 PHP2Shell、XBow 挖 Chrome zero-day 连成一条线：安全行业的人才缺口正在被 agent 以商品化方式填补，补丁评审成为新瓶颈（OpenAI 自己承认生成的补丁有冗余、不规范，仍需人工审）。

## 3. [AI Coding/治理] 高盛限制银行家使用 Claude Code 与 GitHub 编程工具

**事件**：据 Bloomberg（11/4-5），高盛限制其银行家和交易员使用 Anthropic Claude Code 与微软 GitHub 编程工具（量化部门 strats 豁免）。背景是 Replit CEO Amjad Masad 反复警告「跑在员工个人设备上的 coding agent 是企业级系统性安全风险」：供应链投毒、凭据暴露、恶意指令注入（近期案例包括 Cursor 市场里被投毒的 Claude Code 扩展、GitHub 账号劫持）。Replit 建议企业把 agent 放进组织可控的云环境、按任务最小授权。

**关注理由**：agent 安全从「新闻事件」进入「企业管制清单」。此前是券商研究员发报告，现在是高盛直接动刀——金融机构给「非开发人员也能写代码」这一卖点踩了刹车，逻辑是：给不给 agent 编程能力不重要，能控制 agent 能做什么才重要。这与 CrowdStrike 收购 Fiddler 做「急停开关」（11/4 已推）、Anthropic 向 METR 开放驻场审查同向：agent 治理正在变成采购必答题和独立预算科目。对企业用户，教训直接：coding agent 默认不该跑在员工裸机上。

## 4. [具身智能] Agility Robotics 今日挂牌纳斯达克（AGLT）：美国人形第一股交出真实账本

**事件**：Agility Robotics（11/5）通过与 Churchill Capital XI 的 SPAC 合并正式挂牌纳斯达克，代码 AGLT/AGLTW，成为美国首家纯人形机器人上市公司（SPAC 合并及相关融资共约 4.65 亿美元，富士康领投约 2.01 亿美元私募，英伟达、亚马逊、软银愿景二期参投）。首份公开账本：2026 上半年营收仅 17.4 万美元（大部分来自关联方），净亏损 3.62 亿美元；Digit 已在 9 个客户现场（GXO、舍弗勒、丰田加拿大、美客多）累计作业超 6.5 万小时、GXO 单一场地搬运超 10 万料箱；Digit 5 已获 30 家客户约 3 亿美元意向订单（附带吞吐/在线率/摆放精度等未公开的对赌条款），2027 上半年首批交付。RaaS 模式宣称单台年省 10 万美元。

**关注理由**：11/1 已推上市主体，今天兑现的关键增量是「首次公开的真实财务」：17.4 万营收 vs 3.62 亿亏损，把人形机器人行业的收入-成本剪刀差第一次摊在季报制度下。Agility 从此每个季度都要向公众解释试点为什么还没变成复购——这对全行业是透明的标尺：宇树（8 月 A 股上市）、Agility（美股 SPAC）先后过会后，人形机器人正式成为可投资的资产类别，后续 Figure、智元等的估值与商业化数据都有了公开对照物。GXO 案例（客户 CEO 曾承认 45 个试点未达 ROI 仍扩大部署）也说明市场买的是学习曲线而非当下经济性。

## 5. [具身智能] 小鹏×北大/港大开源 GroundingPI：40 亿参数「感知优先」模型在感知评测超 GPT-6 Astra

**事件**：小鹏联合北京大学、香港大学等（11/4）发布并开源 GroundingPI——约 40 亿参数的物理 AI 视觉感知基座模型，论文、代码、权重全公开。与 44 个基线在 34 项视觉感知基准、11 类能力（目标检测、精确定位、OCR、文档布局、界面元素识别、机器人空间定位等）对比，综合得分 73.68，高于团队测试中的 GPT-6 Astra（71.54）。下游实验：作为视觉骨干后，机器人只用一半演示数据即超过用更多数据的对比模型；在机器人操作与自动驾驶任务上优于多个主流骨干。路线自称「感知优先」：不与通用大模型拼语言推理，专攻「物体在哪里、能不能抓、抓哪里」。

**关注理由**：又一个「小而专打败大而全」的实证，且发生在具身最吃劲的感知层：4B 模型在感知任务上压过通用旗舰，说明具身智能的瓶颈能力不必等通用大模型进化。这与此前 Striding AI SLM-0.5、超维动力小模型路线、地瓜「底座芯片先行」一脉相承——具身技术栈正在分层专业化，感知/规划/执行各层出现专用模型。小鹏作为车企下场开源基础模型（而非只做整车），也印证「物理 AI 成为车企第二战场」的判断。
