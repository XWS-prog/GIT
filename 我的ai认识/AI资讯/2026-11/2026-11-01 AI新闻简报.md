# 2026-11-01 AI新闻简报

## 1. [AI Coding] DeepSeek 开源 Super-agent：主动干活的 coding agent 原型

**事件**：10/31，DeepSeek Harness 团队开源 dsh-superagent-prototype（MIT 协议，24 小时破 4000 Star），定位「主动式编码 Agent」研究原型，Bloomberg 直接将其对标 Claude Code。核心差异是主动性：agent 常驻监听一个 GitHub 仓库和（可选的）飞书群聊，不被 @ 也能从反馈中定位问题根因、直接提 PR 修复。架构为 Router-Worker 两层——常驻 Router 只收请求、分发任务不干活，隔离 Worker 会话并行执行，外部 Watchdog 防挂起。内部模拟测试（约 300 条消息、20 个真实工作请求）：p50 12.4 分钟完成一半任务，p95 15.7 分钟，对比单会话 + subagent 方案 p95 29.5 分钟快约 1.9 倍。安全设计上，主动行为默认关闭，observe 模式只记录「本来会做什么」，团队人工审查后才切 auto。团队论文核心论点：多 agent 系统的瓶颈已从模型能力转向人的注意力——一个人最多盯 3-5 个活跃会话。

**关注理由**：coding agent 的竞争正从「响应指令」进入「主动值班」阶段——OpenAI DevDay 的 dots、Anthropic 的 proactive 方向都是同一趋势，但 DeepSeek 是第一个把「主动 + 授权前置 + 观察默认」整套控制流开源出来的，等于把 agent 团队协作的参考架构公开化了。叠加其约 1000 亿元融资和 IPO 筹备，DeepSeek 明确在 agent 层（而非模型层）向 Anthropic 发起正面竞争。Ticket + Mandate（每个任务附带不可变的授权凭据）的领域模型设计值得所有做 agent 平台的团队细读。

## 2. [具身智能] Meta 被曝联手傅利叶三个月造出人形原型 Max：智能体公司抢物理入口

**事件**：10/31-11/1 集中报道，Meta 与中国傅利叶智能合作，在约三个月内做出人形机器人原型 Max（约 48kg），面向家庭场景，搭载英伟达 Jetson Thor 芯片，被定位为 Meta Muse 智能体的实体载体，可执行居家任务；第二代研发已启动，尚无上市时间表。

**关注理由**：继 OpenAI 投 Figure/1X、自研本体（9/5 已推）、AMD 收购李飞飞 World Labs（10/8 已推）之后，又一家大模型巨头确认下场做机器人——而且首次选择与中国本体厂合作而非自建或全资收购，等于把「模型能力 + 中国供应链 + 快速原型」拼成一条新路径。Meta 的动机很直白：语言/视觉模型的语料来自互联网，物理世界的操作数据和失败反馈只能靠本体获取，谁有机器人谁就有真实数据闭环。家庭场景 + 智能体载体这一定位，也预示着消费级机器人的竞争将收敛为「入口之争」。

## 3. [具身智能] 清华×无问芯穹×智元提出 CEL 群体经验学习：96 台真机互相抄作业

**事件**：10/30，清华大学联合无问芯穹、智元提出群体经验学习（CEL）范式，在 96 台真实机器人集群上验证：让机器人借鉴同伴的成功经验持续进化，5 项任务总体成功率 97.5%，其中手机包装任务从 79.2% 提升到 98.3%。

**关注理由**：这是同一团队继 RPent（9/22 已推，任务卡下沉 MCP）之后的第三个落点，方向从「单机能力」转向「群体进化」——当单机 VLA 逼近天花板，让 96 台机器人的成功轨迹成为彼此的训练信号，是规模化部署后自然长出的数据红利，也和智元「万台量产 + 集群部署」的路线互为支撑。若 CEL 在更多任务上可复现，「部署规模即学习能力」会成为本体厂新的护城河逻辑。

## 4. [具身智能] 规模化落地两端信号：广东超 2000 台进厂 + 无界动力×京东 1000 家门店复制

**事件**：10/30-31 两条落地动态。其一，广东已超 2000 台人形机器人进驻制造企业，全年有望突破 3000 台；自变量分拣达 1800 件/小时，美的美罗 U 打螺丝 10 秒 6 颗、成功率 99.8%。其二，10/31 无界动力与京东签署战略合作：其 K15 机器人已在两家七鲜咖啡门店全流程无人化上岗（10 月首批落地），双方将推进 1000+ 七鲜门店规模化复制，并同步深化京东 MALL、RoboBase 合作、布局海外。

**关注理由**：省级统计与单点渠道复制同时出现，说明具身智能落地进入「复制」而非「试点」阶段——前者看的是多行业渗透密度，后者看的是单一渠道方能否批量消化产能。京东作为渠道方直接锁 1000+ 门店，等于给无界动力吃了订单定心丸，这与 10/20 极智嘉入股深诣「场景方反向投资大脑公司」、10/26 GXO 扩大 Digit 部署（客户买学习曲线）构成同一证据链：渠道和场景正在成为具身商业化最稀缺的资源。

## 5. [具身智能/资本] 10 月融资环比腰斩 + Agility 挂牌前摊开 RaaS 成本账：赛道进入再收敛期

**事件**：10 月具身智能赛道公开融资 33 起、合计约 101 亿元，较 9 月的 60 起、110 亿元数量近乎腰斩；同期智元启动新一轮 10-15 亿元融资（估值约 500 亿）并主动暂缓港股 IPO，辉羲科技启动 IPO 辅导（中信证券）。海外方面，Agility Robotics 按 11/5 登陆纳斯达克的计划，在招股材料中首次把 RaaS 成本、关联交易、机器人「日历填满率」等经营细节摊开披露。

**关注理由**：融资数量腰斩但单笔金额向头部集中（跨维智能 10 亿 B 轮为年内最大单笔、辉羲年内累计超 25 亿），印证「头部补血、腰尾部出清」的收敛判断——资本不再为概念买单，转而盯「能不能进厂、能不能持续干活」。Agility 的招股书则可能是行业分水岭：RaaS 模式的真实成本结构和设备利用率将首次接受公开市场审视，其披露的日历填满率、单台经济模型会成为整个人形物流赛道的定价基准，也可能提前戳破或坐实「机器人即服务」的盈利故事。
