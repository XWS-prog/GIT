# 2026-11-07 AI 新闻简报

## 1. [AI Coding] Cursor 一日两发：编码智能体可实时语音对话 + Prompt 直出可上线应用

**事件**：11 月 6 日，Cursor 宣布「与智能体实时语音聊天」（Voice Chat with Agents）：开发者可语音与编码智能体双向对话——口头描述修改需求、询问任务进展、查询代码差异与运行状态，后台编码不受中断；语音层由 Grok Voice 驱动，编码智能体继续用用户所选模型，覆盖 Agents Window、IDE、网页端与 iOS（iPhone 可"Hey Siri, call Cursor"发起，锁屏/灵动岛可控），Privacy Mode 下零数据留存。同日还发布 Build Live Apps：一句 Prompt 让智能体建应用、配好 Postgres 数据库、跑安全检查并部署成可分享链接，Vercel 同步上线一键部署支持——应用第一次离开 localhost 直接上线。

**关注理由**：两条发布指向同一趋势的两端——交互入口从打字转向语音（指挥方式变了），交付终点从「产出代码」推进到「可访问的在线服务」（交付形态变了）。coding agent 的竞争已不在「谁写得好」，而在「离目标有多近、路上要人管几步」。注意 Cursor 语音层用 Grok Voice 而非自研，xAI 模型借 Cursor 渠道进入主流开发工作流，值得留意后续模型路线变化。

## 2. [AI Coding] Amp 推出 Spaces：主 Agent 自主拆解并协调多 Agent 线程

**事件**：11 月 6 日，AI 编程工具 Amp 发布 Spaces：用户不再手动创建、命名、管理多个 Agent 线程，而是与一个主 Agent 对话提出目标（如「推进某功能上线」「做一次安全审查」），由主 Agent 理解需求、拆解任务、自动生成并协调多个并行线程，进展以实时卡片回到聊天中。定位为团队协作场所：成员可在同一 Space 内提需求、评论、接手线程，仅 @amp 时才读取评论以减少干扰。

**关注理由**：继 Claude Code 嵌套会话、DeepSeek Super-agent、Kimi Swarm 之后，编排层竞争再加一员，且 Amp 把「任务拆解权」完整交给 Agent 而非人——开发者的角色被明确重定义为「定义目标、审查结果、处理关键决策」。多 agent 编排正从厂商演示走向产品默认形态，「会不会拆任务」开始成为模型能力的新分水岭。

## 3. [AI Coding/隐私] Claude Code 被曝把用户邮箱发给所访问的网站

**事件**：11 月 6 日前后，GitHub issue 报告 Claude Code 在执行联网与 shell 工具调用时将用户账户邮箱发送给访问的网站，HN 帖子 1200+ 分、395 条评论，被视为 coding agent 的严重隐私退化；Claude Code 2.1.317 已更新为在网络工具调用发送账户邮箱前先询问用户。

**关注理由**：继 10 月评测联网、AGENTS.md 劫持、OpenCode RCE 之后，agent 的隐私边界再次出问题——这次是默认行为层面的元数据外泄，不是提示词注入。agent 有身份（登录态、邮箱、密钥）之后，「它带着你的什么信息出门」会成为和「它能干什么」同级的安全问题。厂商在 issue 曝光后数天内加提示，说明此类问题当前仍靠社区发现而非内部审计拦截。

## 4. [具身智能] 它石智航×安波福进博会签约：年底百台级进真实产线，瞄准全国首个千台级集群

**事件**：11 月 6 日进博会期间，它石智航与汽车零部件巨头安波福签署深化合作协议：年底前完成百台级 A 系列工业具身机器人规模部署，覆盖 8 大生产工艺、33 类应用场景（柔性组装、检测协同、生产管理等），首批机器人已进入安波福智能工厂真实产线；算力底座 2026 年内量产。双方此前已在上海嘉定区政府支持下推进全国首个千台级工业具身机器人集群建设，本次签约标志合作系统化。模型侧依托其获 WAIC「SAIL之星」的通用具身大模型 AWE，现场 A3 机器人演示了连接器自主装配全循环。

**关注理由**：汽车 Tier1 巨头把具身机器人写进真实产线的采购与部署计划，且给出明确时间表（年底百台、目标千台），是「车企供应链反向输出机器人」路径的标志性样本——安波福明确表示要把汽车级系统工程、量产与安全标准延伸到机器人。对照此前优必选×一汽大众、乐聚×兆丰，「真实产线订单」正从孤例变成品类，2027 年看谁能把百台变千台。

## 5. [具身智能] 瑞士 EPFL 系公司发布 AIR 人形：轮式+腱驱动+「先干活后自主」，欧洲路线亮牌

**事件**：11 月 6 日，洛桑 EPFL 孵化公司 Embodied AI 在 Humanoid Europe 2026 发布首台全身人形 AIR，并官宣由 Faber VC 领投的首个机构融资轮。技术路线明显反主流：轮式底盘（厂房是平的，双足徒增故障点）、腱驱动手臂（电机集中躯干，手臂近乎无运动质量，接触时靠机械柔顺被动卸力而非软件急停）、目标通过 ISO/TS 15066 协作机器人安全标准、2027 年 CE 认证。商业模式是「生产性遥操作起步」：第一天由人遥操作上岗产生真实产出并全程录数据，约一个月后切换自主，单一机器人学到的技能向车队迁移；此前双臂工作站已在欧洲厂商拿到付费部署，消费电子厂线缆处理测试中以 98% 任务可靠性（目标 90%）成为五家被测机器人公司中唯一达标者。

**关注理由**：美国人形企业在讲规模融资与上市（Agility 刚挂牌），中国企业讲量产价格战，欧洲队给出了第三条路——把「安全」做进机械结构而非软件兜底，把「数据」来自真实工资单而非训练场。腱驱动被动柔顺+遥操作飞轮若在工业认证上跑通，会是对「仿真训练+软件安全」主流路线的直接对照实验；其线缆处理成绩也再次印证柔性物体操作是当前分水岭任务。
