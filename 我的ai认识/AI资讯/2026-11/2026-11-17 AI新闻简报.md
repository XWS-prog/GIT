# 2026-11-17 AI新闻简报

> 本期时间窗 11/14–11/17（补齐上期 11/13 之后间隔）。侧重 AI Coding 与具身智能。

## 01 [AI Coding/产品] Claude Code Projects 重构落地：multi-agent 从手搓变官方产品形态

**事件**：Anthropic 本周对 Claude Code Projects 做了正式重构（Pro/Max 公测）：一个项目 = 一个主动协调者 + 若干并行线程，各线程在云端独立开分支、独立副本，冲突按普通 PR 合并冲突处理；用户只需描述要做什么，范围界定、任务委派、并行协调、结果审查、成品组装整条链路交给系统。同步上线只读线程分享、`/btw` 侧问、`/fork` 分支线程、artifact 缩略图。Anthropic 开发者账号称协调者现在会主动跑并行线程、回答项目内提问并汇报各线程状态。代价同样明确：每条线程都是完整会话、默认 Opus 高 effort，全在烧订阅额度。

**关注理由**：多 agent 叙事到 2026 年终于收敛成共识——难的不是让多个 agent 干活，而是让人不用当那群 agent 的工头。Cursor 有 background agents、OpenAI 把 Codex 拆成按分钟计费 API、Anthropic 把"工头"直接设进产品，下一步比拼的是谁的工头汇报得清楚、谁烧钱烧得慢，"额度经济学"正成为 multi-agent 产品的真实约束。对团队使用者，这是把 coding agent 从个人工具纳入正式研发流程的关键节点。

## 02 [AI Coding/安全] Cursor 公布完整安全事件报告：恶意 Claude Code 扩展供应链投毒 11 小时

**事件**：Cursor 发布 10 月安全事件完整报告：其发给供应商 Fireworks 的访问密钥泄露，攻击者借此读取了 Privacy Mode 之外的旧 agent 会话轨迹（不到 0.01% 客户的 trace 中含未脱敏凭证）；10 月 29 日攻击者用窃取的凭证将恶意篡改的 Anthropic Claude Code 扩展（v2.1.312/2.1.313）放入 Cursor 扩展市场缓存，在线约 11 小时，最多 5000 用户可能中招（Anthropic 官方渠道和 Open VSX 从未发布过恶意版本）。Cursor 已将全部推理迁离 Fireworks，攻击者最后活动时间为 11 月 1 日。

**关注理由**：这是 coding agent 供应链攻击的第一个完整复盘样本——攻击链是「第三方推理供应商密钥 → agent 轨迹数据 → 凭证 → 插件市场投毒」，每一环都踩在 agent 时代新暴露的攻击面上。加上 11/7 的邮箱泄露、11/12 的 Claude Code "Don't Ask Again" 密钥外泄，短期内已是第三起 agent 权限/凭证类安全事件：agent 的权限与凭证应视为安全敏感状态，插件来源校验和供应商密钥管理要进威胁模型。

## 03 [具身智能/模型] Gemini Robotics 2.5 发布（补推）：VLA 密集发布周，物理 AI 逼近可用线

**事件**：Google DeepMind 11/10 发布迄今最强 VLA 模型 Gemini Robotics 2.5（上期与 GR00T 2 同日，GR00T 2 已推过，本条补齐）：200+ 项真实任务评估，可变形物体操作从 0% 拉到 70%（系蝴蝶结）、悬挂开衫 0%→62%、折叠裤子 0%→40%、夹取糕点 5%→100%；整体速度提升 20–30%。落地侧与 Apptronik、梅赛德斯-奔驰在匈牙利/德国真实产线做概念验证，Apollo 2 人形机器人完成零件分拣成功率 96%。模型研发受益于 Gemini 4 Argon 的仿真引擎，官方明确在推递归自我改进（RSI）路线；同步开源机器人越狱安全基准 ASIMOV-Jailbreak。同期一周内苹果 HALO、英伟达 GR00T 2 构成 VLA 密集发布。

**关注理由**：产业催化重心已从"手脚能不能动"转向"大脑能不能用更少数据、更快适应新任务"——Argon 仿真引擎 + RSI 意味着"仿真攒数据→更强模型→更好仿真"的飞轮在机器人领域开始转起来，物理训练数据需求被压低。96% 是概念验证口径、官方未披露节拍与试验次数，当方向标别当成绩单；但对国内本体厂，"VLA + 仿真引擎 + 真实产线数据闭环"三位一体已成为下一阶段竞争的明确范式。

## 04 [具身智能/基础设施] 华为云发布昇腾原生具身世界模型 CloudRobo-WM1.2（观察点兑现）

**事件**：11/16 华为云线上发布首款昇腾原生具身世界模型 CloudRobo-WM1.2（具身产品线总裁吴小东发布、首席模型专家刘流解读架构）。"昇腾原生"不是迁移适配，而是模型架构、训练推理链路到工具链围绕昇腾算力协同设计，目标打通"场景数据→模型训练→仿真验证→云边端部署→反馈迭代"闭环；生态侧亿嘉和已联合发布配网带电作业机器人 Z200Pro。这是继 2025.6 CloudRobo 平台、2026.6 具身智能专区后华为云在具身方向的第三次落子。

**关注理由**：国产 AI 基础设施的能力边界从"生成内容"扩展到"支撑行动"，云端世界模型 + 昇腾算力组合直接对标英伟达 GR00T/Cosmos 路线。真正看点不在参数规模，而在物理一致性、场景泛化、数据效率，以及昇腾工具链的开放程度（迁移成本、云边端部署效率）——这决定它是实验室指标还是行业生产力。后续跟踪已接入本体的实测数据与工具链开放进度。

## 05 [具身智能/商业化] 优必选签 400 台人形机器人订单，量产交付进入渠道方时代

**事件**：11/15 优必选与永达汽车（汽车经销服务集团）签署 400 台人形机器人采购订单；同期 ABB 向宝马新交付超 1700 台工业机器人。产品端拓斯达发布全尺寸工业双足人形机器人 Star（172cm、双臂负载 10kg、适配现有产线），天机智能推出 21 自由度直驱灵巧手。此前优必选已落地柳州万台级工厂（每 10 分钟下线 1 台）、与一汽-大众战略合作，本次买方首次从车厂产线扩展到汽车经销/服务渠道。

**关注理由**：400 台的量级与买方身份是关键信号——人形机器人订单正从"车厂示范产线"扩散到"渠道服务场景"，商业闭环从 to-B 生产侧向 to-B 服务侧延展。结合本周另一信号（实验室成功率不再是产品指标，无故障时间、工位节拍与良率才是），行业评价体系已切换到交付确定性。跟踪后续交付节奏与实际岗位部署情况。
