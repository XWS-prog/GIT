# 2026-11-21 AI新闻简报

> 本期时间窗 11/20 晚–11/21。侧重 AI Coding 与具身智能。今日主线：桌面 Agent 大战开打、「专家知识 + 编码智能体」连破 Ruby 编译器与 FPGA 两大封闭领域、微软把编程模型做成采购纪律，以及具身智能在零售落地与物理 AI 数据供给两端的实质进展。

## 01 [AI Coding/生态] 桌面 Agent 大战开打：Google 给 Gemini Mac 版上线 Computer Use，苹果被曝自研编码智能体

**事件**：Google 宣布为 Gemini Mac 应用加入 Computer Use 能力——用户用自然语言描述任务，Gemini 在后台操作本地应用、文件和网站，完成点击、输入、跨应用信息处理（如从下载文件夹找发票、提取金额、填报销系统），执行过程在独立虚拟窗口展示，可暂停/终止，首次访问应用需授权；目前面向美国英语用户逐步开放，需 AI Plus/Pro/Ultra 订阅。同周 Bloomberg 曝光苹果正自研可写代码、可操控应用的 AI 智能体，计划最早 2027 年底推出，消息一出 Meta、Anthropic 盘后股价下挫。同期 Signal 宣布在 iOS 27 和部分 Android 上默认阻止 AI 智能体读取屏幕（起因是 Meta Muse 被曝借系统通知/辅助功能权限读取 Signal 消息）。

**关注理由**：操作系统级入口的争夺正式进入「谁都能操作你的电脑」阶段——Google 官方下场使桌面 Agent 从第三方工具（Vercel agent-desktop、Claude Computer Use）变成平台标配，苹果入场则意味着端侧也有了自己的编码+操控一体智能体。三条线拼在一起构成完整信号：平台在做执行能力，隐私软件在做反执行（Signal 屏幕访问限制是第一个系统性「反 Agent 权限」措施），操作系统权限体系将被重构。桌面 Agent 的竞争最终不是比谁点的准，而是比谁的权限边界安全。

## 02 [AI Coding/范式] 「专家知识 + 编码智能体」连破两大封闭领域：Matz 数周造出 Ruby 原生编译器，零 FPGA 经验开发者跑出 213 tok/s

**事件**：两个案例先后刷屏。其一，Ruby 之父松本行弘（Matz）在 The Register 专访中披露：用 Claude Code 深度协助，把搁置三年的 Spinel 计划——Ruby 的 AOT 原生编译器——在数周内实现，MIT 协议开源；思路是 Ruby→AST→C 代码再交 GCC/Clang 编译出无运行时依赖的原生可执行文件，基准比 MiniRuby 快约 11.6 倍（Ruby 4.1.0 测试），含类型推断、方法内联、死代码消除与自带 GC；限制是不支持 eval/线程/运行时元编程，与 Rails 不兼容，定位是性能关键路径的辅助编译。其二，一位无 Verilog、十年没写 C++ 的开发者发博（HN 首页热帖）：用云端编码智能体（Astra/Opus 轮换、Conductor 编排）在 AWS F2 FPGA 实例上跑通三元权重 LLM，从首个可工作基线 6 tok/s 一路优化到 213 tok/s（约 33 倍），数天数百次实验、约 300 万行实验历史、token 花费约 1 万美元；人类贡献主要是「鼓励」，唯一起实质作用的是 DeepGrove 创始人写的一段领域经验 prompt（无乘法三元运算、权重打包、HBM 直流、MXINT8 KV cache、tile 化 attention）。

**关注理由**：两个案例共同指向一个可复制的范式：智能体已能跨过「累积型专业知识」这道门槛，但前提是专家把 know-how 写进 prompt——Matz 的三十年语言设计经验、DeepGrove 创始人的 FPGA 经验，分别以文档形式注入，agent 负责持久执行与海量试错。这解释了为什么几个月前同样的尝试失败、现在成功：能力阈值是刚刚跨过去的。对个人开发者的直接启示是「专家 prompt 资产」开始比工具链更重要；对行业则意味着编译器、硬件描述这类传统上高门槛的系统性工程，开发周期可能被压缩一个数量级。

## 03 [AI Coding/成本] 微软 MAI Code 2 / Code 2 Flash 全量上线 Copilot：把模型选择做成「按任务成功成本」的采购纪律

**事件**：Ignite 2026（11/17）发布的微软首批自研编程模型本周全量落地：MAI Code 2 上线 Copilot Pro/Pro+/Max/Business/Enterprise 与 Azure AI Foundry，Code 2 Flash 甚至进 Copilot Free/Student；微软口径是四项自选基准（DeepSWE 1.1、Terminal Bench 2.1、SWE-Atlas、FrontierCode v1.1）平均达 GPT-6.1 Sol 的 98%、成本仅 40%，达 Claude Opus 5.5 的 96%、成本仅 5%；促销价 $0.50/$2.50（每百万 token）至 2027 年 5 月 17 日，Flash 低至 $0.05/$0.25。同期 Decision-1.1 路由模型 GA（Gemma 4 底座、路由 Copilot 请求快 2.2 倍/便宜 4.4 倍），并首次推出 MAI Licensed Weights——可信客户可经 Frontier Co. 直接拿权重跑私有化。微软明说两款模型「尚未针对基础科研与超长程 agent 工作调优」。

**关注理由**：这是云厂商第一次成建制地把「编码模型」拆成 深度重构（Code 2）+ 高频例活（Flash）+ 路由（Decision）+ 权重授权（Licensed Weights）四件套，本质是把模型选择从「追榜单」变成「按任务成功成本采购」——与 11/11 已推的 aiXcompact（上下文压缩降 78% 成本）、11/13 已推的 Gemini 三层调度同构，说明 agent 技术栈的分层定价已成主流结构。独立核查方（ainotis 等）也给出冷静面：全部基准由微软自选、多数跑在自家 MSBench、成本数字按半价促销计算，明年 5 月促销结束后差距会缩小一半。微软的真正意图是用 Maia 200 自有算力吃下 Copilot 每日海量补全，把 $19/席/月的毛利从外部模型伙伴手里拿回来。

## 04 [具身智能/落地] FamilyMart 宣布全国部署补货机器人：6 年试点转全国铺开，单店补货工时降约 70%

**事件**：日本便利店巨头 FamilyMart 宣布 2027 年 1 月起分阶段在全国门店部署 Telexistence 的 AI 补货机器人 TX GHOST 与数字库存货架 Smart Shelf。TX GHOST 在冷藏库内 24 小时运行，基于门店销售数据决定补货优先级，单台每日最多陈列约 1800 瓶饮料；先行导入门店的饮料补货作业时间减少约 70%。系统并非完全无人：出现饮料倒下等意外时由 Telexistence 工作人员远程操作兜底。双方自 2020 年开始测试，此次从试点走向全国。

**关注理由**：这可能是本周比任何人形发布会都更值得关注的具身新闻——它有明确工作对象（冷藏饮料补货）、明确业务流程（销售数据驱动的优先级）、可量化效率改善（-70%），并且走完了「试点→全国」的完整六年周期，是零售机器人第一个全国级部署承诺。与 11/7 已推的智元便利店直播大考对照：中国路线在验证「通用机器人在真实便利店能撑多久」，日本路线则干脆不追求通用——只把一个枯燥、高频、劳动强度大的环节机器人化，用远程操作兜底长尾。后者证明了一个朴素判断：机器人不需要承担全店工作，稳定吃下一个环节就已经创造真实商业价值。「单环节深耕 + 远程兜底」对国内厂商从「全场景演示」转向可复制作业方案有直接参考价值。

## 05 [具身智能/数据] 物理 AI 数据供给两端同时资本化：NVIDIA 推 Cosmos Data Factory 合成流水线，Humyn Labs 融资做全球真实采集

**事件**：英伟达在 Cosmos 平台推出 Data Factory：5 套云端参考工作流 + 6 种可组合技能（数据筛选、自动标注、场景增强、异常事件生成、仿真、流程编排），支持自然语言驱动——例如从既有驾驶视频检索相似场景、生成雨雪雾版本、再校验生成结果是否符合物理规律；官方口径：8 张 RTX PRO 6000 Blackwell 服务器上缺陷图像数据集组装从两个月缩到一天，特殊场景生成计算成本较传统道路采集低约 45 倍。同日，Physical AI 数据公司 Humyn Labs 宣布 4700 万美元 A 轮（Accel 领投 2600 万股权 + 2100 万风险债务），开展业务仅 6 个月、自报年化收入超 5000 万美元，在拉美/东亚/东南亚等 20 多国为机器人公司与前沿实验室采集人类操作行为数据（仓储、物流、制造、日常生活动作）。

**关注理由**：具身智能的老瓶颈——真实数据贵、稀有场景难采——正在被两条相反的路线同时产业化：英伟达把「合成数据生产」做成可编排的云工作流（与 11/3 已推的机器科学仿真+视频双路线、11/18 已推的 Genesis 工人手套路线并列为第三条路径的基建化版本），Humyn Labs 则证明「全球真人数据采集外包」已经是一门 6 个月做到 5000 万美元 ARR 的生意（对照 11/3 已推的数聚变租房采数据）。两端同时资本化说明行业共识已经形成：物理 AI 的下一阶段竞争不在模型参数，而在数据生产能力与单位成本——但要注意官方口径仅覆盖计算成本（-45x 是算力账，不是项目总账），且 Humyn 的 ARR 为公司自报未经审计。
