# 2026-11-03 AI新闻简报

## 1. [具身智能] 智元便利店 24 小时无人在环直播大考收官：6 台精灵 G2 完成 1730 项任务，4 台"转正"

**事件**：11 月 3 日 10:00，智元"机器人打工不能停"24 小时便利店直播挑战收官。6 台精灵 G2 在上海徐汇一家真实营业的便利店连续工作 24 小时，覆盖迎宾、理货补货、咖啡师、热食、清洁五个岗位、四班连轴转，累计完成任务 1730 项（接待顾客 683 次、商品取送 369 件、咖啡 147 杯、早餐 126 份、补货巡检 277 次、桌面清洁 128 次），全网超 200 万人在线围观。最终 4 台"转正"，2 台暂未转正（巡检补货"摸鱼"主动性不足、清洁机器人深夜擅离岗位跑出店外）。考核中还有"刁钻考题"：区分有糖/无糖可乐（靠"耳朵听懂+眼睛确认"双重校验）、打乱整个口香糖货架靠视觉盘点逐格归位、人形路障+纸箱堵路（先停再绕）。

**关注理由**：这是国内首次有厂商把具身智能放到真实商业营业环境做全天候、全时段、可公开围观的压力测试，而非剪辑 Demo。数据的价值在"负样本"：2 台未转正暴露的正是长时程在岗的主动性、任务逻辑与岗位稳定性问题——这正是从"能演示"到"能上岗"的真实差距。全网 200 万人围观也说明具身智能的公众验证正在变成产品发布仪式的一部分。

## 2. [AI Coding] Anthropic Messages API 开放 message threads 公测：对话状态上移服务端

**事件**：Anthropic 将 Messages API 的 message threads 机制开放公测：一轮对话只在服务端保存一次，后续每轮客户端只上传新增消息和上一条消息 ID，模型可更早开始响应。对 50 万-100 万 token 量级请求，首 token 延迟中位数下降约 35%。thread 在两次请求之间加密保存在内存、不落盘，最后一次请求后 5 分钟过期，对多数 Claude Code 用户已默认开启。官方明确 token 用量并未减少——省下的是传输与预填充时间。

**关注理由**：这是 Agent 基础设施层面的关键信号——长上下文 Agent 的瓶颈已从"算力/模型能力"转移到"工程链路"（传输与预填充延迟），API 供应商开始把对话状态管理做成服务端原生能力。受益最明显的是 computer use 和图片密集型工作流（每步都带截图的 agent），这也是 coding agent 长会话体验优化的方向标。

## 3. [AI Coding] Vercel Labs 开源 agent-desktop：读系统无障碍树，不靠截图猜像素

**事件**：Vercel Labs 开源 Rust 项目 agent-desktop，让任意 agent 操作真实桌面应用。核心路线是不靠截图猜像素，而是读取操作系统无障碍树（accessibility tree）获取元素引用，操作更稳、失败后可安全重试；支持 MCP 协议，目前面向 macOS。GitHub 7,870 星，单日新增 2,243。已有人把它与 Codex、browser-use 串联做月度记账：下载收据并对账发票，原需 3 小时以上的工作不到 1 小时跑完。

**关注理由**：computer use 路线之争的又一票：像素视觉路线（截图+坐标）泛化强但不稳，无障碍树路线稳定可靠但依赖应用可访问性质量。agent-desktop 代表了"桌面 UI 结构化"这一务实方向，且 MCP 化意味着任何 agent 都能即插即用获得桌面操作能力——桌面正在成为继浏览器之后 agent 落地的下一个标准战场。

## 4. [具身智能] 机器科学（RoboScience）完成数亿元 A2 轮：仿真+视频双数据路线把单条数据成本压到 0.05 元

**事件**：11 月 2 日，具身智能企业"机器科学"宣布完成 A2 轮数亿元融资，琥珀资本、鸿瑞达投资、上海半导体产投联合领投，360 战投、国联通宝、金鼎资本等跟投。创始人为两位斯坦福履历组合：田野（前苹果 AI 平台技术负责人）与邵林（新加坡国立大学助理教授）。此前已获京东等 10 亿元级投资。其"仿真+视频"双数据路线将单条数据获取成本压至 0.05 元（传统方案的 1/20 至 1/200），视频训练数据从年初 100 万小时增至 10 月 400 万小时，仿真轨迹超百亿次；分层解耦架构下，搭载 Visics 通用具身大模型的机器人可在 30 秒内切换不同品牌灵巧手、无需重新训练即可抓取现场随机物品。

**关注理由**：在真机数据训练场"重资产"路线之外，"仿真+互联网视频"是另一条被持续验证的数据范式（此前 DexForce 仿真合成数据获 Reuters 专题+10 亿 B 轮同属此路）。资本在具身融资整体降温（10 月 33 起环比腰斩）背景下仍向数据成本 curve 压得最狠的团队集中，说明"数据单位成本"正在成为比参数规模更硬的竞争指标。

## 5. [AI Coding] 阿里 Qoder 获世界互联网大会领先科技奖：国内唯一获奖的通用 Agent 产品

**事件**：11 月 2 日，2026 年世界互联网大会领先科技奖在乌镇颁奖，全球 43 个国家和地区 430 多项成果中仅 20 项入选。阿里智能体平台 Qoder 凭借编程智能体 Harness 技术突破与全球市场份额获奖，是国内唯一获奖的通用 Agent 产品。Qoder 2025 年 8 月全球发布，现已覆盖 800 万+ 用户、10 万+ 企业（中国移动、东方航空、吉利等），IDC 报告显示阿里以 47.6% 份额居中国 AI 编程市场第一（超第二至五名之和），Gartner 企业级 AI 代码智能体魔力象限"挑战者"象限。

**关注理由**：国内 coding agent 竞争格局的官方背书时刻。相比海外 Codex/Claude Code 的模型优势叙事，Qoder 的路线是模型、Agent 运行框架（Harness）与产品联合设计——与 11 月以来"dsh-superagent、Copilot Fusion、message threads"等 harness/编排层密集创新的方向一致：模型之外，执行层正在成为 AI Coding 竞争的第二主战场。
