# 2026-11-06 AI 新闻简报

## 一、[AI Coding/Agent 基建] Google Cloud 发布 Agent Compute Engine：给每个 agent 一台 microVM

**事件**：11/5-11/6，Google Cloud 推出 Agent Compute Engine——面向自主软件 agent 的计算服务，源自运营 Gemini 的基础设施经验。每个 agent 会话分配独立 microVM（内核级隔离、硬件隔离 hypervisor、独立加密身份与短期凭据），支持 copy-on-write 内存共享与快照式挂起/恢复，空闲会话不再占用完整算力。官方基准：20 万 agent 规模下每秒 500 次激活、挂起恢复延迟 <500ms、计算密度达传统方案 10 倍。同时开源 GKE 版执行运行时 Agent Substrate（支持 microVM 或 gVisor 沙箱、任意 K8s 集群可跑，官方列出支持 Claude Code、OpenClaw、Hermes 框架，Nous Research 为早期用户），并配套完整治理层：Agent Gateway（策略执行）、Agent Registry（agent/工具白名单）、Agent Identity（身份分配）、OpenTelemetry 可观测性，未来通过 Envoy 代理延伸到跨云/混合云与端侧 coding agent。欧莱雅已用该治理框架建内部 agentic 平台。

**关注理由**：这是 agent 基建「算力层」的正式产品化——此前各家的竞争焦点在模型与 harness，Google 直接把「agent 会话的调度、隔离、挂起恢复」做成云服务，相当于把 coding agent 的运行时收编进云厂商的基本盘。对用户侧的含义：agent 治理（身份、成本、审计）正在从论文议题变成云厂商的标准化 SKU，与此前 GitHub Universe、GitLab 的治理动作同向；企业采购 coding agent 时「跑在哪、谁审计」将成为必答题。开源的 Agent Substrate 则为私有化部署留了口子，值得跟踪其 Claude Code 兼容层的实际可用性。

## 二、[AI Coding/安全] OpenAI 发布 GPT-6 Cyber：安全专用模型上调至 Critical 级

**事件**：11/5 发布，ExploitGym 基准 48.5%（前代 GPT-5.6 Cyber 32.1%，相对提升 51%；也超 GPT-6 Astra 的 42.4%）。对齐数据：不做部署提示时 99.93% 的测试不越权、开启后 100%。实战成果：复现 1724 个 Linux 内核漏洞并开发 948 个可用提权 exploit（与 11/5 已推的自动化漏洞流水线同源）、发现 Firefox 81 个此前未知高危漏洞并向 Mozilla 提交候选补丁（Mozilla 已开始发布修复）。Preparedness Framework 下网安风险等级从 High 上调至 Critical（意味着官方认定其可在无人干预下针对强防护真实系统开发零日利用）。初期仅向经批准的 Daybreak Red 客户开放（Daybreak Blue 验证版/Red 深度利用版双轨），配套滥用监测、沙箱、人工监督、关键基础设施行为拦截。Cisco、Calif、CodeRabbit 已在用。

**关注理由**：继 GPT-6.1 Terra 系统卡争议之后，OpenAI 第一次把「能力越强、风险等级越高、准入越严」的闭环完整走给外界看——Critical 等级等于官方承认模型具备自主零日开发能力，但解法不是收敛能力而是收紧准入。与 10/16 GPT-6 产出 $250K exploit、11/5 漏洞流水线 948 个 LPE 连成一线：攻防两端的能力都在指数级上移，「用前沿模型保护软件的窗口期有限」成了 OpenAI 自己的口号。对安全从业者：Daybreak 计划的扩大节奏、Mozilla 批量修复 Firefox 的后续是两个可跟踪的落地点。

## 三、[AI Coding/商业模式] GitLab Orbit 上下文图 GA：向竞争对手的 agent 按查询收费

**事件**：GitLab 的 Orbit 上下文图 10/29 GA——把团队的代码、MR、流水线、漏洞数据做成实时图谱，供 coding agent 写码前查询，按量计费（$30/用户/月 1000 次查询，超出约 $0.03/次）。关键数据：CEO 在财报电话会披露约 80% 的查询量来自外部 agent——主要是 Claude Code 和 Codex，而非自家 Duo；3500+ 组织、累计 28 万次查询。同周配套发布治理层：Secrets Manager GA、依赖防火墙、按团队/任务的 AI 支出分析、订阅/组/用户三级消费上限。官方宣称查询图谱可让 agent 幻觉降低 45 倍、token 用量降 4.5 倍（厂商自测，无独立复现）。

**关注理由**：这暴露了一个新商业位——当 coding agent 全面第三方化后，「上下文」本身成了计费资产：GitLab 不做最强的 agent，而是向所有 agent（包括竞争对手的）收过路费。这与 10/26 已推的 GitLab Duo CLI、10/19 按订阅限流是同一战略的三块拼图。值得警惕的两点：一是价值持续性存疑（若 token 降价+上下文窗口扩大，agent 自行读库会稀释图谱价值，12 月财报的外部 agent 查询量是检验点）；二是 Elastic 11/5 威胁报告披露攻击者正通过 Claude Code VS Code 扩展隧道入侵自托管 GitLab（失陷后平均 8 分钟使用被盗凭据）、Truffle Security 发现 2025 年披露的 2.2 万个 live 密钥半年后 81% 仍有效——agent 时代的代码托管平台，没有吊销、限额与审计就不可能通过安全采购。

## 四、[具身智能] 中石油昆仑制造×宇树拟设合营企业：央企场景资本正式下场工业具身

**事件**：11/4 北京市市监局公示（公示期至 11/13），中国石油集团昆仑制造及一致行动人昆仑资本、宇树科技、北京泛界智能拟新设合营企业，从事工业具身智能机器人解决方案业务。股权结构：昆仑制造及一致行动人 60%、宇树 20%、泛界智能 20%，三方共同控制。泛界智能 2026 年 4 月才成立，做 AI 模型开发，最大股东为中国科学院院士乔红——「场（央企场景与装备）+机（宇树本体）+脑（院士团队模型）」的完整拼图。伏笔很清楚：宇树科创板 IPO 时昆仑资本以 1.36 亿元战配 2.23%，双方随即签《战略合作备忘录》，锁定油气/炼化/储运巡检抢险、加油站与充换电综合能源站、海外市场协同三大方向。

**关注理由**：这是「央企场景资本 + 头部本体 + 院士大脑」三方合资的第一个公开样本，性质不同于此前国有基金参股——中石油直接把油气管线、炼化厂区、加油站网络这些高危高价值场景连同防爆规范、应急演练场地打包进合资公司。具身智能「缺能试错的真实场景」 bottleneck（此前传化 300 场景、实景实训专项行动都在解这个问题）在能源央企侧走出了最深的一步。对行业判断的含义：工业具身的订单逻辑正在从「卖机器人」转向「央企下场做解决方案运营商」，宇树 2025 人形收入 8.7 亿的盘子将多一条确定性输血渠道；乔红院士的模型入局也值得跟踪其技术路线。

## 五、[具身智能] 乌镇峰会物理 AI 收官：「最后几毫米」成行业共识瓶颈

**事件**：乌镇峰会（11/2-5）闭幕，物理 AI 议题集中释放三组信号。其一，王兴兴在机器人与具身智能论坛提出：当前瓶颈不在大模型的理解规划，而在模型与物理世界的「最后几毫米」对齐误差，判断 1-2 年内可通过工程化迭代解决、2027 年大概率是行业临界点；宇树 G1 已成全球应用最广人形平台。其二，小米首次披露具身基座模型进展：超 10 万小时、1700+ 场景数据预训练，新任务仅需 ≤10 小时示范数据即可达 75%+ 成功率；小米青年公寓已试运营 30 分钟以上、3 个房间、50+ 任务的连续长程作业，但官方承认「成功率还不能真实运营」。其三，优必选披露每 10 分钟下线一台人形、部分场景效率接近人工 90%；银河通用与宁德时代/西门子/上汽推进千台规模工业应用、零售 50 城 200 点位。同期虹桥论坛上自变量王潜判断物理世界「GPT 时刻」约一年内到来、星海图 G0.7 世界动作模型 60ms 端侧推理，但高继扬泼冷水：通用大模型对具身冲击有限，动作控制必须端侧实时运行。行业数据：2025 年中国具身智能市场约 9150 亿元。

**关注理由**：这组信息的价值在于罕见地出现了口径一致的瓶颈判断——从王兴兴的「最后几毫米」到墨奇黄青虬的「10 万小时高质量数据优于 1000 万小时低质量数据」再到小米「能演示但不能真实运营」，头部玩家第一次集体承认精细操作与真实运营之间存在技术鸿沟，而且量化了弥合路径（对齐误差 1-2 年、新任务 10 小时示范）。之前推过的「部署态」「Worken 有效工时」叙事在这里得到呼应：行业评价体系已从下线台数转向持续完成的真实工作量。王兴兴把临界点从「2-10 年」再收窄到 2027，与 10/14 王潜「一年左右」的判断互相印证，值得作为后续跟踪的基准线。
