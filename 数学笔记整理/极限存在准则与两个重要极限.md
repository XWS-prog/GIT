# 极限存在准则与两个重要极限（高数笔记整理）

> 依据宋浩《高等数学》手写笔记 §1.6 整理（2026-10-19 增补第一重要极限的应用例题、整体替换、柯西准则）；下文中「批注」为原笔记红笔要点。
> 前置：[[极限运算法则]]（§1.5）；后续：[[无穷小的比较与等价无穷小替换]]（§1.7）。

## 一、准则一：夹逼准则（迫敛准则）

**数列版**：若 $y_n \le x_n \le z_n$，且 $\lim_{n\to\infty} y_n = \lim_{n\to\infty} z_n = A$，则 $\lim_{n\to\infty} x_n = A$。

**函数版**：若 $f(x) \le h(x) \le g(x)$，且 $\lim f(x) = \lim g(x) = A$，则 $\lim h(x) = A$。

![夹逼准则](file:///C:/Users/xjhso/Desktop/数学学习笔记/图像汇总/1.6极限存在准则与两个重要极限/夹逼准则示意图.png)
*图：夹逼准则 —— f(x) ≤ h(x) ≤ g(x)，且两端同趋于 A*

> [!note] 批注
> 关键是「**两头夹住、两头同极限**」。找两头的常用手段是放缩：例如用 $\cos x$ 与 $1$ 去夹 $\frac{\sin x}{x}$。

## 二、第一重要极限

**公式**：$\lim_{x\to 0}\dfrac{\sin x}{x} = 1$。

**几何依据**：$0 < x < \frac{\pi}{2}$ 时，$\sin x < x < \tan x$；同除 $\sin x$ 得 $1 < \frac{x}{\sin x} < \frac{1}{\cos x}$，即 $\cos x < \frac{\sin x}{x} < 1$。由夹逼准则，$\lim_{x\to 0}\frac{\sin x}{x} = 1$。

![第一重要极限](file:///C:/Users/xjhso/Desktop/数学学习笔记/图像汇总/1.6极限存在准则与两个重要极限/第一重要极限_sinx比x.png)
*图：第一重要极限 —— cos x ≤ sin x/x ≤ 1，两端同趋于 1*

**常用变形**：

- $\lim_{x\to 0}\dfrac{x}{\sin x} = 1$；
- $\lim_{x\to 0}\dfrac{\tan x}{x} = 1$（$=\frac{\sin x}{x}\cdot\frac{1}{\cos x}$）；
- $\lim_{x\to 0}\dfrac{\arcsin x}{x} = 1$（令 $t = \arcsin x$，则 $\sin t = x$，化为 $\frac{t}{\sin t}$）；
- $\lim_{x\to 0}\dfrac{1-\cos x}{x^2} = \dfrac{1}{2}$。

> [!note] 批注（红字）
> 核心是「**凑**」——把式子凑成 sin□ / □ 的形式再换元；方框必须完全一致。

## 三、第一重要极限的应用例题（10-19 新增）

**例 1**：$\lim_{x\to 0}\dfrac{\tan x}{x}$

$$\frac{\tan x}{x}=\frac{\sin x}{\cos x}\cdot\frac{1}{x}=\frac{\sin x}{x}\cdot\frac{1}{\cos x}
\;\Rightarrow\; \lim_{x\to0}\frac{\sin x}{x}\cdot\lim_{x\to0}\frac{1}{\cos x}=1\cdot 1=1$$

> [!note] 批注（红字）
> 关键一步是「**把极限分进去做**」——先拆成 $\frac{\sin x}{x}\cdot\frac{1}{\cos x}$，两个因子的极限都存在，才允许这样拆。

**例 2**：$\lim_{x\to 0}\dfrac{1-\cos x}{x^2}$

$$\frac{1-\cos x}{x^2}=\frac{(1-\cos x)(1+\cos x)}{x^2(1+\cos x)}
=\frac{\sin^2 x}{x^2(1+\cos x)}=\left(\frac{\sin x}{x}\right)^2\cdot\frac{1}{1+\cos x}$$

故原式 $=\left(\lim_{x\to0}\frac{\sin x}{x}\right)^2\cdot\lim_{x\to0}\frac{1}{1+\cos x}=1^2\cdot\frac{1}{2}=\frac{1}{2}$。

> [!note] 批注（红字）
> 「**考虑去凑 $\sin x$**」——用 $1-\cos^2x$ 造出 $\sin^2x$，再用第一重要极限。书写时注意每一步仍是 $x\to 0$，别把角标写成 $x^2$。

**例 3**：$\lim_{x\to 0}\dfrac{\arcsin x}{x}$

令 $t=\arcsin x$，则 $\sin t=x$；当 $x\to 0$ 时 $t\to 0$。原式 $=\lim_{t\to0}\dfrac{t}{\sin t}=1$。

> [!note] 批注
> 换元法：设 $t=\arcsin x$ 则 $\sin t=x$；本质仍是第一重要极限，只是把 arcsin 翻译成 sin 的逆过程。

## 四、第一重要极限的抽象形式与「整体替换」（10-19 新增）

把 $\sin$ 的自变量看成一个「方框」□，则 lim (sin□ / □) = 1（□ → 0）——只要分子分母的方框**完全一致**，比值就趋于 1。

![整体替换](file:///C:/Users/xjhso/Desktop/数学学习笔记/图像汇总/1.6极限存在准则与两个重要极限/第一重要极限_整体替换.png)
*图：sin□/□ 的整体替换 —— 方框可以是 3x、x²、x-1，只要分子分母一致就趋于 1*

**例 4**：$\lim_{x\to 0}\dfrac{\sin 5x}{3x}=\lim_{x\to0}\dfrac{\sin 5x}{5x}\cdot\dfrac{5}{3}=1\cdot\dfrac{5}{3}=\dfrac{5}{3}$。

**例 5**：$\lim_{x\to 0}\dfrac{\sin x^2}{x^2}=1$（此时 □ = $x^2$，分子分母完全一致）。

**例 6**：$\lim_{x\to 0}\dfrac{\sin 6x}{\sin 2x}$

$$=\lim_{x\to0}\left[\frac{\sin 6x}{6x}\div\frac{\sin 2x}{2x}\right]\cdot\frac{6x}{2x}=\frac{1}{1}\cdot 3=3$$

> [!note] 批注（红字）
> 「**要什么就写什么**」——**整体思维**：先把分子分母的方框凑成同一个东西，缺什么因子就同乘同除补上；例 6 要同时把 $6x$ 与 $2x$ 都凑出来。

## 五、准则二：单调有界准则

**准则**：单调有界数列必有极限。（单调递增且有上界，或单调递减且有下界。）

> [!note] 批注
> 只保证「**存在**」，不告诉极限值；极限值常靠递推式两边取极限求出（如 $a_{n+1}=f(a_n)$）。
> 直观上：单调 + 有界 ⇒ 数列一直朝一个方向走、又被一堵墙挡住，只能**无限逼近**那堵墙。

## 六、第二重要极限

**公式**：

$$\lim_{n\to\infty}\left(1+\frac{1}{n}\right)^n = e,\qquad
\lim_{x\to\infty}\left(1+\frac{1}{x}\right)^x = e,\qquad
\lim_{x\to 0}(1+x)^{1/x} = e$$

![第二重要极限](file:///C:/Users/xjhso/Desktop/数学学习笔记/图像汇总/1.6极限存在准则与两个重要极限/第二重要极限_e.png)
*图：第二重要极限 —— (1 + 1/x)^x 单调递增且有上界 e*

**例 1**：求 $\lim_{x\to\infty}\left(1-\dfrac{1}{x}\right)^x$。

$$\lim_{x\to\infty}\left(1-\dfrac{1}{x}\right)^x
= \lim_{x\to\infty}\left[1+\left(-\dfrac{1}{x}\right)\right]^x
= \lim_{x\to\infty}\left[\left(1+\left(-\dfrac{1}{x}\right)\right)^{-x}\right]^{-1}
= e^{-1} = \dfrac{1}{e}$$

> [!note] 批注（红字）
> 必须**内外是倒数形式**——(1+□)^(1/□)；凑的时候「加什么就配什么倒数」，指数要配成 1/□。

**例 2**：$\lim_{n\to\infty}\left(1-\dfrac{3}{n}\right)^{5n}$

先把指数配成 1/□ 要求的 $-\frac{n}{3}$：

$$=\lim_{n\to\infty}\left[\left(1-\frac{3}{n}\right)^{-n/3}\right]^{(-3)\cdot 5}
= e^{-15}=\frac{1}{e^{15}}$$

> [!note] 批注（红字）
> 指数配成 $-\frac{n}{3}$ 后，为保证值不变，外面要乘回 $(-3)\cdot 5=-15$；这一层「**配倒数再补回指数**」是 $1^\infty$ 型最常考的变形。

## 七、柯西极限存在准则（10-19 新增）

**准则**：数列 $\{x_n\}$ 收敛 $\Leftrightarrow$ $\forall \varepsilon>0$，$\exists N>0$，当 $m>N$、$n>N$ 时，恒有 $|x_m - x_n| < \varepsilon$。

![柯西准则](file:///C:/Users/xjhso/Desktop/数学学习笔记/图像汇总/1.6极限存在准则与两个重要极限/柯西准则示意图.png)
*图：柯西准则 —— N 之后的任意两项彼此无限靠近*

> [!note] 批注（红字）
> 注意「**充要**」二字——不必事先知道极限值 $A$ 就能判定收敛，这正是它比 $\varepsilon$-$N$ 定义强的地方。「某一项」与「任意两项」：只要下标 $m$、$n$ 都大于 $N$，两项就必须彼此靠近。

## 八、知识结构总结与分析

![两个重要极限流程图](file:///C:/Users/xjhso/Desktop/数学学习笔记/图像汇总/1.6极限存在准则与两个重要极限/流程图_两个重要极限.png)
*图：极限存在准则与两个重要极限 —— 两个准则、两个公式与常用变形*

**结构分析**：

1. **两个准则**：夹逼准则负责「夹出来」，单调有界准则负责「证明存在」；柯西准则是「存在性」的充要刻画，不必事先知道极限值。
2. **第一重要极限**解决 $0/0$ 型中的三角式：核心是把式子凑成 sin□ / □，方框必须完全一致，再换元。
3. **第二重要极限**解决 $1^\infty$ 型：核心是凑成 (1+□)^(1/□)，内外必须是倒数形式。
4. **「整体」意识**：sin□ / □ 的方框可以是 $5x$、$x^2$、$x-1$；「要什么就写什么」，缺因子就同乘同除补上。
5. **两个「重要极限」的地位**：它们是导出其他极限与导数公式的基础（如 $(\sin x)' = \cos x$、$(e^x)' = e^x$）。
