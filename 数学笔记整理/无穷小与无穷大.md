# 无穷小与无穷大（高数笔记整理）

> 依据宋浩《高等数学》手写笔记 §1.4 整理（2026-10-18 新增 3 页）；下文中「批注」为原笔记红笔要点。
> 前置：[[函数的极限]]（§1.3）；后续：[[极限运算法则]]（§1.5）。

---

## 一、无穷小

**定义**：若 $\lim_{x\to x_0} f(x) = 0$（或 $x \to \infty$ 时极限为 0），则称 $f(x)$ 为 $x \to x_0$（或 $x \to \infty$）时的**无穷小**。

> [!note] 批注（红字）
> 注意「**变化过程**」「**要有范围**」！同一个函数在不同过程中可能既不是无穷小也不是无穷大；另外——**0 是无穷小**！！！

**定理**（极限与无穷小的关系）：$\lim f(x) = A \iff f(x) = A + \alpha$，其中 $\alpha$ 是无穷小。

> [!note] 批注
> 这是把「极限」翻译成「常数 + 无穷小」的桥梁；后面等价无穷小、泰勒展开都从这里出发。

## 二、无穷大

**说明**：$\infty$ 是极限不存在的一种！只有 $\lim f(x) = A$（$A$ 为常数）才称「有极限」（收敛）。

**定义**（描述性）：在同一变化过程中，若 $\lvert f(x)\rvert$ 无限增大，则称 $f(x)$ 为**无穷大**，记作 $\lim f(x) = \infty$。

**例**：$\lim_{x\to 0} \frac{1}{x} = \infty$。

**定理**（互为倒数）：在同一变化过程中，

- $f(x)$ 为无穷大 $\Rightarrow \frac{1}{f(x)}$ 为无穷小；
- $f(x)$ 为无穷小且 $f(x) \neq 0$ $\Rightarrow \frac{1}{f(x)}$ 为无穷大。

> [!note] 批注（红字）
> 「**取倒数**」——无穷大与无穷小互为倒数；但用 $\frac{1}{f(x)}$ 时必须保证 $f(x) \neq 0$。

## 三、无穷小的运算性质

设 $\alpha$、$\beta$ 是同一变化过程中的无穷小，则：

- $\alpha \pm \beta$ 是无穷小；
- $k\alpha$ 是无穷小（$k$ 为常数）；
- $\alpha\cdot\beta$ 是无穷小；
- $\alpha/\beta$ **不确定**——变化速度不一定相同。

**进一步**：

- 有限个无穷小之和 = 无穷小；**无限个**无穷小之和**不一定**。
- 有限个无穷小之积 = 无穷小；**无限个**无穷小之积**不一定**。
- **有界函数 × 无穷小 = 无穷小**。例：$\lim_{x\to 0} x\sin\frac{1}{x} = 0$（$\sin\frac{1}{x}$ 有界，$x$ 为无穷小）。

**反例**（无限个无穷小之和）：

$$\lim_{n\to\infty}\left(\frac{1}{n^2}+\frac{2}{n^2}+\cdots+\frac{n}{n^2}\right)=\lim_{n\to\infty}\frac{n(n+1)/2}{n^2}=\frac{1}{2}$$

> [!note] 批注
> 关键在「**有限**」与「**有界**」：无限个相加时个数本身在变，不能套用有限次的结论。

---

## 四、无穷大的运算（未定式）

**可直接确定**：

- $(+\infty) + (+\infty) = +\infty$；$(-\infty) + (-\infty) = -\infty$；
- $(+\infty)\cdot(+\infty) = +\infty$；$(-\infty)\cdot(+\infty) = -\infty$。

**不能直接运算**（未定式，必须回到具体函数分析）：

| 运算 | 结果 |
|---|---|
| $(+\infty)+(+\infty)$ | $+\infty$ |
| $(-\infty)+(-\infty)$ | $-\infty$ |
| $(+\infty)\cdot(+\infty)$ | $+\infty$ |
| $(-\infty)\cdot(+\infty)$ | $-\infty$ |
| $\infty-\infty$ | 未定式 |
| $0\cdot\infty$ | 未定式 |
| $\infty/\infty$ | 未定式 |

> [!note] 批注
> 出现未定式，说明「光看类型不够」，要回到具体函数做变形（约分、通分、抓大头、等价替换）。

## 五、知识结构总结与分析

![无穷小与无穷大流程图](file:///C:/Users/xjhso/Desktop/数学学习笔记/图像汇总/1.4无穷小与无穷大/流程图_无穷小与无穷大.png)
*图：无穷小与无穷大 —— 定义、倒数关系与运算性质*

**结构分析**：

1. 无穷小与无穷大不是「数」，而是**随变化过程而变的变量**；判断前必须先说明过程（$x\to x_0$、$x\to\infty$、$x\to x_0^+$ …）。
2. 二者通过「取倒数」互换，这是后续比较无穷小阶、求极限时最常用的转换。
3. 运算性质的关键词是**有限**与**有界**：有限个才可加、可乘；有界量乘无穷小仍是无穷小。
4. $\infty-\infty$、$0\cdot\infty$、$\infty/\infty$ 是三种典型未定式，出现就说明「光看类型不够」，要变形。
