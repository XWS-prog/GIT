## 二、游戏性能实测（重点 PUBG，插电 + 奥创增强模式 + 独显直连）

> 环境：室温 23℃；画质：材质 / 抗锯齿 / 可视距离超高，其余极低，渲染比例 100%，全屏模式

### 🎮PUBG（绝地求生）

1. **2.5K 本机屏幕**

- 平地：195‑235 帧
- 烟雾、房区混战：**125‑150 帧**，1% 低帧稳定，无恶性掉帧

2. **1080P（外接显示器）**

- 平地 220‑260 帧；混战 140‑170 帧，轻松跑满 144Hz 显示器。

3. 温度噪音：双烤 CPU 约 82℃，GPU 约 82℃；增强模式风扇噪音中等偏高；WASD 游戏键位温度低，长时间刚枪手感不烫。

### 🎮其他 3A 参考

- 黑神话悟空 2.5K 高画质：平均 110‑130 帧，DLSS4 开启后 140 帧以上。
- CS2：2.5K 下 300 帧上下。

### ✅优势

1. i7‑14650HX 老游戏兼容性优秀，PUBG 几乎无驱动 bug；
2. 双 2280 硬盘位、双内存插槽，后期升级自由度很高；
3. 90Wh 大电池，不插电办公续航相比同级别游戏本更好；
4. 机身较轻，方便携带；酷睿版温控噪音优于同模具锐龙版。

### ⚠️短板

1. 屏幕只有 165Hz，对比 240Hz 机型，FPS 高速画面顺滑度弱一档；亮度 400 尼特，强光环境观感一般；
2. 增强模式下风扇噪音明显，夜间卧室使用会吵；
3. 原装 16G 为单通道，建议后期升级为 32G 双通道，PUBG 多人混战会更稳。

## 三、新机到手完整注意事项（开箱→验机→系统优化）

> 重要：**全程录制完整开箱视频，保留所有包装、封箱贴、底部 SN 码，作为维权证据**。

### 1、开箱外观检查（不要插电源，不要开机）

1. 检查快递外箱有无严重挤压、破洞；检查原厂封箱贴，看有无二次粘贴、残胶（封条可仿制，仅做参考）。
2. 核对三处 SN 码：**外箱侧面 SN、机身底部 SN、BIOS 内 SN**，三者必须一致。
3. 检查机身：A/B/C/D 面有无划痕、磕碰；屏幕有无碎点；接口无使用痕迹。
4. **运输模式校验：不插电源，按电源键，机器不能开机，属于正常新机运输模式；如果不插电能开机，大概率是二次机器，直接申请退换货**。

### 2、首次开机，严禁提前联网！

1. 插上原装电源适配器，按电源开机。
2. 到 Windows 联网界面，**Shift+F10 调出命令提示符，输入 OOBE\BYPASSNRO，回车，电脑重启，跳过联网**。

> ❗一旦联网就会自动激活 Windows，激活后非质量问题无法 7 天无理由退换。

### 3、验机检测（不联网状态完成）

1. 确认配置：打开任务管理器，核对 CPU i7‑14650HX、内存 16G、硬盘 1TB、RTX5060 显卡。
2. 屏幕检测：用检测工具检查屏幕有无坏点、漏光。
3. 硬盘通电时间：硬盘通电次数＜100 次，通电时间＜100 小时，属于正常新机浮动区间。
4. 键盘全按键测试、接口测试。

> 以上全部没问题，再连接 WiFi 联网激活 Windows。

### 4、驱动与奥创中心（Armoury Crate）必做设置（玩 PUBG 必调）

1. 联网后，**只在华硕官网下载对应机型驱动，更新 BIOS、显卡驱动；不要用第三方驱动工具**。
2. 打开奥创智控中心：
    - 玩游戏必须插电源；性能模式切为【增强模式】。
    - GPU 模式切换为【独显输出（独显直连）】，**切换后需要重启电脑，这一步对 PUBG 帧数提升非常关键**。
    - 日常办公学习，切【性能 / 安静模式】，混合输出，降低噪音、提升续航。
3. NVIDIA 控制面板：关闭垂直同步，电源管理模式设为【最高性能优先】。

### 5、硬盘内存建议

1. 原装 1TB 固态，PUBG 约 50G，建议不要塞满，预留至少 200G 空间。
2. 原装 16G 单通道，**主玩 PUBG 强烈建议升级 32G（16G×2 双通道），烟雾、多人混战卡顿会明显减少**；双硬盘位后期可以再加一块 2280 固态。

### 6、避坑提醒

1. 不要卸载奥创中心，卸载会丢失性能模式、独显直连切换功能；觉得广告多可以在软件内关闭推送。
2. 玩游戏务必插原装适配器，不插电性能会大幅下降。
3. 游戏本底部进风口不能被被子、软垫堵住，建议配散热支架垫高，提升散热、降低温度噪音。
