## 第一章 计算机基础及Python简介

### 1.1 引言与计算思维

**为什么需要计算机**：网络提供多维度沟通与生活/工作模式；认识自然、分析自然规律并量化计算；数学、逻辑、哲学的推理演算。典型案例：1997 年"深蓝"击败卡斯帕罗夫；2016 年 AlphaGo 以 4:1 胜李世石，2017 年 3:0 胜柯洁，核心原理是**深度学习**。

**计算机求解问题的步骤**（一条主线，务必记牢）：

```
实际问题 → 问题模型（分析、抽象） → 求解算法（模型求解） → 编制程序（编程） → 问题实现（调试）
```

**AI 时代为什么还要学编程**：① AI 不会自动理解需求，需要人分析问题、精准描述并提问；② AI 能写代码不代表正确、符合要求，人必须看得懂、能纠错；③ 编程的本质是**逻辑训练 + 解决问题的能力**。结论：**AI 是超强辅助，你才是指挥者**。

**课程要求**：掌握一种程序设计语言；提高程序的分析、设计和调试能力；培养计算思维。方法：打好基础，多练习多思考——编程能力与在机器上投入的时间成正比。

> **知识点标注**：🔴 计算机求解问题的五个步骤；🟡 计算思维与 AI 时代学习编程的意义；🟢 课程考核与等级考试信息（NCRE 二级 Python 科目代码 66，机考 120 分钟；成绩分优秀/良好/及格/不及格四等）。

### 1.2 计算机基础概述

**计算工具的发展**：算盘 → 计算尺 → 手摇计算器 → 电动计算器 → 电子计算机。1642 年法国数学家 B. Pascal 用钟表元件制造能做十进制加减法的加法机。

**第一台电子计算机**：1946 年美国宾州大学研制成功 ENIAC，使用 18000 个电子管、6000 个开关，占地 150 m²，重 30 吨，功耗 140 KW，运算速度 5000 次/秒。我国第一台大型电子计算机 104 机于 1959 年 4 月完成调试，4200 个电子管、4000 个晶体二极管，容量 4K，每秒运算 1 万次。

**存储容量单位**（换算率 1024）：

```
1KB = 1024B    1MB = 1024KB    1GB = 1024MB    1TB = 1024GB
```

**80 年来没变的东西**：冯·诺依曼（John Von Neumann）提出的**基本结构和工作原理**，体现在其设计的"存储程序式"计算机 EDVAC 中。

**计算机系统的组成**：

- **硬件**：计算机系统中所有实际物理装置的总称。
- **软件**：在计算机中运行的各种程序和相关的数据及文档。

**工作原理（两大要点）**：

1. 采用**二进制**，数据和指令均用二进制存储；
2. 建立**存储程序和程序控制**——编好的程序放在存储器里，计算机自动按程序工作。

**硬件五大部件**：运算器 + 控制器（合称**中央处理器 CPU**）+ 内存储器（三者构成主机）；外存储器 + I/O 设备（构成外设）。

> **知识点标注**：🔴 存储单位换算、冯·诺依曼"存储程序"原理、硬件五大部件与 CPU 组成；🟡 二进制存储、硬件与软件概念；🟢 计算机发展史具体数据。

### 1.3 程序设计语言

**定义**：语言用于通信；程序设计语言用于**人与计算机之间的通信**，是由人使用但计算机可以理解的语言，用于表达需要计算机完成什么任务以及怎样完成。

**语言的分类**：

| 类别 | 特点 |
| :--- | :--- |
| 机器语言（低级） | 直接用二进制代码表达指令，计算机硬件可直接识别执行 |
| 汇编语言（低级） | 用助记符与机器指令一一对应，提高早期编程效率 |
| 高级语言（面向算法） | 接近自然语言，更容易描述和求解计算问题 |

同一个任务 `A = 15 + 10` 的三种写法对比：

```
机器语言：10110000 00001111 / 00101100 00001010 / 11110100
汇编语言：MOV A,15   ADD A,10   HLT
高级语言：A=15+10    PRINT A    END
```

**程序的执行方式**：

- **编译**：将高级语言源代码**一次性全部**转换成机器语言目标代码的过程，执行编译的程序称为**编译器**，对应**静态语言**。
- **解释**：将源代码**逐条**转换成目标代码并逐条运行的过程，执行解释的程序称为**解释器**，对应**脚本语言**（Python 属此类）。

> **知识点标注**：🔴 三级语言的划分与各自特点、编译与解释的区别；🟡 程序设计语言的作用；🟢 三种语言的写法示例。

### 1.4 Python 历史、特性与开发环境

**发展脉络**：1989 年荷兰人 Guido van Rossum 发明 → 1991 年正式发布 → 2000 年 Python 2.0 → 2008 年 Python 3.0 → 2018 年 Python 3.7。口号：*Life is short, you need Python.*

**应用领域**：通用编程语言，覆盖科学计算、数据处理、人工智能、网络爬虫、机器人等。

**五大特性**：

1. **开发效率高**——更少的代码、更短的时间完成任务；
2. **移植性好**——任何安装了解释器的计算机环境都可运行；
3. **资源丰富**——标准库功能强大；
4. **扩展性好**——可集成 C/C++/Java 代码，故称**胶水语言**；
5. **学习难度低**——语法简单，易学易用。

**开发环境**：官网 `www.python.org/downloads/` 下载 Python 3.x 版本安装。两种运行方式：

- **方法 1 交互式**：调用 IDLE 启动图形化运行环境，适合逐句验证；
- **方法 2 文件式**：写成 `.py` 文件整体运行，适合完整程序。

> **知识点标注**：🔴 Python 五大特性（尤其"胶水语言"）、两种运行方式；🟡 编译/解释归属与典型应用；🟢 版本年份。

### 1.5 进制与转换

**四种进制与 Python 前缀**：

| 进制 | 英文 | 前缀 | 数码 |
| :---: | :--- | :---: | :--- |
| 二进制 | Binary | `0b` / `0B` | 0、1 |
| 八进制 | Octonary | `0o` / `0O` | 0~7 |
| 十进制 | Decimal | 默认 | 0~9 |
| 十六进制 | Hexadecimal | `0x` / `0X` | 0~9、a~f / A~F |

**三要素**：数码（基本符号）、基数 R（如 2/8/10/16）、位权 Rᵏ；计数原则为"逢 R 进一"。

**转换方法（核心）**：

1. **R 进制 → 十进制**：**位权展开式求和**。
   - 例：`(1101.011)₂ = 1×2³ + 1×2² + 0×2¹ + 1×2⁰ + 0×2⁻¹ + 1×2⁻² + 1×2⁻³ = (13.375)₁₀`
2. **十进制 → R 进制**：整数与小数**分别转换再组合**。
   - 整数部分：**除以 R 取余，逆序取余**；
   - 小数部分：**乘 R 取整，顺向取整**。

> **知识点标注**：🔴 两种转换方向的方法（位权展开求和 / 除 R 取余 + 乘 R 取整）、Python 前缀；🟡 基数与位权概念；🟢 `(1998.215)₁₀` 一类展开示例。

## 第二章 编写简单的程序

### 2.1 程序书写规则与示例

**示例：求两个整数的和与平均值**（体现"输入—计算—输出"三段式）：

```python
m = eval(input("输入第一个整数："))
n = eval(input("输入第二个整数："))
sum = m + n          # 求和
avg = (m + n) / 2    # 求平均
print("和为：", sum)
print("平均值为：", avg)
```

**Python 程序的书写规则**：

1. 一般情况下一行一条语句；
2. 语句**从第一列开始，前面不能有空格**，否则产生语法错误；
3. 以 `#` 开始的是注释语句；
4. 所有语法符号必须在**英文输入法**下输入（字符串中的符号除外）。

**IPO 程序编写方法**：任何程序都有统一的处理模式——

- **Input 输入**：交互界面输入（input 函数）、随机数据、文件输入、网络输入；
- **Process 处理**：对输入数据计算产生结果，处理方法统称**算法**，是程序的灵魂；
- **Output 输出**：屏幕输出、网络输出、文件输出。

> **知识点标注**：🔴 四条书写规则、IPO 三环节及"算法是程序灵魂"；🟡 注释与英文符号要求；🟢 输入的四种来源。

### 2.2 标识符与命名规则

**标识符**：一个字符序列，用来标识操作、变量、函数等，是 Python 的基本语法单位。

**命名规则**：

1. 必须以**字母或下划线 `_` 开头**，后跟字母、数字、下划线序列；
   - 合法：`x`、`num`、`num_1`、`numEggs`、`python123`；
   - 不合法：`2x`、`a-b`、`num Eggs`。
2. **区分大小写**：`int`、`Int`、`INT` 是三个不同的标识符。

**标识符的类别**：

| 类别 | 说明 |
| :--- | :--- |
| 关键字（保留字） | Python 本身的一部分，不能像普通标识符使用 |
| 预定义标识符 | 内置或标准库提供的函数名、属性、方法，如 `input`、`print` |
| 用户自定义标识符 | 自己创建，须遵守命名规则，且不能用关键字和预定义标识符 |

**查看关键字**：`help()` 函数查看详细说明；`keyword.kwlist` 以列表形式列出全部关键字（`import keyword`）。

> **知识点标注**：🔴 合法标识符的判断、大小写敏感、三类标识符；🟡 关键字与预定义标识符的区别；🟢 `help()` 与 `kwlist` 的用法。

### 2.3 变量与赋值

**变量**：用来标识数据对象，指程序中值可以改变的量。

**赋值语句**：`变量 = 表达式`。Python 解释器根据赋值**自动确定数据类型**，可用内置 `type()` 函数判断类型。表达式可简单（`x = 100`）也可复杂（`x = (100-20)/2`）。两个要点：

- 变量在访问之前**必须先赋值**；
- 只支持该类型允许的运算。

**Python 3 标准数据类型**：

| 可变性 | 类型 |
| :--- | :--- |
| 不可变数据 | int、float、complex、bool、str、tuple、range 对象 |
| 可变数据 | list、dict、set |

**三种赋值方式**：

```python
x = 100                 # 简单赋值
x = y = z = 200         # 链式赋值：多个变量同时赋同一个值
a, b = b, a             # 解包赋值：序列解包，常用于两变量交换
```

解包赋值时**变量个数必须与序列元素个数一致**，否则报错。

> **知识点标注**：🔴 链式赋值与解包赋值（含变量交换）、可变/不可变类型分类、`type()`；🟡 赋值语句的自动类型推断；🟢 `x = x + 1` 与 `x + 1 = x` 的合法性区别。

### 2.4 数据的输入与输出

**输入函数 `input()`**：

```python
变量 = input("提示字符串")
```

注意：`input()` 得到的**永远是字符串**，要得到数字必须处理。两种常用写法：

```python
x = eval(input("请输入："))   # 去掉引号后求值，可得到数值
y = int(input("请输入："))    # 用 int()/float() 代替 eval，更安全
```

**输出函数 `print()`**：

```python
print(objects, sep=' ', end='\n')
```

- `objects`：输出对象，多个对象用逗号分隔；
- `sep`：多个对象之间的间隔符，**默认是空格**；
- `end`：输出结尾符号，**默认是换行符 `\n`**；设为 `''` 则不换行。

```python
print(1, 2, 3)             # 1 2 3
print(1, 2, 3, sep='*')    # 1*2*3
print(1, 2, 3, end=':')    # 1 2 3:（不换行）
```

> **知识点标注**：🔴 `input()` 返回字符串、`eval()` 的作用、`print()` 的 `sep` 与 `end` 参数；🟡 IPO 中输入输出的多种形式；🟢 文件方式下 `end=''` 的表现。

### 2.5 数值类型与运算

**三种数值类型**：

- **整型 int**：与数学整数一致，四种进制表示（`0b`、`0o`、`0x` 引导，十进制默认）；
- **浮点型 float**：带小数的数值，两种表示——小数形式（如 `+3.4`、`.56`）和指数形式（如 `123.6e9`、`1E-27`）。规则：**E/e 前后必须有数，E(e) 后必须为整数**；
- **复数 complex**：虚部用后缀 `j`/`J` 表示，如 `12.3+4j`。虚部 `0j` 中的 `0` **不能省略**；用 `z.real`、`z.imag` 分别取实部和虚部，二者都是浮点型。

**七个算术运算符**：

| 运算符 | 含义 | 示例 | 结果 | 注意 |
| :---: | :--- | :--- | :---: | :--- |
| `+` | 加 | `3 + 4.5` | 7.5 | |
| `-` | 减 | `12 - 4.8` | 7.2 | |
| `*` | 乘 | `2 * 5.0` | 10.0 | `*` **不可省略**，`4ab` 须写成 `4*a*b` |
| `/` | 实数除法 | `10 / 5` | 2.0 | 结果**恒为浮点数** |
| `//` | 整数除法 | `10 // 4` | 2 | 向下取整，`-10 // 4 = -3` |
| `%` | 取余 | `10 % 3` | 1 | 操作数可为实数，`3.5 % 3 = 0.5` |
| `**` | 乘方 | `2 ** 3` | 8 | `4.0 ** 0.5 = 2.0` |

**优先级**：`**` > `* / // %` > `+ -`；有括号先算括号。算术运算两侧只要有一个浮点数，结果就是浮点数（`/` 除外——恒为 float）。

**复合赋值运算符**：`+=`、`-=`、`*=`、`/=`、`//=`、`%=`、`**=`，如 `a += b` 等价于 `a = a + b`。

**两位数的分离技巧**：个位 `m % 10`，十位 `m // 10`；个位十位互换 `m % 10 * 10 + m // 10`。

**内置数值函数**：`abs(x)` 绝对值、`divmod(x,y)` 返回商和余数、`pow(x,y[,z])` 幂、`round(x[,ndigits])` 四舍五入（`0.5` 时取**最近的偶数**，"四舍六入五成双"）、`max()`、`min()`。

**math 库**（4 个常数 + 44 个函数，仅支持整数和浮点，需 `import` 后用）：

```python
import math                      # 方式一
from math import sqrt, pi        # 方式二
from math import *               # 方式二的另一种写法
```

| 类别 | 常用成员 |
| :--- | :--- |
| 常数 | `pi`、`e`、`inf`（正无穷，负为 `-inf`）、`nan`（非浮点数） |
| 数值函数 | `fabs`、`fmod`、`fsum`、`gcd`、`trunc`、`modf`、`ceil`（向上）、`floor`（向下）、`factorial` |
| 幂对数 | `pow`、`exp`、`sqrt`、`log`、`log2`、`log10`、`degrees`、`radians`、`hypot` |
| 三角函数 | `sin`、`cos`、`tan`、`asin`、`acos`、`atan`（参数均为**弧度**） |

角度转弧度用 `radians(30)`；一元二次方程求根须写成 `(-b+sqrt(b*b-4*a*c))/(2*a)`，括号不能省。

> **知识点标注**：🔴 七种运算符（尤其 `/`、`//`、`%`、`**`）、优先级、`round()` 的五成双规则、math 库导入与常用函数；🟡 复数类型与 `real`/`imag`、浮点指数形式规则；🟢 `divmod`/`hypot` 等较偏函数。

### 2.6 字符串

**四种定义方式**：单引号 `'...'`、双引号 `"..."`、三单引号 `'''...'''`、三双引号 `"""..."""`。三引号内可包含单双引号，且**可以跨行**。

**索引与切片**：字符串有两种序号体系——**正向递增**（0 起）和**反向递减**（-1 起）。

```python
s = "Hello Mike"     # 索引：H(0/-10) e(1/-9) ... e(9/-1)
s[0]        # 单个字符
s[头:尾]    # 切片：取 [头, 尾) 的子串，不含尾下标
s[头:尾:步长]  # 步长>0 从左向右，<0 从右向左
s[::-1]     # 反转整个字符串
```

切片缺省规则：头缺省从开头取，尾缺省取到最后，头尾均缺省取整个字符串。

**典型例题——月份缩写**（切片的实际运用）：

```python
m = int(input("输入1-12的整数："))
months = "JanFebMarAprMayJunJulAugSepOctNovDec"
pos = (m - 1) * 3               # 每项 3 个字母，起始位置 = (m-1)*3
print(months[pos:pos+3])
```

**字符串运算符**：`+` 拼接、`*` 复制（`"Tom"*3` → `TomTomTom`）、`in` / `not in` 判断子串。

**内置处理函数**：`len(x)` 长度、`str(x)` 转字符串、`chr(x)` 编码→字符、`ord(x)` 字符→编码、`hex(x)` 转十六进制、`oct(x)` 转八进制。

**字符编码**：ASCII 用单字节表示，最高位为 0，最多 128 个字符（0~127）；Unicode 把世界所有语言统一到一套编码。常用 ASCII 值（**掌握**）：

| 字符 | 十六进制 | 十进制 |
| :--- | :---: | :---: |
| 空格 | 20H | 32 |
| `0`~`9` | 30H~39H | 48~57 |
| `A`~`Z` | 41H~5AH | 65~90 |
| `a`~`z` | 61H~7AH | 97~122 |

大小关系：**空格 < 数字 < 大写字母 < 小写字母**。

**字符串处理方法**（字符串**不可变**，所有"修改"方法都返回新串，不改原串）：

| 类别 | 方法 |
| :--- | :--- |
| 查找 | `find()` / `rfind()`（不存在返回 -1）、`index()` / `rindex()`（不存在抛异常）、`count()` |
| 分隔 | `split()` / `rsplit()`（默认按空白符分隔） |
| 连接 | `join()`（列表中多个字符串用指定字符连接） |
| 大小写 | `lower()`、`upper()`、`capitalize()`、`title()`、`swapcase()` |
| 去字符 | `strip()`、`rstrip()`、`lstrip()`（默认去空白、制表、换行） |
| 替换 | `replace()`（原串不变，需赋值接收） |
| 判断 | `isupper()`、`islower()` 等 |

**format 格式化**：

```python
"模板{}和{}".format(对象1, 对象2)      # 默认顺序，也可指定顺序
"{:<填充字符><对齐方式><宽度>}".format(x)  # : 是格式引导符
```

对齐方式：`^` 居中、`<` 左对齐、`>` 右对齐；填充字符只能是一个字符，默认空格；宽度为整数。

**转义字符**：`\n` 换行、`\t` 水平制表、`\r` 回车、`\\` 反斜杠、`\'` / `\"` 引号、`\b` 退格、`\0` 空字符、`\nnn`（1~3 位八进制）、`\xhh`（1~2 位十六进制），行尾 `\` 表示续行。

> **知识点标注**：🔴 索引与切片（含 `[::-1]`）、`find` 与 `index` 的区别、字符串不可变性、format 格式、ASCII 常用值；🟡 字符串运算符与处理方法、转义字符；🟢 Unicode 编号范围、三引号跨行。

### 2.7 类型转换

**自动转换**：发生在不同类型混合运算时，规则为——

- `int → float`（整型自动转浮点）；
- `bool → int`（`True → 1`，`False → 0`）。

**强制转换**：

| 函数 | 作用 |
| :--- | :--- |
| `int(x)` | 将字符串（不带小数点、不能是表达式）或浮点数转为整型 |

注意：`int("99//3")` 会抛 `ValueError`——字符串必须是纯数字，不能是表达式。在 `input()` 中可用 `int()` 或 `float()` 代替 `eval()`。

## 第三章 程序流程控制

**程序的三种基本结构**：顺序结构、分支（选择）结构、循环结构。

### 3.1 条件表达式

选择结构和循环结构都依据**条件表达式**的值决定执行流程，其中常用关系运算符和逻辑运算符。

**关系运算符**（假设 `a=10, b=20`）：

| 运算符 | 含义 | 示例 | 结果 |
| :---: | :--- | :--- | :--- |
| `==` | 等于 | `a == b` | False |
| `!=` | 不等于 | `a != b` | True |
| `>` | 大于 | `a > b` | False |
| `<` | 小于 | `a < b` | True |
| `>=` | 大于等于 | `a >= b` | False |
| `<=` | 小于等于 | `a <= b` | True |

关系运算符**可以连用**，与数学写法完全一致：`0 < a < 10`。

**逻辑运算符**：`not`（非，取反）、`and`（与，两者都真才为真）、`or`（或，有一个为真即为真）。

**短路原理**——逻辑运算的返回值是**参与运算的操作数**，不是单纯的 True/False：

- `and`：左边为 0（假）则值为左边，否则值为右边。`0 and 2 → 0`，`1 and 2 → 2`；
- `or`：左边为 0 则值为右边，否则值为左边。`0 or 2 → 2`，`1 or 2 → 1`。

**对象的布尔值**：Python 中每个对象天生具有布尔值，用 `bool()` 获取。**以下对象为 False，其余均为 True**：

```
None、False、所有值为零的数（0 / 0.0 / 0.0+0.0j）、""（空字符串）、[]、()、{}、空集合 set()
```

**混合运算顺序**：括号 → 算术运算 → 关系运算 → 逻辑运算。注意区分关系运算符 `==` 与赋值符号 `=`。

**常见条件表达式**：

```python
x % 2 == 0                          # x 是偶数
x % 3 == 0 and x % 10 == 5          # x 是 3 的倍数且个位为 5
(x % 2 == 0 or x % 3 == 0) and not (x % 2 == 0 and x % 3 == 0)   # 能被 2 或 3 整除，但不同时被两者整除
```

> **知识点标注**：🔴 短路原理与 `and`/`or` 的返回值、布尔值为 False 的对象清单、运算符优先级；🟡 关系运算符连用、三个逻辑运算符；🟢 复杂条件的构建。

### 3.2 选择结构

**单分支 `if`**：

```python
if 条件表达式:
    语句块        # 条件为 True 才执行；冒号不可省，语句块要缩进
```

**双分支 `if...else`**：条件为真执行语句块 1，否则执行语句块 2，二者**有且只有一个**被执行。

```python
if 条件表达式:
    语句块1
else:
    语句块2
```

**简洁表达式（条件表达式）**：`语句1 if 条件 else 语句2`，条件真取语句 1，否则取语句 2。

```python
print("偶数") if x % 2 == 0 else print("奇数")
k = 'No' if s < 18 else 'Yes'
```

**多分支 `if...elif...else`**：

```python
if 条件1:
    语句块1
elif 条件2:
    语句块2
elif 条件3:
    语句块3
else:
    语句块n
```

`else` 后面**不能加条件**，且 `else` 分支可选。典型应用——BMI 指数分级：

| BMI 范围 | 判定 |
| :--- | :--- |
| < 18.5 | 过轻 |
| 18.5 ~ 23.9 | 正常 |
| 24 ~ 27.9 | 过重 |
| 28 ~ 32 | 肥胖 |
| > 32 | 过于肥胖 |

**`if` 嵌套**：在 `if` 语句块中再包含完整的 `if` 结构。典型例题——输入三位整数求最大数位：

```python
num = int(input("请输入一个三位正整数："))
a = num // 100       # 百位
b = num // 10 % 10   # 十位
c = num % 10         # 个位
if a > b:
    if a > c:
        max_num = a
    else:
        max_num = c
else:
    if b > c:
        max_num = b
    else:
        max_num = c
print(num, "中最大的数字是：", max_num)
```

三位数的分离有两种途径：算术运算（`//`、`%`）和字符串索引（`num[0]`、`num[1]`、`num[2]`，此时 `num` 为输入字符串）。

> **知识点标注**：🔴 四种选择结构的语法与缩进、简洁表达式、多分支的判断顺序；🟡 if 嵌套、三位数分离技巧；🟢 三角形面积合法性检查（三边关系 `a+b>c and a+c>b and b+c>a`）。

### 3.3 循环结构

**引入循环**：有规律的重复计算。如打印 `sin x`（每 10° 一个间隔，0~360），顺序结构需 37 行，循环结构几行即可。

**`for` 语句**（遍历循环）：

```python
for 循环变量 in 迭代器:
    语句块      # 循环体需缩进，块内各语句缩进量相同
```

迭代器可以是**字符串**（逐字符遍历）、`range()` 对象等。`range()` 的三种形式：

```python
range(n)        # 0 ~ n-1
range(m, n)     # m ~ n-1
range(m, n, d)  # m ~ n-1，步长 d
```

**`while` 语句**（条件循环）：

```python
while 条件表达式:
    语句块
```

先求条件值，为 True 执行循环体一次，再重复；为 False 时结束。适合**循环次数未知**的场景。

**`break` 与 `continue`**：

- `break`——**结束整个循环**；
- `continue`——**结束本轮循环**，转去做下一次循环。

```python
# break 版：输出 1 2（遇到 3 的倍数立即结束）
# continue 版：输出 1 2 4 5 7 8 10（跳过 3 的倍数）
for i in range(1, 11):
    if i % 3 == 0:
        break          # 换成 continue 即为另一版
    print(i, end='  ')
```

**循环中的 `else` 子句**：**循环正常结束（遍历完/条件变假）时执行**；若由 `break` 提前退出，则 `else` 不执行。这是判素数的经典写法：

```python
n = int(input("输入一个正整数n(n>=2):"))
for i in range(2, n):
    if n % i == 0:
        print(n, "不是素数")
        break
else:
    print(n, "是素数")
```

**循环嵌套**：循环体内又包含一个完整的循环结构。典型例子——九九乘法表：

```python
for i in range(1, 10):
    for j in range(1, i + 1):
        print("{}×{}={:<4}".format(i, j, i*j), end='  ')
    print()
```

**浮点数的相等判断要小心**：`A == B` 改写为 `abs(A-B) < 1e-8`；`A != B` 改写为 `abs(A-B) > 1e-8`。牛顿迭代法求平方根时若直接用 `y*y != x` 作条件可能陷入死循环（可用 Ctrl+C 终止）。

> **知识点标注**：🔴 `for`/`while` 语法、`range()` 三种形式、`break` 与 `continue` 的区别、循环 `else` 的执行条件、循环嵌套；🟡 浮点数相等判断的改写、牛顿迭代法；🟢 循环体内修改循环变量对迭代的影响（`for x in range(2,6): x=8` 不改变迭代序列）。

## 第四章 列表与元组

### 4.1 列表的定义与索引

**列表（list）**：用来**有序**存放一组相关数据，以便统一处理。把一组数据放在一对方括号 `[]` 中即定义了一个列表。每个数据称为**元素**，数据个数称为**长度**。

```python
scores = [98, 96, 95, 94, 92]
```

**双向索引**（与字符串相同）：正向 `0,1,2,3,4`，反向 `-5,-4,-3,-2,-1`。`scores[2] == scores[-3] == 95`。

**元素类型**：可以是数值、字符串，也可以是列表、元组、字典、集合等任意类型——支持**嵌套**。

```python
ls = ['book', 666, [2021, 'python', 314], 20]
print(ls[2][1][-2])     # 逐层索引：'python'[-2] → 'o'
```

**例 4-1 月份输出**：把 12 个月份放进列表，输入 `i` 输出 `monthes[i-1]`——注意"差 1"处理。

> **知识点标注**：🔴 列表定义、双向索引、嵌套列表的逐层访问；🟡 元素类型可多样性；🟢 "差 1"下标处理。

---

### 4.2 列表元素的增删改查

**列表元素有序且可变**，支持修改、添加、删除。

**修改**：`列表名[索引] = 新值`。

**列表方法一览**（核心表格）：

| 方法 | 说明 |
| :--- | :--- |
| `append(x)` | 将元素 x 添加至列表**尾部** |
| `extend(L)` | 将列表 L 中所有元素添加至尾部 |
| `insert(index, x)` | 在指定位置 index 处添加元素 x |
| `remove(x)` | 删除**首次出现**的指定元素（按值） |
| `pop(index)` | 删除并返回指定位置元素，默认最后一个 |
| `clear()` | 删除所有元素，**保留列表对象** |
| `index(x)` | 返回第一个值为 x 的元素下标，不存在则**抛异常** |
| `count(x)` | 返回 x 在列表中出现的次数 |
| `reverse()` | **原地**翻转列表 |
| `sort()` | **原地**排序 |
| `copy()` | 复制列表（独立空间，不共享） |

**删除方式对比**：

- 已知**索引**：`del 列表名[索引]` 或 `pop()`；`pop()` 删除同时**返回**该元素，删末尾最方便；
- 已知**值**：用 `remove()`；
- `del 列表名`：删除整个表，**不保留表结构**；
- `clear()` / `del ls[:]` / `ls[:] = []`：清空元素，**保留表结构**。

**其他常用操作**：`len(列表)` 求长度、`in` / `not in` 判断元素是否存在、`index()` 查找、`count()` 统计。

> **知识点标注**：🔴 全部 11 个方法的作用、`del` 与 `clear` 的区别、`pop` 的返回值；🟡 `remove` 按值删除首次出现、`index` 找不到会报错；🟢 `len`、`in`、`count` 的用法。

---

### 4.3 操作列表

**遍历列表**（从头到尾访问元素）：

1. 用 `range()` 遍历——`for i in range(len(ls)): print(ls[i])`，通过修改参数可灵活访问部分元素；
2. 直接元素遍历——`for item in ls: print(item)`，表达更直观。

**排序**：

- `L.sort(key=None, reverse=False)`——**原地排序**，改变原列表。`reverse=True` 降序；`key` 指定排序规则，如 `fruitlist.sort(key=len)` 按长度排。字符串和元组（不可变）**没有** `sort` 方法；
- `sorted(L)`——**生成新列表**，不改变原列表，适用于字符串、元组。

嵌套列表默认以元素的第一个子元素为关键字升序排序。

**翻转**：

- `reverse()`——直接翻转原列表，改变内容（字符串、元组无此方法）；
- `reversed()`——生成新的迭代对象，原列表不变。

**切片**：与字符串切片完全一致，`列表[起始:终止:步长]`，如 `ls[::-1]` 反转。

**扩充（三种方式）**：

```python
ls + [x]        # "+" 连接，生成新列表，不改变原列表
ls.extend(L)    # 把 L 的元素加入原列表，原地改变
ls * 3          # "*" 重复，生成新列表
```

**复制（关键区别）**：

```python
lsCopy = ls.copy()   # 深拷贝：两个列表独立空间，互不影响
ls1 = ls             # 赋值：浅拷贝，两个列表共享同一空间
```

执行 `del ls[0]` 后，`lsCopy` 不受影响，`ls1` 会同步变化。同理：`list2 = list1; list2.clear()` 会使 `list1` 也变空。

> **知识点标注**：🔴 `sort` 与 `sorted`、`reverse` 与 `reversed`、`copy()` 与赋值拷贝的本质区别、`+` 与 `extend` 的区别；🟡 两种遍历方式、`key` 参数；🟢 嵌套列表的默认排序规则。

---

### 4.4 数值列表与列表生成式

**创建列表的四种方式**：

1. `=` 直接赋值；
2. `split()` 方法（字符串按分隔符切分为列表）；
3. `list()` 函数——把元组、range 对象、字符串等可迭代对象转为列表；
4. `input()` 输入（得到字符串，配合 `eval()` 去引号）。

**列表生成式**（重点）：

```python
列表 = [循环变量相关表达式 for 循环变量 in 可迭代对象]
```

```python
[x**2 for x in range(1, 11)]        # 1~10 的平方
[s*2 for s in 'abcd']               # ['aa','bb','cc','dd']
[(i[0], i[2]) for i in ls]          # 从学生信息中提取姓名和籍贯
```

**嵌套列表生成式**：`[表达式 for 外循环 for 内循环]`，可实现——① 嵌套列表平铺；② 过滤不符合条件的元素（加 `if`）；③ 多序列元素的任意组合（多重循环）。

**数值列表的统计函数**：`len()` 元素个数、`min()` 最小值、`max()` 最大值、`sum()` 元素之和。

> **知识点标注**：🔴 列表生成式的写法（含带 `if` 过滤、双重循环）、四种统计函数；🟡 `list()` 转换、生成式的嵌套；🟢 `split()` 创建列表。
